# 排列组合

## 基本计数原理

排列组合是组合数学的基础，其核心在于**不重不漏**地计数。所有复杂的计数问题最终都可以归结为两个基本原理：加法原理和乘法原理。

### 加法原理

若完成一件事有 $n$ 类不同的方案，第 $i$ 类方案中有 $m_i$ 种不同的方法，则完成这件事共有：

$$
N = m_1 + m_2 + \cdots + m_n = \sum_{i=1}^{n} m_i
$$

种不同的方法。加法原理的关键在于"分类"，各类方案之间互斥（即不能同时采用两类方案）。

**示例**：从北京到上海，可以选择高铁（3个班次）、飞机（5个班次）或汽车（2个班次），则共有 $3+5+2=10$ 种出行方式。

### 乘法原理

若完成一件事需要分成 $n$ 个步骤，第 $i$ 步有 $m_i$ 种不同的方法，则完成这件事共有：

$$
N = m_1 \times m_2 \times \cdots \times m_n = \prod_{i=1}^{n} m_i
$$

种不同的方法。乘法原理的关键在于"分步"，各步骤之间独立（即前一步的选择不影响后一步的选择数）。

**示例**：从3件上衣和2条裤子中选一套穿搭，分两步：选上衣（3种）、选裤子（2种），共 $3 \times 2 = 6$ 种搭配。

!!! tip "原理辨析"
    加法原理：互斥事件，用"或"连接，结果相加。
    乘法原理：独立事件，用"且"连接，结果相乘。


## 排列

### 全排列

从 $n$ 个不同元素中取出全部 $n$ 个元素，按照一定的顺序排成一列，叫做 $n$ 个元素的一个全排列。全排列数记作 $P_n$ 或 $A_n^n$：

$$
P_n = A_n^n = n! = n \times (n-1) \times (n-2) \times \cdots \times 2 \times 1
$$

规定 $0! = 1$。

### 选排列

从 $n$ 个不同元素中取出 $k$ 个（$k \leq n$）元素，按照一定的顺序排成一列，叫做从 $n$ 个不同元素中取出 $k$ 个元素的一个排列。排列数记作 $A_n^k$（或 $P_n^k$）：

$$
A_n^k = \frac{n!}{(n-k)!} = n \times (n-1) \times (n-2) \times \cdots \times (n-k+1)
$$

**理解**：第1个位置有 $n$ 种选择，第2个位置有 $n-1$ 种选择，……，第 $k$ 个位置有 $n-k+1$ 种选择，由乘法原理即得上式。

### 排列的递推关系

排列数满足如下递推关系：

$$
A_n^k = A_{n-1}^k + k \cdot A_{n-1}^{k-1}
$$

**解释**：考虑是否包含某个特定元素 $x$：
- 不选 $x$：从剩余 $n-1$ 个元素中选 $k$ 个排列，即 $A_{n-1}^k$
- 必选 $x$：先从剩余 $n-1$ 个元素中选 $k-1$ 个排列（$A_{n-1}^{k-1}$），再将 $x$ 插入到 $k$ 个位置中的任意一个，共 $k \cdot A_{n-1}^{k-1}$

## 组合

### 组合数定义

从 $n$ 个不同元素中取出 $k$ 个（$k \leq n$）元素，不考虑顺序组成一组，叫做从 $n$ 个不同元素中取出 $k$ 个元素的一个组合。组合数记作 $\binom{n}{k}$ 或 $C_n^k$：

$$
\binom{n}{k} = C_n^k = \frac{A_n^k}{k!} = \frac{n!}{k! \cdot (n-k)!}
$$

**理解**：先选排列（考虑顺序）有 $A_n^k$ 种，而每组 $k$ 个元素的 $k!$ 种排列对应同一个组合，故除以 $k!$。

### 组合数的基本性质

| 性质 | 公式 | 含义 |
|------|------|------|
| 对称性 | $\binom{n}{k} = \binom{n}{n-k}$ | 选 $k$ 个 = 留 $n-k$ 个 |
| 递推式 | $\binom{n}{k} = \binom{n-1}{k} + \binom{n-1}{k-1}$ | 杨辉三角 |
| 边界 | $\binom{n}{0} = \binom{n}{n} = 1$ | |
| 单峰性 | $\binom{n}{0} < \binom{n}{1} < \cdots < \binom{n}{\lfloor n/2 \rfloor} = \binom{n}{\lceil n/2 \rceil} > \cdots > \binom{n}{n}$ | 中间项最大 |

!!! note "杨辉三角递推的组合解释"
    考虑是否包含某个特定元素 $x$：
    - 不选 $x$：从剩余 $n-1$ 个中选 $k$ 个，即 $\binom{n-1}{k}$
    - 必选 $x$：从剩余 $n-1$ 个中选 $k-1$ 个，即 $\binom{n-1}{k-1}$


## 多重集排列

考虑含有重复元素的排列问题。设多重集 $S = \{n_1 \cdot a_1, n_2 \cdot a_2, \cdots, n_k \cdot a_k\}$，其中 $n_i$ 是元素 $a_i$ 的个数，记 $n = n_1 + n_2 + \cdots + n_k$，则 $S$ 的全排列数为：

$$
\frac{n!}{n_1! \cdot n_2! \cdot \cdots \cdot n_k!} = \binom{n}{n_1, n_2, \cdots, n_k}
$$

**直观解释**：先假设所有元素互不相同，有 $n!$ 种排列。然后对于每种元素 $a_i$，其 $n_i$ 个副本之间的 $n_i!$ 种排列实际上是相同的，故需要除以各 $n_i!$。

**示例**：单词 "MISSISSIPPI" 有多少种不同的排列？
- M: 1个, I: 4个, S: 4个, P: 2个, 共11个字母
- 排列数 = $\dfrac{11!}{1! \cdot 4! \cdot 4! \cdot 2!} = 34650$

## 可重复组合与隔板法

### 可重复组合

从 $n$ 种不同元素中可重复地选取 $k$ 个元素，不考虑顺序，称为可重复组合。其组合数为：

$$
\binom{n + k - 1}{k}
$$

### 隔板法

隔板法是解决"相同元素分组"问题的经典技巧。

**问题模型**：将 $k$ 个**完全相同**的球放入 $n$ 个**不同**的盒子中，有多少种放法？

#### 情形1：每盒至少1个球（正整数解）

方程 $x_1 + x_2 + \cdots + x_n = k$（$x_i \geq 1$）的正整数解个数。

**方法**：$k$ 个球之间有 $k-1$ 个空隙，插入 $n-1$ 块隔板，分成 $n$ 组：

$$
\binom{k-1}{n-1}
$$

#### 情形2：允许空盒（非负整数解）

方程 $x_1 + x_2 + \cdots + x_n = k$（$x_i \geq 0$）的非负整数解个数。

**方法**：令 $y_i = x_i + 1$，则 $y_i \geq 1$，方程变为 $y_1 + y_2 + \cdots + y_n = k + n$。于是解数为：

$$
\binom{(k+n)-1}{n-1} = \binom{n+k-1}{n-1} = \binom{n+k-1}{k}
$$

这就是可重复组合的公式！

**示例**：方程 $a + b + c = 10$（$a,b,c \geq 0$）有多少非负整数解？
- 解数 = $\binom{10 + 3 - 1}{3 - 1} = \binom{12}{2} = 66$

## C++ 预处理组合数

在算法竞赛中，我们通常需要快速计算组合数 $\binom{n}{m} \bmod p$，其中 $p = 10^9 + 7$ 是常见的大质数。使用**阶乘 + 乘法逆元**可以做到 $O(n)$ 预处理、$O(1)$ 查询。

### 原理

$$
\binom{n}{m} = \frac{n!}{m! \cdot (n-m)!} \equiv n! \cdot (m!)^{-1} \cdot ((n-m)!)^{-1} \pmod{p}
$$

由于 $p$ 是质数，根据费马小定理，$a^{p-1} \equiv 1 \pmod{p}$，故 $a$ 的逆元为 $a^{p-2} \pmod{p}$。

### 代码实现

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MOD = 1e9 + 7;
const int MAXN = 1e6 + 5;

long long fact[MAXN];      // fact[i] = i! mod MOD
long long inv_fact[MAXN];  // inv_fact[i] = (i!)^{-1} mod MOD

// 快速幂: a^b mod MOD
long long qpow(long long a, long long b) {
    long long res = 1;
    while (b > 0) {
        if (b & 1) res = res * a % MOD;
        a = a * a % MOD;
        b >>= 1;
    }
    return res;
}

// 预处理阶乘和阶乘的逆元
void init(int n) {
    fact[0] = 1;
    for (int i = 1; i <= n; i++) {
        fact[i] = fact[i-1] * i % MOD;
    }
    inv_fact[n] = qpow(fact[n], MOD - 2);
    for (int i = n - 1; i >= 0; i--) {
        inv_fact[i] = inv_fact[i+1] * (i+1) % MOD;
    }
}

// 计算 C(n, m) mod MOD
long long C(int n, int m) {
    if (m < 0 || m > n) return 0;
    return fact[n] * inv_fact[m] % MOD * inv_fact[n - m] % MOD;
}

int main() {
    init(1000000);
    cout << C(5, 2) << endl;   // 输出: 10
    cout << C(10, 3) << endl;  // 输出: 120
    cout << C(100, 50) << endl; // 输出 C(100,50) mod 1e9+7
    return 0;
}
```

!!! tip "技巧：线性递推逆元"
    也可以先求出 $1 \sim n$ 的逆元，再递推阶乘逆元：$inv[i] = (p - p/i) \cdot inv[p \bmod i] \bmod p$。


## 例题

### 例题1：双色球

**题目**：双色球投注规则：从红球号码01~33中选6个，从蓝球号码01~16中选1个。问共有多少种不同的投注？

**解答**：

选红球：从33个中选6个（不考虑顺序），有 $\binom{33}{6}$ 种选法。
选蓝球：从16个中选1个，有 $\binom{16}{1} = 16$ 种选法。

由乘法原理，总投注数：

$$
\binom{33}{6} \times 16 = \frac{33!}{6! \cdot 27!} \times 16 = 1107568 \times 16 = 17721088
$$

!!! note
    这就是为什么双色球一等奖中奖概率约为 $1/1772$ 万。

### 例题2：排列中的相邻问题

**题目**：有 $n$ 个男生和 $m$ 个女生排队，求所有女生互不相邻的排列数。

**解答**：

使用**插空法**：

1. 先排 $n$ 个男生：有 $n!$ 种排法。
2. $n$ 个男生排好后，形成 $n+1$ 个空隙（包括两端）。
3. 从 $n+1$ 个空隙中选 $m$ 个放入女生，有 $A_{n+1}^m$ 种放法。
4. 女生内部排列：$m!$ 种。

因此总排列数：

$$
n! \times A_{n+1}^m = n! \times \binom{n+1}{m} \times m!
$$

当 $m > n+1$ 时，答案为 $0$（鸽巢原理保证必有两女生相邻）。

**数值例子**：3男2女，排列数 = $3! \times \binom{4}{2} \times 2! = 6 \times 6 \times 2 = 72$。

### 例题3：不定方程的解数

**题目**：求方程 $x_1 + x_2 + x_3 + x_4 = 20$ 满足 $x_1 \geq 2, x_2 \geq 3, x_3 \geq 4, x_4 \geq 1$ 的正整数解个数。

**解答**：

先做变量替换，将下界转化为0：

令 $y_1 = x_1 - 2$，$y_2 = x_2 - 3$，$y_3 = x_3 - 4$，$y_4 = x_4 - 1$，则 $y_i \geq 0$。

代入原方程：

$$
(y_1 + 2) + (y_2 + 3) + (y_3 + 4) + (y_4 + 1) = 20
$$

化简：

$$
y_1 + y_2 + y_3 + y_4 = 20 - 10 = 10
$$

非负整数解的个数为（可重复组合 / 隔板法）：

$$
\binom{10 + 4 - 1}{4 - 1} = \binom{13}{3} = 286
$$

故原方程满足条件的解有 **286** 个。

!!! abstract "排列组合解题思想"
    1. **分类讨论**：复杂问题拆解为互斥的几类（加法原理）
    2. **分步计算**：每步独立选择数相乘（乘法原理）
    3. **特殊优先**：有限制的元素/位置先处理
    4. **正难则反**：直接计数困难时用"总 - 反面"
    5. **模型转化**：将陌生问题转化为排列/组合/隔板模型
