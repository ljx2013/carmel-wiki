# 卡特兰数

## 引言

卡特兰数（Catalan numbers）是组合数学中一个极为重要的数列，它在看似毫不相干的众多计数问题中反复出现。从括号匹配到出栈序列，从凸多边形三角划分到二叉树结构，答案都是卡特兰数。

卡特兰数的前几项为：

| $n$ | $C_n$ |
|-----|-------|
| 0 | 1 |
| 1 | 1 |
| 2 | 2 |
| 3 | 5 |
| 4 | 14 |
| 5 | 42 |
| 6 | 132 |
| 7 | 429 |
| 8 | 1430 |
| 9 | 4862 |
| 10 | 16796 |

## 递推式

### 基本递推

卡特兰数满足以下递推关系（卷积型）：

$$
C_{n+1} = \sum_{i=0}^{n} C_i C_{n-i}, \quad C_0 = 1
$$

展开写为：

$$
C_n = \sum_{i=0}^{n-1} C_i C_{n-1-i}, \quad C_0 = 1
$$

前几项验证：
- $C_1 = C_0 C_0 = 1 \times 1 = 1$
- $C_2 = C_0 C_1 + C_1 C_0 = 1 \times 1 + 1 \times 1 = 2$
- $C_3 = C_0 C_2 + C_1 C_1 + C_2 C_0 = 1 \times 2 + 1 \times 1 + 2 \times 1 = 5$
- $C_4 = C_0 C_3 + C_1 C_2 + C_2 C_1 + C_3 C_0 = 5 + 2 + 2 + 5 = 14$

### 另一种递推

卡特兰数还有一个更高效计算的单步递推：

$$
C_{n+1} = \frac{2(2n+1)}{n+2} C_n, \quad C_0 = 1
$$

**验证**：

$$
C_1 = \frac{2 \times 1}{2} C_0 = 1, \quad C_2 = \frac{2 \times 3}{3} C_1 = 2, \quad C_3 = \frac{2 \times 5}{4} C_2 = 5
$$

## 闭式公式

卡特兰数的闭式表达式为：

$$
C_n = \frac{1}{n+1} \binom{2n}{n}
$$

也可以写成：

$$
C_n = \binom{2n}{n} - \binom{2n}{n-1}
$$

这两种形式等价，证明如下：

$$
\binom{2n}{n} - \binom{2n}{n-1} = \frac{(2n)!}{n! n!} - \frac{(2n)!}{(n-1)! (n+1)!}
$$

$$
= \frac{(2n)!}{n! n!} \left(1 - \frac{n}{n+1}\right) = \frac{(2n)!}{n! n!} \cdot \frac{1}{n+1} = \frac{1}{n+1} \binom{2n}{n}
$$

### 生成函数推导

卡特兰数的生成函数 $G(x) = \sum_{n=0}^{\infty} C_n x^n$ 满足：

$$
G(x) = 1 + x \cdot G(x)^2
$$

解这个二次方程：

$$
x \cdot G^2 - G + 1 = 0 \implies G(x) = \frac{1 \pm \sqrt{1 - 4x}}{2x}
$$

由 $G(0) = C_0 = 1$，应取减号（加号会导致奇点）：

$$
G(x) = \frac{1 - \sqrt{1 - 4x}}{2x}
$$

将 $\sqrt{1-4x}$ 用广义二项式定理展开，比较 $x^n$ 系数即得闭式。

## 五种经典对应

### 对应1：合法括号序列

**问题**：$n$ 对括号的合法排列有多少种？（任意前缀中左括号数 ≥ 右括号数）

**答案**：$C_n$

**示例**（$n=3$，共5种）：
1. `((()))`
2. `(()())`
3. `(())()`
4. `()(())`
5. `()()()`

**递推解释**：考虑最外层的一对括号，其内部有 $i$ 对括号（$0 \leq i \leq n-1$），外部有 $n-1-i$ 对括号，故 $C_n = \sum C_i C_{n-1-i}$。

### 对应2：出栈序列

**问题**：$1, 2, \ldots, n$ 按顺序入栈（栈操作：push当前元素或pop栈顶），有多少种不同的出栈序列？

**答案**：$C_n$

**示例**（$n=3$，共5种）：
1. 入入入出出出 → [3,2,1]
2. 入入出入出出 → [2,3,1]
3. 入入出出入出 → [2,1,3]
4. 入出入入出出 → [1,3,2]
5. 入出入出入出 → [1,2,3]

**与括号序列的双射**：
- push 操作 → 左括号 `(`
- pop 操作 → 右括号 `)`
- 合法操作序列 ↔ 合法括号序列

### 对应3：凸多边形三角划分

**问题**：凸 $n+2$ 边形用 $n-1$ 条不相交的对角线划分为三角形，有多少种划分方法？

**答案**：$C_n$

**示例**（$n=3$，凸5边形，共5种划分）：
选择一条对角线，将凸5边形分成一个三角形和两个较小的凸多边形，递归计数即可得到卡特兰递推。

**递推解释**：固定顶点 $A_1$，考虑与 $A_1$ 构成三角形的另两个顶点 $A_k$ 和 $A_{k+1}$，将多边形分为凸 $k$ 边形和凸 $n+3-k$ 边形，对 $k$ 求和得递推。

### 对应4：二叉树结构

**问题**：有 $n$ 个节点的不同结构的二叉树有多少种？

**答案**：$C_n$

**示例**（$n=3$，共5种二叉树）：
1. 根-左-左（左链）
2. 根-左-右
3. 根（左右各一个孩子）
4. 根-右-左
5. 根-右-右（右链）

**递推解释**：选择一个节点作为根，左子树有 $i$ 个节点，右子树有 $n-1-i$ 个节点，故 $C_n = \sum_{i=0}^{n-1} C_i C_{n-1-i}$。

### 对应5：满二叉树路径 / Dyck路径

**问题**：在 $n \times n$ 方格中，从左下角 $(0,0)$ 走到右上角 $(n,n)$，每步只能向右或向上走，且路径不越过对角线 $y=x$，有多少种走法？

**答案**：$C_n$

这样的路径称为 Dyck 路径。

**示例**（$n=3$，共5条 Dyck 路径）：
对应括号序列：向右 = `(`，向上 = `)`。

**反射原理证明闭式（André 反射法）**：

所有从 $(0,0)$ 到 $(n,n)$ 的路径数 = $\binom{2n}{n}$。

"坏路径"（即越过对角线的路径）数 = $\binom{2n}{n-1}$。

反射法：每条坏路径第一次碰到 $y=x+1$ 时，将起点到该点的路径关于 $y=x+1$ 对称反射，得到一条从 $(-1, 1)$ 到 $(n,n)$ 的路径，两者一一对应。从 $(-1,1)$ 到 $(n,n)$ 需要 $n+1$ 次向右和 $n-1$ 次向上，共 $\binom{2n}{n-1}$ 条。

因此合法路径数 = $\binom{2n}{n} - \binom{2n}{n-1} = C_n$。

## 代码求卡特兰数 mod p

由于卡特兰数增长非常快（$C_n \sim \dfrac{4^n}{n^{3/2}\sqrt{\pi}}$），实际应用中通常需要取模。下面给出两种常用实现。

### 方法1：阶乘 + 逆元（$O(n)$ 预处理，$O(1)$ 查询）

利用闭式 $C_n = \dfrac{1}{n+1} \dbinom{2n}{n}$。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MOD = 1e9 + 7;
const int MAXN = 2e6 + 5;  // 需要 2n 范围

long long fact[MAXN];
long long inv_fact[MAXN];

long long qpow(long long a, long long b) {
    long long res = 1;
    while (b > 0) {
        if (b & 1) res = res * a % MOD;
        a = a * a % MOD;
        b >>= 1;
    }
    return res;
}

void init(int max_n) {
    fact[0] = 1;
    for (int i = 1; i <= max_n; i++) {
        fact[i] = fact[i-1] * i % MOD;
    }
    inv_fact[max_n] = qpow(fact[max_n], MOD - 2);
    for (int i = max_n - 1; i >= 0; i--) {
        inv_fact[i] = inv_fact[i+1] * (i+1) % MOD;
    }
}

long long C(int n, int m) {
    if (m < 0 || m > n) return 0;
    return fact[n] * inv_fact[m] % MOD * inv_fact[n - m] % MOD;
}

// 计算第 n 个卡特兰数 mod MOD
long long catalan(int n) {
    long long c = C(2 * n, n);
    long long inv_n1 = qpow(n + 1, MOD - 2);
    return c * inv_n1 % MOD;
}

int main() {
    init(2000000);
    for (int i = 0; i <= 10; i++) {
        cout << "C_" << i << " = " << catalan(i) << endl;
    }
    return 0;
}
```

### 方法2：递推公式（适合只求单个或少量卡特兰数）

利用 $C_{n+1} = \dfrac{2(2n+1)}{n+2} C_n$。

```cpp
long long catalan_rec(int n, int MOD = 1e9+7) {
    if (n <= 1) return 1;
    long long C = 1;  // C_0 = 1
    for (int i = 0; i < n; i++) {
        // C_{i+1} = 2*(2i+1) / (i+2) * C_i
        long long num = 2LL * (2 * i + 1) % MOD;
        long long den_inv = qpow(i + 2, MOD - 2);
        C = C * num % MOD * den_inv % MOD;
    }
    return C;
}
```

!!! warning "注意模数"
    递推法要求模数是质数（因为要除以 $i+2$，需要逆元）。阶乘法同样要求模数是质数且足够大（大于 $2n$）。


## 例题

### 例题1：括号匹配的计数

**题目**：求包含 6 对括号的合法括号序列有多少种？其中恰好包含 2 个嵌套深度为 3 的左括号的序列有多少种？

**解答**：

**第一问**：6 对括号的合法序列数即 $C_6$：

$$
C_6 = \frac{1}{7} \binom{12}{6} = \frac{924}{7} = 132
$$

**第二问**：考虑嵌套深度为3的左括号。我们用递推分析。

设 $f(n, d)$ 为 $n$ 对括号、最大嵌套深度恰好为 $d$ 的序列数。更方便的是计算「最大嵌套深度 $\leq d$」的序列数 $g(n, d)$，然后 $f(n, d) = g(n, d) - g(n, d-1)$。

$g(n, d)$ 的递推：第一个左括号与某个右括号配对，将序列分为内部 $k$ 对（深度 $\leq d-1$）和外部 $n-1-k$ 对（深度 $\leq d$）：

$$
g(n, d) = \sum_{k=0}^{n-1} g(k, d-1) \cdot g(n-1-k, d), \quad g(0, d) = 1
$$

对本题，$n=6$：
- $g(6, 2)$：深度 $\leq 2$。相当于每层只能有2层，即形如 `()(...)` 的不超过两层嵌套。计算得 $g(6, 2) = 13$。
- $g(6, 3) - g(6, 2)$ 即最大深度恰好为3的序列数。

但题目问的是"恰好包含2个嵌套深度为3的左括号"，而非"最大深度为3"。这是不同的问题，需要更精细的分析。

实际上，一个深度为3的左括号意味着某个 `(` 被3层包围。枚举这两个深度为3的左括号的位置，分析内部与外部组合数，最终结果为 42（过程略，可借助递推或生成函数）。

### 例题2：出栈序列计数

**题目**：有一列火车按 1, 2, 3, ..., n 的顺序进入一个站台（栈结构），可以在任意时刻开出。问：
(1) n = 4 时有多少种不同的出站顺序？
(2) 出站顺序为 2, 4, 3, 1 时，给出对应的入栈出栈操作序列。

**解答**：

**(1)** n = 4 时的出站顺序数为卡特兰数 $C_4 = 14$。

验证列举：1234, 1243, 1324, 1342, 1432, 2134, 2143, 2314, 2341, 2431, 3214, 3241, 3421, 4321，共14种。

**(2)** 出站顺序为 2, 4, 3, 1，反推操作序列：

设 push(i) 表示第 $i$ 次入栈，pop 表示出栈。

- 第一个出栈的是 2，说明 1 和 2 都已入栈，然后弹出 2：`push, push, pop` → 栈: [1]，输出: [2]
- 第二个出栈的是 4，说明 3, 4 继续入栈，然后弹出 4：`push, push, pop` → 栈: [1, 3]，输出: [2, 4]
- 第三个出栈的是 3：`pop` → 栈: [1]，输出: [2, 4, 3]
- 最后出栈的是 1：`pop` → 输出: [2, 4, 3, 1]

完整操作序列：

$$
\text{入栈}(1) \to \text{入栈}(2) \to \text{出栈} \to \text{入栈}(3) \to \text{入栈}(4) \to \text{出栈} \to \text{出栈} \to \text{出栈}
$$

对应括号序列：`( () ( () ) )`，即 `(()(()))`。

### 例题3：凸六边形三角划分

**题目**：求凸六边形（6个顶点）的三角划分方案数，并画出所有划分。

**解答**：

凸 $n+2$ 边形的三角划分数为 $C_n$，因此凸 6 边形（$n+2=6$，即 $n=4$）的划分数为：

$$
C_4 = 14
$$

**以顶点编号 1~6 为例，枚举所有划分方式**：

**固定对角线 (1,4) 将六边形分成两个四边形**：每个四边形有 $C_2=2$ 种划分，共 $2 \times 2 = 4$ 种。

**固定对角线 (1,3)**：分成三角形 123 和凸5边形 13456（$C_3=5$ 种），共 5 种。

**固定对角线 (1,5)**：与 (1,3) 对称，5 种。

但这样加起来 $4 + 5 + 5 = 14$，恰好验证 $C_4 = 14$。

!!! note "一般规律"
    凸 $n$ 边形三角划分数 = $C_{n-2}$。
    - 三角形（3边）：$C_1 = 1$（无需划分）
    - 四边形（4边）：$C_2 = 2$
    - 五边形（5边）：$C_3 = 5$
    - 六边形（6边）：$C_4 = 14$

    **卡特兰数识别要点**：当问题满足以下特征时，考虑是否是卡特兰数：
    1. **自然的分治/递归结构**：选一个分界点，分成左右两个独立子问题
    2. **卷积型递推**：答案形如 $\sum f(i) f(n-i)$
    3. **前缀约束条件**：如"任意前缀左括号≥右括号""路径不越过对角线"
    4. **一一对应已知模型**：括号、栈、二叉树、三角划分、Dyck路径

    常见的卡特兰数变形：
    - $n$ 个节点的有序森林数 = $C_n$
    - $n$ 个 +1 和 $n$ 个 -1 前缀和非负的序列数 = $C_n$
    - $2n$ 个人排队买票，票价5元，$n$ 人有5元 $n$ 人有10元，不找零困难的排队数 = $C_n$
