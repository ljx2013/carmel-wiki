# 时间/空间复杂度

# 简介

时间/空间复杂度是评判代码是否能通过某个测试点的重要根据，同时也是选手根据自己写的代码来判断自己大约能够通过多少个测试点的检查标准。

## 概念

时间/空间复杂度通常用 $O$ 表示，例如一个`for(int i=1;i<=n;i++)`的时间复杂度就是 $O(n)$ ，空间复杂度就是 $O(1)$ 。

### 关于循环

在一般代码中，时间复杂度一般是看代码中的循环而定的，空间复杂度一般是看代码中数组的大小而定的。

例如：

```c++
#include<bits/stdc++.h>
using namespace std;
int a[10005];
int main(){
    ios::sync_with_stdio(0);
    cin.tie(0);
    cout.tie(0);
    int n;
    cin>>n;
    for(int i=1;i<=n;i++){
        cin>>a[i];
    }
    reverse(a+1,a+n+1);
    for(int i=1;i<=n;i++){
        cout<<a[i]<<' ';
    }
    return 0;
}
```

其中：

`a[10005]`的空间复杂度是 $O(n)$，时间复杂度是 $O(1)$ 。

L10~L12的输入代码的时间复杂度是 $O(n)$ 。

`reverse(a+1,a+n+1)`的时间复杂度是 $O(n)$ 。

L14~L15的输出代码的时间复杂度是 $O(n)$ 。

因此，这段代码的时间复杂度是 $O(3n)$ ，空间复杂度是 $O(n)$ 。
