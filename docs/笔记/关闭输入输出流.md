# 关闭输入输出流

# 介绍

在CSP-J/S等竞赛中，时间限制是极为严格的。因此，选手不仅需要注意代码的时间复杂度，还需要注意程序的读入输出效率。

有时，你会发现`cin`与`cout`的效率太低，大部分原因是因为输入输出的同步流没有关闭，因此才造成了`TLE`。

所以我在这里提供两种解决方案：

1. 关闭输入输出流。

2. 使用`scanf`或`printf`。

在某些特殊情况下，关闭输入输出流会较快于`scanf`与`printf`。

今天我们先介绍第1种方法。

## 使用方法

关闭输入输出流共有两部分组成：

1. `ios::sync_with_stdio(0)`

2. `cin.tie(0)`与`cout.tie(0)`

两部分的位置在主函数中仅次于`freopen()`的位置，我们拿A+B Problem举例：

```c++
#include<bits/stdc++.h>
using namespace std;
int main(){
    freopen("xxx.in","r",stdin);
    freopen("xxx.out","w",stdout);
    ios::sync_with_stdio(0);
    cin.tie(0);
    cout.tie(0);
    //你的代码
    return 0;
}
```
