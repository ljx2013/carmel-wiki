# 扩展欧几里得算法（exgcd）

## 问题

求整数 `x, y` 使 `a·x + b·y = gcd(a, b)`。

## 递归实现

由 `gcd(b, a mod b)` 的解回推：若 `b·x' + (a mod b)·y' = g`，则
`a·y' + b·(x' − ⌊a/b⌋·y') = g`。

```c++
#include <bits/stdc++.h>
using namespace std;

long long exgcd(long long a, long long b, long long &x, long long &y) {
    if (!b) { x = 1; y = 0; return a; }
    long long g = exgcd(b, a % b, y, x);
    y -= a / b * x;
    return g;
}

int main() {
    long long x, y;
    long long g = exgcd(12, 18, x, y);
    cout << g << ' ' << x << ' ' << y << '\n';  // 6 -2 1  (12*-2+18*1=6)
    return 0;
}
```

## 用途

- 解线性同余方程 `a·x ≡ c (mod b)`。
- 求乘法逆元（当 `gcd(a, m)=1`）。

## 小结

| 输出 | 含义 |
| --- | --- |
| `g` | `gcd(a,b)` |
| `x, y` | 满足 `a·x+b·y = g` 的一组解 |
