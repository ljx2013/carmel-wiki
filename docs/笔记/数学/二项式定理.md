# 二项式定理

## 内容

$$
(a + b)^n = \sum_{k=0..n} C(n, k) \cdot  a^(n-k) \cdot  b^k
$$

## 常用特例

- $(1 + 1)^n = 2^n = \Sigma  C(n, k)$。
- $(1 - 1)^n = 0$（n>0），即组合数奇偶项和相等。

## 示例：求二项式系数行

```c++
#include <bits/stdc++.h>
using namespace std;
int main() {
    int n = 5; vector<int> c(n+1, 0); c[0] = 1;
    for (int i=1;i<=n;++i) for (int k=i;k>=1;--k) c[k] += c[k-1];
    for (int x : c) cout << x << ' ';   // 1 5 10 10 5 1
    return 0;
}
```
