# 牛顿插值

## 思想

用差商（divided differences）构造插值多项式：

$$
P(x) = f[x0] + f[x0,x1](x-x0) + f[x0,x1,x2](x-x0)(x-x1) + …
$$

相比拉格朗日，新增一个点时只需多算一项，便于在线扩展。
