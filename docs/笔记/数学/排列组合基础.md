# 排列组合基础

## 概念

- **排列** `P(n, k) = n! / (n−k)!`：从 n 个取 k 个排成一列。
- **组合** `C(n, k) = n! / (k!·(n−k)!)`：从 n 个取 k 个组成集合（不计顺序）。

## 实现

```c++
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

ll fact(int n) { ll r = 1; for (int i=2;i<=n;++i) r *= i; return r; }

ll P(int n, int k) { return fact(n) / fact(n - k); }
ll C(int n, int k) { return fact(n) / fact(k) / fact(n - k); }

int main() {
    cout << C(5, 2) << ' ' << P(5, 2) << '\n';   // 10 20
    return 0;
}
```

## 性质

- `C(n, k) = C(n, n−k)`，`C(n, k) = C(n−1, k) + C(n−1, k−1)`。

## 小结

| 记号 | 含义 |
| --- | --- |
| `P(n,k)` | 排列数 |
| `C(n,k)` | 组合数 |
