# 拉格朗日插值

## 思想

已知 `n+1` 个点 `(xi, yi)`，可唯一确定一个 `n` 次多项式。插值公式：

$$
P(x) = \sum_{i} yi \cdot  \prod_{j\ne i} (x - xj) / (xi - xj)
$$

## 实现（x 为连续整数 0..n 时）

```c++
#include <bits/stdc++.h>
using namespace std;
using ll = long long;
const ll MOD = 1000000007;
ll qpow(ll a, ll b){ ll r=1%MOD; a%=MOD; while(b){ if(b&1)r=r*a%MOD; a=a*a%MOD; b>>=1; } return r; }

// 已知 f(0..n)=y[0..n]，求 f(k)
ll lagrange(vector<ll>& y, ll k) {
    int n = y.size()-1; ll ans = 0;
    vector<ll> pre(n+1,1), suf(n+1,1);
    for (int i=1;i<=n;++i) pre[i]=pre[i-1]*(k-i+1)%MOD;
    for (int i=n-1;i>=0;--i) suf[i]=suf[i+1]*(k-i-1)%MOD;
    for (int i=0;i<=n;++i) {
        ll num = pre[i]*suf[i]%MOD;
        ll den = qpow((ll)i*(i-n)%MOD, MOD-2);
        ans = (ans + y[i]*num%MOD*den) % MOD;
    }
    return (ans%MOD+MOD)%MOD;
}

int main() { vector<ll> y={1,1,2,6}; cout << lagrange(y, 5) << '\n'; return 0; }  // f(x)=x!? 示意
```
