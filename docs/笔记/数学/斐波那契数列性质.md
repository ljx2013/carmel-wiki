# 斐波那契数列性质

## 定义与性质

$F(0)=0, F(1)=1, F(n)=F(n-1)+F(n-2)$。常用性质：

- 矩阵快速幂求第 `n` 项（见「矩阵快速幂」）。
- $\\\\gcd  (F(a), F(b)) = F(\\\\gcd  (a,b))$。
- 卡西尼恒等式：$F(n+1)\cdot F(n-1) - F(n)^2 = (-1)^n$。

## 实现

```c++
#include <bits/stdc++.h>
using namespace std;
using ll = long long;
ll fib(ll n) {
    ll a=0, b=1;
    for (ll i=0;i<n;++i) { ll c=(a+b); a=b; b=c; }
    return a;
}
int main() { cout << fib(10) << '\n'; return 0; }  // 55
```
