# 多重集排列组合

## 内容

若共 `n` 个元素，分为 `k` 类，各类数量 `a1..ak`（Σai = n），则不同排列数为：

```
n! / (a1! · a2! · … · ak!)
```

## 示例

```c++
#include <bits/stdc++.h>
using namespace std;
using ll = long long;
ll fact(int n){ ll r=1; for(int i=2;i<=n;++i) r*=i; return r; }

int main() {
    // "AABBC"：5 个字母，A×2 B×2 C×1
    ll ans = fact(5) / (fact(2) * fact(2) * fact(1));
    cout << ans << '\n';   // 30
    return 0;
}
```

## 小结

| 公式 | 含义 |
| --- | --- |
| `n! / ∏ ai!` | 多重集全排列 |
