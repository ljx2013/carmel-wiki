# 浮点误差与精度

## 要点

- `double` 约 15-16 位有效数字，比较时用 `fabs(a-b) < eps`。
- 大数相减会损失精度；涉及判等优先用整数/分数。
- 计算几何常用 $eps = 1e-9$ 或仅用 `<`/`>` 尽量避免判等。

## 示例

```c++
#include <bits/stdc++.h>
using namespace std;
const double EPS = 1e-9;
int main() {
    double a = 0.1*3, b = 0.3;
    cout << (fabs(a-b) < EPS) << '\n';   // 1（认为相等）
    return 0;
}
```
