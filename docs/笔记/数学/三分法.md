# 三分法（求单峰极值）

## 思想

对定义域上的**单峰**函数（先增后减或先减后增），用两个三分点收缩区间求极值。

```c++
#include <bits/stdc++.h>
using namespace std;
double f(double x){ return -(x-3)*(x-3)+5; }   // 峰值在 x=3
int main() {
    double l=0, r=10;
    for (int i=0;i<100;++i) {
        double m1 = l + (r-l)/3, m2 = r - (r-l)/3;
        if (f(m1) < f(m2)) l = m1; else r = m2;
    }
    printf("%.4f\n", f((l+r)/2));
    return 0;
}
```
