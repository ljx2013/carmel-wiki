# 置换群

## 概念

置换即 `1..n` 到自身的双射。置换可分解为不相交轮换的乘积。置换复合、求逆构成群。

## 实现（轮换分解）

```c++
#include <bits/stdc++.h>
using namespace std;
int main() {
    int p[] = {2,3,1,5,4};   // 1->2->3->1, 4->5->4
    int n=5, vis[6]={0}, cycles=0;
    for (int i=1;i<=n;++i) if(!vis[i]) {
        ++cycles; for(int x=i;!vis[x];x=p[x-1]) vis[x]=1;
    }
    cout << cycles << '\n';   // 2 个轮换
    return 0;
}
```

| 操作 | 说明 |
| --- | --- |
| 轮换分解 | 不相交轮换之积 |
