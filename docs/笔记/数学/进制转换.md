# 进制转换

## 方法

- `n` 转 `k` 进制：反复 `n % k` 取余、`n /= k`。
- `k` 进制转十进制：按位加权求和。

## 实现

```c++
#include <bits/stdc++.h>
using namespace std;
string to_base(int n, int k) {
    if (n==0) return "0";
    string s; while (n) { s += char('0' + n%k); n /= k; }
    reverse(s.begin(), s.end()); return s;
}
int main() { cout << to_base(255, 16) << '\n'; return 0; }  // "ff"
```
