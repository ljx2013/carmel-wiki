# 幂法（求主特征向量）

## 思想

对矩阵 `A` 反复乘向量 $v \leftarrow  A\cdot v$ 并归一化，向量会趋于绝对值最大的特征值对应的特征向量。

## 实现（示意，浮点）

```c++
#include <bits/stdc++.h>
using namespace std;
int main() {
    // A=[[2,1],[1,2]]，主特征值3，特征向量(1,1)
    double v[2]={1,0};
    for (int it=0;it<100;++it) {
        double nv[2] = {2*v[0]+v[1], v[0]+2*v[1]};
        double s = nv[0]+nv[1]; v[0]=nv[0]/s; v[1]=nv[1]/s;
    }
    cout << v[0] << ' ' << v[1] << '\n';   // 趋于 0.5 0.5
    return 0;
}
```
