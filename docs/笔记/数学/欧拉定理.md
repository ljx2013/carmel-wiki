# 欧拉定理

## 内容

若 `gcd(a, m) = 1`，则：

```
a^φ(m) ≡ 1 (mod m)
```

当 `m` 为质数时退化为**费马小定理** `a^(m−1) ≡ 1 (mod m)`。

## 应用：指数取模化简

求 `a^b mod m` 时，若 `gcd(a,m)=1`，可把指数对 `φ(m)` 取模：

```
a^b ≡ a^(b mod φ(m))   (mod m)     （gcd(a,m)=1）
```

## 示例

```c++
#include <bits/stdc++.h>
using namespace std;
using ll = long long;
ll phi(ll n){ /* 见「欧拉函数」 */ ll r=n; for(ll i=2;i*i<=n;++i){ if(n%i==0){ r=r/i*(i-1); while(n%i==0)n/=i; } } if(n>1)r=r/n*(n-1); return r; }
ll qpow(ll a, ll b, ll m){ ll r=1%m; a%=m; while(b){ if(b&1)r=r*a%m; a=a*a%m; b>>=1; } return r; }

int main() {
    ll m = 7;
    cout << qpow(3, 100, m) << '\n';                 // 3^100 mod 7
    cout << qpow(3, 100 % phi(m), m) << '\n';       // 指数对 φ(7)=6 取模，结果相同
    return 0;
}
```

## 小结

| 定理 | 条件 |
| --- | --- |
| `a^φ(m) ≡ 1 (mod m)` | `gcd(a,m)=1` |
