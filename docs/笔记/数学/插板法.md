# 插板法（隔板法）

## 思想

把 `n` 个相同元素分成 `k` 个非负/正整数部分，等价于在空隙中插入 `k−1` 块板。

## 公式

- **正整数拆分** `x1+…+xk = n (xi≥1)`：方案数 `C(n−1, k−1)`。
- **非负整数拆分** `xi≥0`：转化为正整数后得 `C(n+k−1, k−1)`。

## 小结

| 情形 | 方案数 |
| --- | --- |
| `xi ≥ 1` | `C(n−1, k−1)` |
| `xi ≥ 0` | `C(n+k−1, k−1)` |
