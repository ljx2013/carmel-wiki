# 卢卡斯数列

## 定义

$L(0)=2, L(1)=1, L(n)=L(n-1)+L(n-2)$。与斐波那契相关：$L(n)=F(n-1)+F(n+1)$。

## 实现

```c++
#include <bits/stdc++.h>
using namespace std;
using ll = long long;
ll lucas(ll n) {
    if (n==0) return 2; if (n==1) return 1;
    ll a=2, b=1;
    for (ll i=2;i<=n;++i) { ll c=(a+b); a=b; b=c; }
    return b;
}
int main() { cout << lucas(10) << '\n'; return 0; }  // 123
```
