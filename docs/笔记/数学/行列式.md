# 行列式

## 定义与性质

方阵 `A` 的行列式 `det(A)`：三角化后为主对角线乘积；交换两行变号；某行倍加不变。

## 实现（高斯消元求行列式）

```c++
#include <bits/stdc++.h>
using namespace std;
const int N = 105;
double a[N][N];
double det(int n) {
    double res = 1;
    for (int c=0;c<n;++c) {
        int r = c; for (int i=c;i<n;++i) if (fabs(a[i][c])>fabs(a[r][c])) r=i;
        if (fabs(a[r][c])<1e-9) return 0;
        if (r!=c) { swap(a[r],a[c]); res = -res; }
        for (int i=c+1;i<n;++i) {
            double t = a[i][c]/a[c][c];
            for (int j=c;j<n;++j) a[i][j] -= t*a[c][j];
        }
        res *= a[c][c];
    }
    return res;
}
int main() {
    int n=2; a[0][0]=1;a[0][1]=2;a[1][0]=3;a[1][1]=4;
    cout << det(n) << '\n';   // -2
    return 0;
}
```
