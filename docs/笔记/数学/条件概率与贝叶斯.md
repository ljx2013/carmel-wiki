# 条件概率与贝叶斯

## 定义

$P(A\mid B) = P(A\cap B) / P(B)$。乘法公式：$P(A\cap B) = P(A)P(B\mid A)$。

## 贝叶斯公式

$$
P(A\mid B) = P(B\mid A)\cdot P(A) / P(B)
$$
