# 生成函数入门

## 思想

把数列 `{a_n}` 写成形式幂级数 $F(x) = \Sigma  a_n x^n$，用代数运算（乘法、求逆、开方）转化组合计数问题。

## 常见母函数

- 常数序列：$1 + x + x^2 + … = 1/(1-x)$。
- 斐波那契：$F(x) = x / (1 - x - x^2)$。
- 组合选取：$(1+x)^n = \Sigma  C(n,k) x^k$。

## 示例：无限硬币凑面值的方案数

```c++
// 用 1/2/5 凑 n 元：生成函数 1/((1-x)(1-x^2)(1-x^5))
// 实际用 DP 更常见：dp[0]=1; for v in {1,2,5} for i=v..n dp[i]+=dp[i-v];
#include <bits/stdc++.h>
using namespace std;
int main() {
    int n = 10; vector<int> dp(n+1, 0); dp[0] = 1;
    for (int v : {1, 2, 5}) for (int i=v;i<=n;++i) dp[i] += dp[i-v];
    cout << dp[n] << '\n';
    return 0;
}
```
