# 线性同余方程

## 形式

求解 $a\cdot x \equiv  b (\bmod  m)$，即 $a\cdot x - b$ 是 `m` 的倍数。

## 解法

等价于 $a\cdot x + m\cdot y = b$。用 exgcd 求 $\\\\gcd  (a, m) = g$：
- 若 `g ∤ b`，无解。
- 否则有 `g` 个模 `m` 不同解：$x = (x0\cdot b/g) \bmod  (m/g) + k\cdot (m/g)$，k=0..g−1。

```c++
#include <bits/stdc++.h>
using namespace std;

long long exgcd(long long a, long long b, long long &x, long long &y) {
    if (!b) { x = 1; y = 0; return a; }
    long long g = exgcd(b, a % b, y, x); y -= a / b * x; return g;
}

// 返回解的个数，并把一个解存入 x0；无解返回 0
long long solve(long long a, long long b, long long m, long long &x0) {
    a %= m; b = (b % m + m) % m;
    long long x, y, g = exgcd(a, m, x, y);
    if (b % g) return 0;
    x0 = (x * (b / g) % (m / g) + m / g) % (m / g);
    return g;
}

int main() {
    long long x0;
    cout << solve(4, 6, 10, x0) << ' ' << x0 << '\n';  // 2 4  (4,9 两解)
    return 0;
}
```
