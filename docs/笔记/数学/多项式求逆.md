# 多项式求逆

## 问题

给定多项式 `A(x)`，求 `B(x) ≡ A(x)⁻¹ (mod x^n)`，即 `A·B ≡ 1 (mod x^n)`。

## 倍增法

已知 `B0 ≡ A⁻¹ (mod x^{⌈n/2⌉})`，则：

```
B ≡ B0 · (2 − A·B0)   (mod x^n)
```

用 NTT 做乘法，每次长度翻倍，总复杂度 `O(n log n)`。

## 小结

| 公式 | `B = B0(2 − A·B0)` |
| --- | --- |
