# 高斯消元法

## 思想

用行变换把线性方程组的系数矩阵化为上三角（或最简形），回代求解。常用于解 `Ax = b`、求秩、求逆。

```c++
#include <bits/stdc++.h>
using namespace std;
const int N = 105;
double a[N][N];

// 解 n 元方程组，返回 1/0/-1 表示唯一解/无解/无穷解；解存入 x
int gauss(int n, double x[]) {
    int r = 0;
    for (int c = 0; c < n; ++c) {
        int piv = r;
        for (int i = r; i < n; ++i) if (fabs(a[i][c]) > fabs(a[piv][c])) piv = i;
        if (fabs(a[piv][c]) < 1e-9) continue;
        swap(a[r], a[piv]);
        for (int i = 0; i < n; ++i) if (i != r) {
            double t = a[i][c] / a[r][c];
            for (int j = c; j <= n; ++j) a[i][j] -= t * a[r][j];
        }
        ++r;
    }
    for (int i = r; i < n; ++i) if (fabs(a[i][n]) > 1e-9) return 0;  // 无解
    for (int i = 0; i < n; ++i) x[i] = a[i][n] / a[i][i];
    return r == n ? 1 : -1;
}

int main() {
    int n = 2; a[0][0]=2; a[0][1]=1; a[0][2]=5;
    a[1][0]=1; a[1][1]=1; a[1][2]=3;
    double x[2]; gauss(n, x);
    cout << x[0] << ' ' << x[1] << '\n';   // 2 1
    return 0;
}
```

## 小结

| 步骤 | 说明 |
| --- | --- |
| 选主元 | 提高数值稳定性 |
| 消元 → 回代 | 得到解 |
