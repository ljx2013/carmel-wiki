# 计算几何基础

## 要点

- 用 `struct Point { double x, y; }` 表示点。
- 叉积 $cross(a,b) = ax\cdot by - ay\cdot bx$：正表示 a 在 b 逆时针方向，负为顺时针，0 共线。
- 比较与判等用 `eps`。
