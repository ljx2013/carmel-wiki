# 加法

## 加法的定义

加法（addition）是最基本的二元算术运算，表示把两个或多个数量合并成一个总量的过程，记作 `+`。

- 运算数称为**加数**（addend），结果称为**和**（sum）。
- 在集合论中，加法可以理解为两个不相交集合的元素个数相加（基数运算），即 $\mid A \cup  B\mid  = \mid A\mid  + \mid B\mid $（当 $A \cap  B = ∅$）。
- 加法满足**交换律** $a + b = b + a$ 与**结合律** $(a + b) + c = a + (b + c)$，还满足单位元性质 $a + 0 = a$。

## 皮亚诺公理

皮亚诺公理（Peano Axioms）用五条公理严格定义了自然数 $ℕ = {0, 1, 2, …}$ 与后继函数 $S(n) = n + 1$，并在此基础上递归地定义加法：

1. `0` 是一个自然数。
2. 每一个自然数 `n` 都有唯一的后继 `S(n)`，且 `S(n)` 也是自然数。
3. `0` 不是任何自然数的后继，即不存在 `n` 使 $S(n) = 0$。
4. 若 $S(a) = S(b)$，则 $a = b$（后继函数单射）。
5. 归纳公理：若一个性质对 `0` 成立，且假设它对 `n` 成立时可推出对 `S(n)` 也成立，则该性质对所有自然数成立。

基于后继函数，加法递归定义为：

$$
a + 0     = a
a + S(b)  = S(a + b)
$$

例如 `2 + 3` 的推导过程：

$$
2 + 3
= 2 + S(2)
= S(2 + 2)
= S(2 + S(1))
= S(S(2 + 1))
= S(S(2 + S(0)))
= S(S(S(2 + 0)))
= S(S(S(2)))
= S(S(3))
= S(4)
= 5
$$

可见，"加 3"本质上就是"连续取 3 次后继"。这正是计算机中"循环 `n` 次自增"的严格数学来源。

## C++ 中的加法

C++ 内置了对基本数值类型的加法运算符 `+`，可直接作用于整数、浮点及指针等类型：

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    int a = 3, b = 5;
    int c = a + b;        // 整数加法，c == 8

    long long x = 1LL << 40;
    long long y = x + x;  // long long 加法

    double p = 1.2, q = 3.4;
    double r = p + q;     // 浮点加法，r == 4.6

    string s = "ab", t = "cd";
    string u = s + t;     // std::string 也重载了 +，拼接得到 "abcd"

    return 0;
}
```

需要注意的几点：

- **溢出**：有符号整数（如 `int`、`long long`）相加超出其表示范围属于未定义行为。例如 `int` 范围约为 $[-2^31, 2^31-1]$。超过范围应使用 `long long` 乃至高精度。
- **无符号回绕**：`unsigned int` 溢出是良定义的，会按模 $2^32$ 回绕（不是报错，而是取余）。
- **运算符重载**：用户自定义类型可通过重载 `operator+` 定义自己的加法语义（详见下文 BigInt 思路）。

## 迭代器与 `++`

在 C++ 标准库中，迭代器（iterator）用于遍历容器。`++` 让迭代器前进到下一个元素，分为两种形式，性能有差别：

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    vector<int> v = {1, 2, 3, 4};

    // 前置 ++：先自增，返回自增后的自身（引用），无临时对象，效率更高
    for (auto it = v.begin(); it != v.end(); ++it) {
        cout << *it << ' ';
    }
    cout << '\n';

    // 后置 ++：先返回自增前的副本，再自增自身（需要一次拷贝）
    auto it = v.begin();
    while (it != v.end()) {
        cout << *it << ' ';
        it++;          // 效果等价，但多一次临时对象拷贝
    }
    return 0;
}
```

要点：

- **前置 `++it`**：返回引用，不创建临时对象，在循环与泛型算法（如 `std::advance`）中通常更优。
- **后置 `it++`**：返回的是自增前的旧值副本，因此内部需要保存副本，开销略大；在 vector 等随机访问迭代器上差异微小，但在 `list`、`set` 等双向/前向迭代器上较明显。
- 遍历容器时**推荐统一使用前置 `++it`**。

## 高精度加法

当参与运算的数超过 `long long`（约 $9.2 \times  10^18$）甚至更大时，需要用"高精度"方式把数字拆成一位或多位一组，用数组/字符串按位存储，模拟竖式加法。

思路：

1. 把两个加数以**字符串**读入，倒序存入 `vector<int>`，个位在下标 `0`。
2. 从低位到高位逐位相加，加上进位 `carry`，本位写 `(sum % 10)`，进位更新为 $sum / 10$。
3. 较长数处理完后，若仍有进位则补上。
4. 结果再倒序输出。

```c++
#include <bits/stdc++.h>
using namespace std;

// 返回 a + b，支持任意长度非负整数（字符串输入）
string addBig(const string &a, const string &b) {
    vector<int> A, B;
    for (int i = (int)a.size() - 1; i >= 0; --i) A.push_back(a[i] - '0');
    for (int i = (int)b.size() - 1; i >= 0; --i) B.push_back(b[i] - '0');

    vector<int> C;
    int carry = 0;
    int n = max(A.size(), B.size());
    for (int i = 0; i < n; ++i) {
        int x = (i < (int)A.size() ? A[i] : 0);
        int y = (i < (int)B.size() ? B[i] : 0);
        int s = x + y + carry;
        C.push_back(s % 10);   // 本位
        carry = s / 10;        // 进位
    }
    if (carry) C.push_back(carry);

    string res;
    for (int i = (int)C.size() - 1; i >= 0; --i) res += char(C[i] + '0');
    return res;
}

int main() {
    string a = "123456789012345678901234567890";
    string b = "987654321098765432109876543210";
    cout << addBig(a, b) << '\n';   // 1111111110111111111011111111100
    return 0;
}
```

- 时间复杂度：$O(\\\\max  (\mid a\mid , \mid b\mid ))$。
- 可扩展到"压位"存储（每位存 $10^4$ 或 $10^8$）以减少位数、提升效率。
- 负数、小数、乘法、比较等可在此基础上扩展为完整的高精度类。

## BigInt（大整数）

C++ **标准库没有内置的大整数类型**，需要自行封装或借助扩展/第三方库。常见做法：

1. **`__int128`**（GCC / Clang 扩展）：128 位整数，范围约 $[-1.7\times 10^38, 1.7\times 10^38]$，可直接用 `+` 运算，但 $cin/cout$ 不支持，需手写输入输出。
   
   ```c++
   #include <bits/stdc++.h>
   using namespace std;
   // __int128 不能直接 cin/cout，可用 to_string 风格手写打印
   void print(__int128 x) {
       if (x < 0) { putchar('-'); x = -x; }
       if (x > 9) print(x / 10);
       putchar(char(x % 10 + '0'));
   }
   int main() {
       __int128 a = (__int128)1e18 * (__int128)1e18;  // 远超 long long
       print(a); putchar('\n');
       return 0;
   }
   ```

2. **`std::vector<int>` 封装**：即上面"高精度加法"所用的底层结构，进一步封装成 `BigInt` 类，重载 `operator+`、`operator*`、比较、赋值等，即可得到任意精度整数。竞赛中常现场实现加法/乘法，不必引入库。

3. **Python 的任意精度整数**：Python 的 `int` 原生支持任意大小（`a + b` 自动高精度），做实验或验证大数结果非常方便。

4. **第三方库**：如 Boost.Multiprecision 的 `cpp_int`（$#include <boost/multiprecision/cpp_int.hpp>$，`using boost::multiprecision::cpp_int;`）可在工程中使用。

> 竞赛场景：优先用自己写的高精度（vector 按位存）或用 `__int128`；工程场景可用 Boost.Multiprecision。

## 快速加法（二进制拆分 + 加法）

普通的"把 `a` 累加 `b` 次"需要 `O(b)` 步。利用"快速幂"的同款倍增思想，把 `b` 按二进制拆成 $2^k$ 的和，用 `a` 自身翻倍（每次 `O(1)`）来构造 $2^k\cdot a$，从而把 `a` 加 `b` 次降到 `O(log b)` 次加法。

最常见的应用是**模意义下的快速乘**（quick multiply）：在计算 `(a * b) % mod` 时，若 `a`、`b` 接近 `mod` 量级，`a * b` 会溢出 `long long`，于是把乘法拆成"二进制加法"并边加边取模，避免中间溢出。

```c++
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

// 计算 (a * b) % mod，保证中间过程不溢出 long long（前提是 a,b,mod < 2^62 左右）
ll mul_mod(ll a, ll b, ll mod) {
    ll res = 0;
    a %= mod; b %= mod;
    while (b) {
        if (b & 1) res = (res + a) % mod;   // 当前二进制位为 1，则累加 a
        a = (a + a) % mod;                  // a 翻倍：a -> 2a
        b >>= 1;                            // 处理下一位
    }
    return res;
}

int main() {
    // 注意用精确整数字面量，避免 1e18 作为 double 不精确带来的误差
    const ll mod = 1000000000000000007LL;  // 10^18 + 7
    ll a = 1000000007LL, b = 1000000009LL;
    cout << mul_mod(a, b, mod) << '\n';    // 16000000056
    return 0;
}
```

要点：

- 把"加 `b` 次 `a`"变成"按 `b` 的二进制位，对 $2^k\cdot a$ 求和"，步数 `O(log b)`。
- 取模版本可安全计算两个大数之积对大模数取模而不溢出。
- 若编译器支持 `__int128`，也可直接 `(ll)(((__int128)a * b) % mod)`，更简洁；快速乘主要用于不保证 `__int128` 可用或模数极大（接近 $2^63$）的场合。
