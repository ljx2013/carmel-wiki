# 第二类斯特林数

## 定义

`S(n, k)` 表示把 `n` 个不同元素划分成 `k` 个**非空无序**集合的方案数。

## 递推

```
S(n, k) = k·S(n−1, k) + S(n−1, k−1)
S(n, 0) = [n=0], S(n, n) = 1
```

含义：第 `n` 个元素单独成集合，或并入已有的 `k` 个集合之一。

## 实现

```c++
#include <bits/stdc++.h>
using namespace std;
using ll = long long;
int main() {
    ll S[20][20] = {};
    S[0][0] = 1;
    for (int n=1;n<=10;++n)
        for (int k=1;k<=n;++k)
            S[n][k] = k*S[n-1][k] + S[n-1][k-1];
    cout << S[5][3] << '\n';   // 25
    return 0;
}
```

## 小结

| 公式 | 含义 |
| --- | --- |
| `k·S(n−1,k)+S(n−1,k−1)` | 划分递推 |
