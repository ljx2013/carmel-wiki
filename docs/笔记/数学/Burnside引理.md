# Burnside 引理

## 内容

在群 `G` 作用下，不同轨道（等价类）数为：

$$
N = (1/\mid G\mid ) \cdot  \sum_{g\in G} C(g)
$$

其中 `C(g)` 为被置换 `g` 固定的元素个数。

## 用途

解决染色/摆放的"旋转/翻转等价"计数。
