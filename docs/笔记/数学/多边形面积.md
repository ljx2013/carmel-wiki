# 多边形面积

## 鞋带公式

按顶点顺序，面积 = $½ \mid \Sigma  (x_i\cdot y_{i+1} - x_{i+1}\cdot y_i)\mid $。

```c++
#include <bits/stdc++.h>
using namespace std;
struct P { long long x, y; };
int main() {
    vector<P> v = {{0,0},{4,0},{4,3}};   // 直角三角形
    long long area = 0; int n = v.size();
    for (int i=0;i<n;++i) { int j=(i+1)%n; area += v[i].x*v[j].y - v[j].x*v[i].y; }
    cout << area/2 << '\n';   // 6
    return 0;
}
```
