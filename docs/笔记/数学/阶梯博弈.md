# 阶梯博弈（Staircase Nim）

## 规则

`n` 级台阶，每级有若干石子；每次把某级若干石子移到下一级，不能移动（移出地面）者负。

## 结论

等价于只对**奇数级**（从底向上数）做 Nim：把所有奇数级石子数异或，非 0 则先手胜。因为偶数级的移动可被对手"镜像"抵消。

## 实现

```c++
#include <bits/stdc++.h>
using namespace std;
int main() {
    int s[] = {0, 3, 0, 5, 0, 2};   // 台阶 1..5 的石子数
    int x = 0;
    for (int i=1;i<=5;i+=2) x ^= s[i];   // 奇数级异或
    cout << (x ? "win" : "lose") << '\n';
    return 0;
}
```
