# 错位排列（Derangement）

## 定义

`D(n)` 表示 `1..n` 的全排列中，所有元素都不在原来位置上的排列数（即没有 `i` 落在第 `i` 位）。

## 递推

```
D(0) = 1, D(1) = 0
D(n) = (n − 1) · (D(n−1) + D(n−2))
```

也等于 `n! · Σ_{k=0..n} (−1)^k / k!`（趋近于 `n!/e`）。

## 实现

```c++
#include <bits/stdc++.h>
using namespace std;
using ll = long long;
int main() {
    ll d[15]; d[0]=1; d[1]=0;
    for (int i=2;i<=10;++i) d[i] = (i-1) * (d[i-1] + d[i-2]);
    cout << d[4] << '\n';   // 9
    return 0;
}
```

## 小结

| 项 | 值 |
| --- | --- |
| `D(2)` | 1 |
| `D(3)` | 2 |
| `D(4)` | 9 |
