# 线性变换

## 定义

映射 $T: V\to W$ 满足 $T(u+v)=T(u)+T(v)$、$T(c\cdot v)=c\cdot T(v)$。在给定基下由矩阵表示。

## 与矩阵

线性变换复合对应矩阵乘法；可逆变换对应可逆矩阵。
