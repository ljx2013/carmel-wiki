# 欧拉筛（线性筛）

## 思想

埃氏筛中合数会被多个质数重复标记。欧拉筛保证**每个合数只被它的最小质因子标记一次**，达到线性 `O(n)`。

```c++
#include <bits/stdc++.h>
using namespace std;

const int N = 1000005;
int minp[N];          // 最小质因子
vector<int> primes;

void linear_sieve(int n) {
    for (int i = 2; i <= n; ++i) {
        if (!minp[i]) { minp[i] = i; primes.push_back(i); }
        for (int p : primes) {
            if (p > minp[i] || 1LL * i * p > n) break;  // 关键：只筛到最小质因子为止
            minp[i * p] = p;
        }
    }
}

int main() {
    linear_sieve(30);
    for (int p : primes) cout << p << ' ';
    return 0;
}
```

## 关键

`if (p > minp[i]) break;` 确保 `i*p` 的标记在 `p` 超过 `i` 的最小质因子时停止，避免重复标记。

## 小结

| 项目 | 说明 |
| --- | --- |
| 复杂度 | `O(n)` 线性 |
| 优势 | 每个合数仅标记一次 |
| 附带 | 可顺便求最小质因子 |
