# 快速幂（二进制取幂）

## 思想

把指数 `b` 按二进制拆分，利用 $a^(2k) = (a^k)^2$ 将 $a^b$ 从 `O(b)` 降到 `O(log b)`。

```c++
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

ll qpow(ll a, ll b, ll m) {
    ll res = 1 % m; a %= m;
    while (b) {
        if (b & 1) res = res * a % m;   // 当前位为 1，累乘 a
        a = a * a % m;                  // a -> a^2
        b >>= 1;
    }
    return res;
}

int main() {
    cout << qpow(2, 10, 1000000007) << '\n';   // 1024
    return 0;
}
```

## 注意

- 乘法可能溢出时改用快速乘（见「加法」中的快速加法）。
- `1 % m` 处理 $m=1$ 的边界。
