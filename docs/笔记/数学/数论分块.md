# 数论分块

## 思想

对 $\sum_{i=1..n} \lfloor n/i\rfloor $，$\lfloor n/i\rfloor $ 在一段区间内为常数，可整段求和：`[l, r]` 其中 $r = n/(n/l)$，贡献 $(r-l+1)\cdot \lfloor n/l\rfloor $。复杂度 `O(√n)`。

## 实现

```c++
#include <bits/stdc++.h>
using namespace std;
using ll = long long;
ll sum_floor(ll n) {
    ll ans = 0;
    for (ll l=1, r; l<=n; l=r+1) {
        r = n/(n/l);
        ans += (r - l + 1) * (n / l);
    }
    return ans;
}
int main() { cout << sum_floor(10) << '\n'; return 0; }  // 1..10 的 floor(10/i) 之和 = 27
```
