# 质数与合数

## 基本概念

- **质数（素数）**：大于 1 且只有 1 和自身两个正因数的自然数。2 是唯一的偶质数。
- **合数**：大于 1 且有其他因数的自然数。1 既不是质数也不是合数。
- 若 `n` 是合数，则它必有一个不超过 `√n` 的质因数。

## 试除法判素

```c++
#include <bits/stdc++.h>
using namespace std;

bool isPrime(long long n) {
    if (n < 2) return false;
    for (long long i = 2; i * i <= n; ++i)
        if (n % i == 0) return false;
    return true;
}

int main() {
    for (int x : {2, 97, 100, 101}) cout << x << ' ' << isPrime(x) << '\n';
    return 0;
}
```

## 唯一分解视角

任一大于 1 的整数都可唯一写成若干质数之积（见「唯一分解定理」）。质数分布大致每 `ln n` 出现一个（素数定理）。

## 小结

| 类别 | 例子 | 判定要点 |
| --- | --- | --- |
| 质数 | 2,3,5,7 | 无 `√n` 以内的因子 |
| 合数 | 4,6,8,9 | 存在非平凡因子 |
| 特殊 | 1 | 既非质也非合 |
