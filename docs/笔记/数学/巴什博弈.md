# 巴什博弈（Bash Game）

## 规则

一堆 `n` 个物品，两人轮流取 `1..m` 个，取光者胜。

## 结论

**先手必胜当且仅当 $n \bmod  (m+1) \ne  0$**。因为每轮两人可取总和恰为 `m+1`，先手把余数取走后控场。

## 实现

```c++
#include <bits/stdc++.h>
using namespace std;
int main() {
    int n = 10, m = 3;
    cout << (n % (m+1) ? "first win" : "second win") << '\n';  // 10%4=2 -> first
    return 0;
}
```
