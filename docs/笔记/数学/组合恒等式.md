# 组合恒等式

## 常用恒等式

- 对称性：$C(n,k) = C(n,n-k)$
- 递推：$C(n,k) = C(n-1,k) + C(n-1,k-1)$
- 范德蒙德：$\Sigma  C(r,i)\cdot C(s,k-i) = C(r+s,k)$
- 平方和：$\Sigma  C(n,i)^2 = C(2n,n)$

## 验证范德蒙德

```c++
#include <bits/stdc++.h>
using namespace std;
using ll = long long;
ll C(ll n, ll k){ if(k<0||k>n) return 0; k=min(k,n-k); ll r=1; for(ll i=1;i<=k;++i) r=r*(n-i+1)/i; return r; }
int main() {
    int r=3,s=4,k=4; ll sum=0;
    for (int i=0;i<=k;++i) sum += C(r,i)*C(s,k-i);
    cout << sum << ' ' << C(r+s,k) << '\n';   // 相等
    return 0;
}
```
