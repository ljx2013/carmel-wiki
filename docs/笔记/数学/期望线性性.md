# 期望线性性

## 内容

对任意随机变量 `X, Y`（无论是否独立）：

$$
E[X + Y] = E[X] + E[Y]
E[c\cdot X] = c\cdot E[X]
$$

这是期望 DP 的核心武器：即使变量相关，线性性仍成立。

## 示例：收集所有 n 种卡片的期望次数

```c++
#include <bits/stdc++.h>
using namespace std;
int main() {
    int n = 6; double E = 0;
    for (int i=0;i<n;++i) E += (double)n/(n-i);   // 每阶段等待时间期望 n/(n-i)
    cout << E << '\n';   // 优惠券收集问题
    return 0;
}
```
