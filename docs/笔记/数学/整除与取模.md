# 整除与取模

## 基本概念

- **整除**：若整数 `a` 能被非零整数 `b` 整除，记作 $b \mid  a$，即存在整数 `k` 使 $a = k\cdot b$。
- **取模（模运算）**：`a mod b` 表示 `a` 除以 `b` 的余数，满足 $0 \le  a \bmod  b < \mid b\mid $。
- **同余**：$a \equiv  b (\bmod  m)$ 当且仅当 $m \mid  (a - b)$，即 `a`、`b` 除以 `m` 余数相同。

## C++ 中的取模

C++ 的 `%` 对负数结果符号与被除数相同，做“数学取模”要修正：

```c++
#include <bits/stdc++.h>
using namespace std;

// 保证返回 [0, m) 的非负余数
long long mod(long long a, long long m) {
    return (a % m + m) % m;
}

int main() {
    cout << (-7 % 5) << '\n';        // C++ 原样：-2
    cout << mod(-7, 5) << '\n';      // 修正后：3
    return 0;
}
```

## 常用性质

- $(a + b) \bmod  m = ((a \bmod  m) + (b \bmod  m)) \bmod  m$，乘、减同理（乘需防溢出，用快速乘）。
- 若 $a \equiv  b (\bmod  m)$ 且 $c \equiv  d (\bmod  m)$，则 $a\pm c \equiv  b\pm d$、$a\cdot c \equiv  b\cdot d (\bmod  m)$。
