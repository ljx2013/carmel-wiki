# 整除与取模

## 基本概念

- **整除**：若整数 `a` 能被非零整数 `b` 整除，记作 `b | a`，即存在整数 `k` 使 `a = k·b`。
- **取模（模运算）**：`a mod b` 表示 `a` 除以 `b` 的余数，满足 `0 ≤ a mod b < |b|`。
- **同余**：`a ≡ b (mod m)` 当且仅当 `m | (a − b)`，即 `a`、`b` 除以 `m` 余数相同。

## C++ 中的取模

C++ 的 `%` 对负数结果符号与被除数相同，做“数学取模”要修正：

```c++
#include <bits/stdc++.h>
using namespace std;

// 保证返回 [0, m) 的非负余数
long long mod(long long a, long long m) {
    return (a % m + m) % m;
}

int main() {
    cout << (-7 % 5) << '\n';        // C++ 原样：-2
    cout << mod(-7, 5) << '\n';      // 修正后：3
    return 0;
}
```

## 常用性质

- `(a + b) mod m = ((a mod m) + (b mod m)) mod m`，乘、减同理（乘需防溢出，用快速乘）。
- 若 `a ≡ b (mod m)` 且 `c ≡ d (mod m)`，则 `a±c ≡ b±d`、`a·c ≡ b·d (mod m)`。

## 小结

| 概念 | 记号 / 写法 | 说明 |
| --- | --- | --- |
| 整除 | `b \| a` | a 是 b 的倍数 |
| 取模 | `a % b` | C++ 中负数结果带符号 |
| 同余 | `a ≡ b (mod m)` | 余数相同 |
