# 高斯消元求秩

## 思想

矩阵秩 = 行阶梯形中非零行的个数。对系数矩阵做高斯消元，统计主元个数。

## 实现

```c++
#include <bits/stdc++.h>
using namespace std;
const int N = 105;
double a[N][N];
int mat_rank(int n, int m) {
    int r = 0;
    for (int c=0;c<m;++c) {
        int piv = r; for (int i=r;i<n;++i) if (fabs(a[i][c])>fabs(a[piv][c])) piv=i;
        if (fabs(a[piv][c])<1e-9) continue;
        swap(a[r], a[piv]);
        for (int i=0;i<n;++i) if (i!=r) {
            double t = a[i][c]/a[r][c];
            for (int j=c;j<m;++j) a[i][j] -= t*a[r][j];
        }
        ++r;
    }
    return r;
}
int main() {
    int n=2,m=2; a[0][0]=1;a[0][1]=2;a[1][0]=2;a[1][1]=4;
    cout << mat_rank(n,m) << '\n';   // 1（两行线性相关）
    return 0;
}
```
