# 容斥原理（Inclusion–Exclusion）

## 公式

```
|A1 ∪ … ∪ An| = Σ|Ai| − Σ|Ai∩Aj| + Σ|Ai∩Aj∩Ak| − … + (−1)^(n+1)|∩Ai|
```

求"都不满足"的数量 = 总数 − 至少满足一个。

## 示例：1..n 中与 m 互质的数的个数

```c++
#include <bits/stdc++.h>
using namespace std;
using ll = long long;
ll coprime_cnt(ll n, ll m) {
    vector<ll> p;
    for (ll i=2;i*i<=m;++i) if (m%i==0){ p.push_back(i); while(m%i==0) m/=i; }
    if (m>1) p.push_back(m);
    ll ans = 0;
    for (int s=1;s<(1<<p.size());++s) {
        ll mul=1, bits=0;
        for (int i=0;i<p.size();++i) if (s>>i&1){ mul*=p[i]; ++bits; }
        if (bits&1) ans += n/mul; else ans -= n/mul;
    }
    return n - ans;
}
int main() { cout << coprime_cnt(10, 6) << '\n'; return 0; }  // 与6互质:1,5,7 -> 3 (注意<=10)
```
