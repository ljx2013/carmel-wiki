# Polya 计数定理

## 内容

在 Burnside 基础上，若用 `m` 种颜色染 `n` 个位置，群 `G` 作用，则不同染色数：

$$
N = (1/\mid G\mid ) \cdot  \sum_{g\in G} m^{c(g)}
$$

`c(g)` 为置换 `g` 的轮换个数。
