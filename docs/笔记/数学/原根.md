# 原根

## 定义

对与 `m` 互质的 `g`，若 `g` 模 `m` 的阶为 $\phi (m)$（即 $g^k \bmod  m$ 遍历所有与 `m` 互质余数），称 `g` 为模 `m` 的原根。存在原根当且仅当 $m \in  {2,4,p^k,2p^k}$（p 奇质数）。

## 判定

`g` 是原根 iff 对所有 $\phi (m)$ 的质因子 `q`，$g^{\phi (m)/q} \not\equiv  1 (\bmod  m)$。

## 实现（找最小原根）

```c++
#include <bits/stdc++.h>
using namespace std;
using ll = long long;
ll qpow(ll a, ll b, ll m){ ll r=1%m; a%=m; while(b){ if(b&1)r=r*a%m; a=a*a%m; b>>=1; } return r; }
vector<ll> fac(ll n){ vector<ll> v; for(ll i=2;i*i<=n;++i) if(n%i==0){ v.push_back(i); while(n%i==0) n/=i; } if(n>1) v.push_back(n); return v; }
ll find_primitive(ll m, ll phi_m) {
    auto f = fac(phi_m);
    for (ll g=2; ; ++g) {
        bool ok = true;
        for (ll q : f) if (qpow(g, phi_m/q, m) == 1) { ok=false; break; }
        if (ok) return g;
    }
}
int main() { cout << find_primitive(7, 6) << '\n'; return 0; }  // 3
```
