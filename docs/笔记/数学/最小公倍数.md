# 最小公倍数（lcm）

## 定义与公式

能同时被 `a, b` 整除的正整数中最小者称为 `lcm(a, b)`。与 gcd 的关系：

```
lcm(a, b) = |a · b| / gcd(a, b)
```

## 实现（先除后乘防溢出）

```c++
#include <bits/stdc++.h>
using namespace std;

long long gcd(long long a, long long b) { return b ? gcd(b, a % b) : a; }

long long lcm(long long a, long long b) {
    return a / gcd(a, b) * b;   // 先除后乘，避免 a*b 溢出
}

int main() {
    cout << lcm(12, 18) << '\n';  // 36
    return 0;
}
```

## 注意

- 必须先 `/gcd` 再 `*b`，否则 `a*b` 可能溢出 `long long`。
- 多个数的 lcm 同样两两合并。

## 小结

| 公式 | 写法 |
| --- | --- |
| 最小公倍数 | `a / gcd(a,b) * b` |
