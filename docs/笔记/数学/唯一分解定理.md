# 唯一分解定理

## 内容

任一大于 1 的整数 `n` 都可**唯一**写成质数之积：

$$
n = p1^a1 \cdot  p2^a2 \cdot  … \cdot  pk^ak   （p1<p2<…<pk 为质数，ai\ge 1）
$$

这种分解在忽略顺序意义下唯一。

## 分解实现

```c++
#include <bits/stdc++.h>
using namespace std;

vector<pair<long long, int>> factorize(long long n) {
    vector<pair<long long, int>> res;
    for (long long i = 2; i * i <= n; ++i) {
        if (n % i == 0) {
            int c = 0;
            while (n % i == 0) { n /= i; ++c; }
            res.push_back({i, c});
        }
    }
    if (n > 1) res.push_back({n, 1});
    return res;
}

int main() {
    auto f = factorize(360);
    for (auto [p, c] : f) cout << p << '^' << c << ' ';  // 2^3 3^2 5^1
    return 0;
}
```

## 推论

- 约数个数 $d(n) = (a1+1)(a2+1)…(ak+1)$。
- 约数和、欧拉函数等均可由分解推出。
