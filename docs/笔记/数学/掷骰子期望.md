# 掷骰子期望

## 典型题

连续掷公平六面骰，直到出现过所有 6 个面，期望次数 = $6\cdot (1+1/2+…+1/6) \approx  14.7$（优惠券收集，见「期望线性性」）。

## 单面首次出现

掷到特定点数的期望次数 = `6`（几何分布）。
