# 乘法逆元

## 定义

在模 `m` 下，若 $a\cdot x \equiv  1 (\bmod  m)$，称 `x` 为 `a` 的**乘法逆元**，记作 `a⁻¹`。存在当且仅当 $\\\\gcd  (a, m)=1$。

## 求法

- **费马小定理**（m 为质数）：$a⁻¹ \equiv  a^(m-2) (\bmod  m)$。
- **扩展欧几里得**：解 $a\cdot x + m\cdot y = 1$。
- **线性递推**（求 `1..n` 对质数 `p` 的逆元）：

```c++
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

ll qpow(ll a, ll b, ll m){ ll r=1%m; a%=m; while(b){ if(b&1) r=r*a%m; a=a*a%m; b>>=1;} return r; }

ll inv_fermat(ll a, ll p){ return qpow(a, p-2, p); }            // p 为质数

// 线性求 1..n 对质数 p 的逆元
void inv_linear(int n, int p, vector<ll> &inv) {
    inv.resize(n+1); inv[1]=1;
    for (int i=2;i<=n;++i) inv[i] = (ll)(p - p/i) * inv[p%i] % p;
}

int main() {
    cout << inv_fermat(3, 7) << '\n';   // 5  (3*5=15≡1)
    vector<ll> iv; inv_linear(6, 7, iv);
    for (int i=1;i<=6;++i) cout << iv[i] << ' ';
    return 0;
}
```
