# 最大公约数（gcd）

## 定义

整数 `a, b` 的**最大公约数** `gcd(a, b)` 是能同时整除两者的正整数中最大的。约定 $\\\\gcd  (0, a) = \mid a\mid $。

## 欧几里得算法（辗转相除法）

基于 $\\\\gcd  (a, b) = \\\\gcd  (b, a \bmod  b)$：

```c++
#include <bits/stdc++.h>
using namespace std;

long long gcd(long long a, long long b) {
    while (b) { a %= b; swap(a, b); }
    return a;
}

int main() {
    cout << gcd(12, 18) << '\n';   // 6
    cout << gcd(0, 7) << '\n';     // 7
    return 0;
}
```

C++17 起标准库提供 `std::gcd`（头文件 `<numeric>`）。

## 性质

- $\\\\gcd  (a, b) = \\\\gcd  (a, b - a)$。
- 多个数的 gcd 可两两合并：$\\\\gcd  (a, b, c) = \\\\gcd  (\\\\gcd  (a, b), c)$。
