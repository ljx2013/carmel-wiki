# 欧拉函数 φ(n)

## 定义

$\phi (n)$ 表示 `1..n` 中与 `n` 互质的数的个数。例如 $\phi (1)=1$，$\phi (6)=2$（1,5）。

## 公式

由唯一分解 $n = \prod  p_i^a_i$：

$$
\phi (n) = n \cdot  \prod  (1 - 1/p_i)
$$

## 单值求法

```c++
#include <bits/stdc++.h>
using namespace std;

long long phi(long long n) {
    long long res = n;
    for (long long i = 2; i * i <= n; ++i) {
        if (n % i == 0) {
            res = res / i * (i - 1);
            while (n % i == 0) n /= i;
        }
    }
    if (n > 1) res = res / n * (n - 1);
    return res;
}

int main() {
    cout << phi(12) << '\n';   // 4 (1,5,7,11)
    return 0;
}
```

## 性质

- $n = \sum_{d\mid n} \phi (d)$（约数和形式）。
- 积性函数：$\\\\gcd  (a,b)=1 \Rightarrow  \phi (ab)=\phi (a)\phi (b)$。
