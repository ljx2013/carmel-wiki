# 向量运算

## 基本概念

向量可用坐标 `(x, y)` 或数组表示。常见运算：加减、数乘、点积、叉积。

## 实现

```c++
#include <bits/stdc++.h>
using namespace std;

struct Vec { double x, y; };
Vec operator+(Vec a, Vec b){ return {a.x+b.x, a.y+b.y}; }
double dot(Vec a, Vec b){ return a.x*b.x + a.y*b.y; }       // 点积
double cross(Vec a, Vec b){ return a.x*b.y - a.y*b.x; }     // 叉积（2D 标量）

int main() {
    Vec a{1,2}, b{3,4};
    cout << dot(a,b) << ' ' << cross(a,b) << '\n';   // 11 -2
    return 0;
}
```
