# 贝祖定理（Bézout's Identity）

## 内容

存在整数 `x, y` 使 `a·x + b·y = c` 有解的**充要条件是** `gcd(a, b) | c`。

## 求全部解

设 `g = gcd(a, b)`，特解 `(x0, y0)` 由 exgcd 得到（`a·x0 + b·y0 = g`）。则原方程一组特解为 `x = x0·c/g`，`y = y0·c/g`。通解：

```
x = x0·c/g + k·(b/g)
y = y0·c/g − k·(a/g)      (k ∈ ℤ)
```

## 最小正整数 x

```c++
long long exgcd(long long a, long long b, long long &x, long long &y) {
    if (!b) { x = 1; y = 0; return a; }
    long long g = exgcd(b, a % b, y, x); y -= a / b * x; return g;
}
// 求 a·x ≡ c (mod b) 的最小正整数解（特解为 x0，步长 step = b/g）
long long min_pos_x(long long x0, long long step) {
    long long xpos = (x0 % step + step) % step;
    return xpos == 0 ? step : xpos;
}
int main() {
    long long a = 4, b = 10, c = 6;
    long long x, y, g = exgcd(a, b, x, y);
    long long x0 = x * (c / g);
    long long step = b / g;
    cout << min_pos_x(x0, step) << '\n';   // 4（4 与 9 两解）
    return 0;
}
```

## 小结

| 条件 | 结论 |
| --- | --- |
| `gcd(a,b) \| c` | 方程有整数解 |
| 否则 | 无整数解 |
