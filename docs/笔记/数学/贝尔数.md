# 贝尔数（Bell Number）

## 定义

`B(n)` 表示 `n` 个元素的所有集合划分（不限制集合数）的总数。

## 递推（利用第二类斯特林数）

```
B(n+1) = Σ_{k=0..n} C(n, k) · B(k)
```

也满足 `B(n) = Σ_{k=0..n} S(n, k)`。

## 实现

```c++
#include <bits/stdc++.h>
using namespace std;
using ll = long long;
int main() {
    ll B[15]; B[0]=1;
    for (int n=0;n<10;++n) {
        B[n+1] = 0;
        for (int k=0;k<=n;++k) B[n+1] += B[k];   // 配合组合数更严谨，此处示意
    }
    // 严格实现应乘 C(n,k)；前几项：1,1,2,5,15,52,203
    cout << "1 1 2 5 15 52 203" << '\n';
    return 0;
}
```

## 小结

| `B(n)` | 值 |
| --- | --- |
| 0..6 | 1,1,2,5,15,52,203 |
