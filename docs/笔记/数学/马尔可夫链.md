# 马尔可夫链

## 定义

状态序列满足马尔可夫性：$P(X_{t+1}\mid X_t,…,X_0) = P(X_{t+1}\mid X_t)$。由转移矩阵 `P` 描述。

## 稳态

若链不可约非周期，存在平稳分布 $\pi $ 满足 $\pi  = \pi P$。可用矩阵快速幂求若干步后分布。
