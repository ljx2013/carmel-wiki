# 概率基础

## 概念

- 样本空间 $\Omega $、事件 `A`、`P(A)` 为 A 发生概率，满足 $0 \le  P(A) \le  1$，$P(\Omega )=1$。
- 古典概型：$P(A) = \mid A\mid  / \mid \Omega \mid $（等可能）。
- 加法公式：$P(A\cup B) = P(A)+P(B)-P(A\cap B)$。
