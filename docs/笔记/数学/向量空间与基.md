# 向量空间与基

## 概念

向量空间对加法和数乘封闭。一组**基**是线性无关且能生成整个空间的向量集；基的大小 = 维数。

## 与线性基的关系

OI 中的"线性基"（见「线性基」）即异或空间的一组基，用于快速查询可表出的异或值。
