# 第一类斯特林数

## 定义

`s(n, k)`（有符号）表示把 `n` 个元素排成 `k` 个**轮换（圆排列）**的方案数（带符号）。无符号记为 `c(n,k)`，满足 $c(n,k) = \mid s(n,k)\mid $。

## 递推（无符号）

$$
c(n, k) = (n-1)\cdot c(n-1, k) + c(n-1, k-1)
$$

## 实现

```c++
#include <bits/stdc++.h>
using namespace std;
using ll = long long;
int main() {
    ll c[20][20] = {};
    c[0][0] = 1;
    for (int n=1;n<=10;++n)
        for (int k=1;k<=n;++k)
            c[n][k] = (n-1)*c[n-1][k] + c[n-1][k-1];
    cout << c[5][2] << '\n';   // 50
    return 0;
}
```
