# 威佐夫博弈（Wythoff Game）

## 规则

两堆石子 `(a, b)`，每人可：从一堆取任意多，或从两堆同时取相同多，取光者胜。

## 结论

必败态（奇异局势）为 $(\lfloor k\cdot \phi \rfloor , \lfloor k\cdot \phi \rfloor +k)$，其中 $\phi =(1+\sqrt 5)/2$，$k = \mid a-b\mid $。即 $a = \lfloor (b-a)\cdot \phi \rfloor $ 时为必败。

## 实现

```c++
#include <bits/stdc++.h>
using namespace std;
#include <cmath>
int main() {
    int a = 3, b = 5; if (a > b) swap(a, b);
    int k = b - a;
    int lose = (int)(k * (1 + sqrt(5)) / 2.0);
    cout << (lose == a ? "lose" : "win") << '\n';  // (3,5): k=2 lose=3 -> lose
    return 0;
}
```
