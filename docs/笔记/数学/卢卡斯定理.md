# 卢卡斯定理（Lucas）

## 内容

当 `p` 为质数时：

$$
C(n, m) \bmod  p = C(n \bmod  p, m \bmod  p) \cdot  C(\lfloor n/p\rfloor , \lfloor m/p\rfloor ) \bmod  p
$$

用于求大 `n,m` 的组合数模质数。

## 实现

```c++
#include <bits/stdc++.h>
using namespace std;
using ll = long long;
const ll MOD = 1000003;
ll qpow(ll a, ll b){ ll r=1%MOD; a%=MOD; while(b){ if(b&1)r=r*a%MOD; a=a*a%MOD; b>>=1; } return r; }
ll C(ll n, ll m){ if(m<0||m>n) return 0; m=min(m,n-m); ll r=1; for(ll i=1;i<=m;++i) r=r*(n-i+1)%MOD*qpow(i,MOD-2)%MOD; return r; }
ll lucas(ll n, ll m){ if(m==0) return 1; return C(n%MOD,m%MOD)*lucas(n/MOD,m/MOD)%MOD; }
int main() { cout << lucas(1000000, 500000) << '\n'; return 0; }
```
