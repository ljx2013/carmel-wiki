# 莫比乌斯反演

## 莫比乌斯函数 μ

由唯一分解：若 `n` 含平方因子则 `μ(n)=0`；否则 `μ(n) = (−1)^k`（k 为不同质因子个数）。满足 `Σ_{d|n} μ(d) = [n=1]`。

## 反演公式

若 `F(n) = Σ_{d|n} f(d)`，则 `f(n) = Σ_{d|n} μ(d)·F(n/d)`。

## 实现（线性筛 μ）

```c++
#include <bits/stdc++.h>
using namespace std;
const int N = 100005;
int mu[N], minp[N]; vector<int> primes;
void sieve(int n) {
    mu[1] = 1;
    for (int i=2;i<=n;++i) {
        if (!minp[i]) { minp[i]=i; primes.push_back(i); mu[i]=-1; }
        for (int p : primes) { if (p>minp[i] || 1LL*i*p>n) break; minp[i*p]=p; mu[i*p] = (minp[i]==p)?0:-mu[i]; }
    }
}
int main() { sieve(20); for (int i=1;i<=10;++i) cout << mu[i] << ' '; cout << '\n'; return 0; }
```
