# 费马小定理

## 内容

若 `p` 为质数且 `p ∤ a`，则：

```
a^(p−1) ≡ 1 (mod p)
```

等价地，`a^p ≡ a (mod p)`（对任意 `a`）。

## 用途

- **求逆元**：`a⁻¹ ≡ a^(p−2) (mod p)`（见「乘法逆元」）。
- **素数测试**：不满足 `a^(p−1)≡1` 的 `p` 必为合数（逆命题不绝对成立）。

## 示例

```c++
#include <bits/stdc++.h>
using namespace std;
using ll = long long;
ll qpow(ll a, ll b, ll m){ ll r=1%m; a%=m; while(b){ if(b&1)r=r*a%m; a=a*a%m; b>>=1; } return r; }

int main() {
    ll p = 7;
    cout << qpow(2, p-1, p) << '\n';   // 1
    cout << qpow(3, p-2, p) << '\n';   // 3 在模 7 下的逆元 = 5
    return 0;
}
```

## 小结

| 结论 | 条件 |
| --- | --- |
| `a^(p-1) ≡ 1 (mod p)` | `p` 质数，`p∤a` |
