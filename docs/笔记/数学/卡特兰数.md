# 卡特兰数（Catalan）

## 定义

$$
Cat(0) = 1
Cat(n) = \sum_{i=0..n-1} Cat(i)\cdot Cat(n-1-i) = C(2n, n) / (n+1)
$$

前几项：1, 1, 2, 5, 14, 42, 132, 429。

## 典型应用

- `n` 对括号的合法匹配数。
- 二叉树形态数、出栈序列数、`n+1` 个叶子的满二叉树数。
