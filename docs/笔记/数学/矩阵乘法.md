# 矩阵乘法

## 定义

`C = A × B`，其中 `C[i][j] = Σ_k A[i][k] · B[k][j]`。要求 A 的列数 = B 的行数。不满足交换律，满足结合律。

## 实现（模 MOD）

```c++
#include <bits/stdc++.h>
using namespace std;
using ll = long long;
const ll MOD = 1000000007;

using Mat = vector<vector<ll>>;
Mat mul(const Mat &A, const Mat &B) {
    int n = A.size(), m = B[0].size(), k = B.size();
    Mat C(n, vector<ll>(m, 0));
    for (int i=0;i<n;++i) for (int u=0;u<k;++u) for (int j=0;j<m;++j)
        C[i][j] = (C[i][j] + A[i][u]*B[u][j]) % MOD;
    return C;
}

int main() {
    Mat A = {{1,2},{3,4}}, B = {{0,1},{1,0}};
    Mat C = mul(A, B);
    cout << C[0][0] << ' ' << C[0][1] << '\n';   // 2 1
    return 0;
}
```

## 小结

| 性质 | 说明 |
| --- | --- |
| 结合律 | `(AB)C = A(BC)` |
| 不交换 | `AB ≠ BA` |
