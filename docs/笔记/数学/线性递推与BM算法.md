# 线性递推与 Berlekamp–Massey

## 问题

给定序列前若干项，求最短的线性递推式 $a_n = \Sigma  c_i \cdot  a_{n-i}$，并快速求第 `n` 项（结合多项式取模 + 快速幂）。

## 要点

- BM 算法在 `O(k^2)` 内求出长度为 `k` 的递推系数。
- 用多项式模递推式 + 倍增快速幂在 `O(k^2 log n)` 求第 `n` 项。
