# 模线性方程组（扩展 CRT）

## 问题

求解不一定互质的同余方程组：

$$
x \equiv  a1 (\bmod  m1)
x \equiv  a2 (\bmod  m2)
$$

## 两两合并

把前两个方程合并为一个 $x \equiv  A (\bmod  M)$：
由 $x = a1 + k\cdot m1 = a2 + t\cdot m2$ 得 $k\cdot m1 - t\cdot m2 = a2 - a1$，用 exgcd 求解，合并后 $M = \operatorname{\operatorname{lcm} } (m1, m2)$。

```c++
#include <bits/stdc++.h>
using namespace std;
using ll = long long;
ll exgcd(ll a, ll b, ll &x, ll &y){ if(!b){x=1;y=0;return a;} ll g=exgcd(b,a%b,y,x); y-=a/b*x; return g; }

// 合并 x≡a1(mod m1) 与 x≡a2(mod m2)；成功返回 true，结果写入 a1,m1
bool merge(ll &a1, ll &m1, ll a2, ll m2) {
    ll k, t, g = exgcd(m1, m2, k, t);
    if ((a2 - a1) % g) return false;
    ll M = m1 / g * m2;
    k = (k % (m2/g) + m2/g) % (m2/g);
    a1 = (a1 + k * (a2 - a1) / g % M + M) % M;
    m1 = M;
    return true;
}

int main() {
    ll a = 2, m = 3;
    merge(a, m, 3, 5);
    merge(a, m, 2, 7);
    cout << a << ' ' << m << '\n';   // 23 105
    return 0;
}
```
