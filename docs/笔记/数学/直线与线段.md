# 直线与线段

## 要点

- 线段相交判定：两线段互相跨越对方（`cross` 异号）。
- 交点：参数方程联立。

## 实现（叉积判方向）

```c++
#include <bits/stdc++.h>
using namespace std;
struct P { double x, y; };
double cross(P a, P b){ return a.x*b.y - a.y*b.x; }
bool intersect(P a, P b, P c, P d) {
    auto dir = [](P p, P q, P r){ return cross({q.x-p.x,q.y-p.y},{r.x-p.x,r.y-p.y}); };
    double d1 = dir(c,d,a), d2 = dir(c,d,b), d3 = dir(a,b,c), d4 = dir(a,b,d);
    return ((d1>0)^(d2>0)) && ((d3>0)^(d4>0));   // 互相跨越
}
int main() { P a{0,0},b{2,2},c{0,2},d{2,0}; cout << intersect(a,b,c,d) << '\n'; return 0; }
```
