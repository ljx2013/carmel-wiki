# 抽屉原理（鸽巢原理）

## 内容

把 `n+1` 个物体放入 `n` 个抽屉，必有至少一个抽屉含 ≥2 个物体。

推广：放 `m` 个物体到 `n` 个抽屉（`m>n`），必有抽屉含 $\lceil m/n\rceil $ 个。

## 典型应用

- 任意 `n+1` 个 `1..2n` 的整数中必有两个互质。
- 长度为 `n+1` 的序列必有长度为 `n` 的单调子序列（Erdős–Szekeres）。
