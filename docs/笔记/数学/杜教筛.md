# 杜教筛

## 思想

求积性函数 `f` 的前缀和 `S(n) = Σ_{i≤n} f(i)`。若找到 `g` 使 `f*g = h` 好求，则：

```
S(n) = (Σ_{i=1..n} h(i) − Σ_{i=2..n} g(i)·S(⌊n/i⌋)) / g(1)
```

对 `⌊n/i⌋` 分块递归，小范围预处理，复杂度 `O(n^{2/3})`。

## 示例（求 μ 前缀和）

```c++
#include <bits/stdc++.h>
using namespace std;
using ll = long long;
const int N = 1000005;
ll smu[N]; int mu[N]; bool ok[N];
unordered_map<ll,ll> M;
ll get_mu(ll n) {
    if (n < N) return smu[n];
    if (M.count(n)) return M[n];
    ll r = 1;
    for (ll l=2, r2; l<=n; l=r2+1) { r2 = n/(n/l); r -= (r2-l+1)*get_mu(n/l); }
    return M[n] = r;
}
int main() {
    // 预处理 smu[1..N-1] 见「莫比乌斯反演」
    cout << get_mu(1000000000LL) << '\n';
    return 0;
}
```

## 小结

| 复杂度 | `O(n^{2/3})` |
| --- | --- |
