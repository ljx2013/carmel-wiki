# 哈希与多项式哈希

## 多项式哈希

把字符串 `s` 看作多项式 `Σ s_i · b^i`，模 `MOD` 求哈希。常用双模数防碰撞。

```c++
#include <bits/stdc++.h>
using namespace std;
using ll = long long;
const ll MOD = 1000000007, B = 131;
ll poly_hash(const string& s) {
    ll h = 0; for (char c : s) h = (h * B + c) % MOD; return h;
}
int main() {
    // 滚动哈希：H[i] = (H[i-1]*B + s[i]) % MOD，子串哈希可 O(1) 求
    cout << poly_hash("abc") << '\n';
    return 0;
}
```
