# 威尔逊定理

## 内容

`p` 为质数 **当且仅当**：

```
(p − 1)! ≡ −1 ≡ p − 1   (mod p)
```

即合数 `n>4` 时恒有 `(n−1)! ≡ 0 (mod n)`。

## 应用

可作为质数判定的理论依据（但阶乘计算代价大，实际少用）。

## 推论：模质数下的逆元

对任意 `1 ≤ k ≤ p−1`，有 `k⁻¹ ≡ −(p−1)! / k ≡ (p−1)! · k⁻¹`，更直接地用线性递推求逆元更高效（见「乘法逆元」）。

## 小结

| 结论 | 等价条件 |
| --- | --- |
| `(p-1)! ≡ -1 (mod p)` | `p` 是质数 |
