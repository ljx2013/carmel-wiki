# 矩阵求逆

## 思想

把 $[A \mid  I]$ 增广矩阵做行变换化为 $[I \mid  A⁻¹]$（高斯消元）。要求 A 可逆（$\\\\det   \ne  0$）。

## 实现（浮点 2×2 示意）

```c++
#include <bits/stdc++.h>
using namespace std;
// 2x2 逆：A⁻¹ = (1/det)·[[d,-b],[-c,a]]
int main() {
    double a=1,b=2,c=3,d=4;
    double det = a*d - b*c;
    double ia = d/det, ib = -b/det, ic = -c/det, id = a/det;
    cout << ia << ' ' << ib << ' ' << ic << ' ' << id << '\n';
    return 0;
}
```

通用做法：对 $n\times 2n$ 增广矩阵高斯消元，消成 $[I\mid A⁻¹]$。
