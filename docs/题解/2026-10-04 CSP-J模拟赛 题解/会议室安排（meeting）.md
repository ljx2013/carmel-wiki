# 会议室安排（meeting）题解

## 题目描述

小 T 要为学校安排 $n$ 场会议。第 $i$ 场会议在时刻 $s_i$ 开始、时刻 $t_i$ 结束。

同一间会议室在同一时刻最多只能进行一场会议；如果一场会议在时刻 $t$ 结束，另一场会议可以在时刻 $t$ 开始并使用同一间会议室（即「结束」与「开始」发生在同一时刻时不冲突）。

请计算：要保证所有会议都能按时进行，最少需要多少间会议室？

## 输入格式

从文件 `meeting.in` 中读入数据。

第一行一个正整数 $n$，表示会议场数。

接下来 $n$ 行，每行两个正整数 $s_i\ t_i$，用一个空格分隔，表示一场会议的开始时刻与结束时刻。

## 输出格式

输出到文件 `meeting.out` 中。

一行一个整数，表示最少需要的会议室数量。

### 样例 1 输入

    3
    1 3
    2 4
    3 5

### 样例 1 输出

    2

### 样例 1 解释

时刻 $2\sim3$ 同时进行第 $1$、$2$ 场会议；时刻 $3\sim4$ 同时进行第 $2$、$3$ 场会议。$2$ 间会议室即可满足（例如第 $1$ 间开第 $1$、$3$ 场，第 $2$ 间开第 $2$ 场）。

### 样例 2 输入

    3
    1 2
    2 3
    3 4

### 样例 2 输出

    1

### 样例 2 解释

三场会议首尾相接，任意时刻都只有一场会议在进行，$1$ 间会议室即可。

### 样例 3 输入

    4
    1 10
    2 3
    3 4
    2 5

### 样例 3 输出

    3

### 样例 3 解释

时刻 $2$ 时第 $1$、$2$、$4$ 场会议同时进行，需要 $3$ 间会议室。

### 样例 4、5 输入

见选手目录下的 `meeting/meeting4.in` 与 `meeting/meeting4.ans`、`meeting/meeting5.in` 与 `meeting/meeting5.ans`。

## 数据范围与测试点

对于所有测试数据，保证：$1 \le n \le 2 \times 10^5$，$1 \le s_i < t_i \le 10^9$。答案不会超过 $n$，在 $32$ 位有符号整数范围内。

| 测试点    | 分值 | 数据范围                    | 特殊性质        |
| ------ | -:| ----------------------- | ----------- |
| $1\sim3$  | $10$ | $n \le 1000$，$s_i,t_i \le 1000$ | 无特殊性质        |
| $4\sim6$  | $10$ | $n \le 5000$             | 无特殊性质        |
| $7\sim8$  | $10$ | $n \le 2 \times 10^5$      | 所有会议时长相同     |
| $9\sim10$ | $10$ | $n \le 2 \times 10^5$      | 无特殊性质        |

## 题解

**问题本质**：最少需要的会议室数，等于「任意时刻同时进行的会议数的最大值」（区间最大重叠数）。因为同一时刻重叠的每一场会议都必须占用一间不同的会议室，而按结束时间贪心分配恰好能用上界那么多间。

**贪心 + 小根堆做法**：

1. 把所有会议按开始时刻 $s_i$ 从小到大排序。
2. 用一个**小根堆**维护「当前各间会议室下一次空闲的时刻」（即每间会议室正在进行的那场会议的结束时刻 $t$）。堆顶是「最早空闲」的会议室。
3. 依次处理每场会议 $i$：
   - 若堆非空且 $s_i \ge$ 堆顶（最早空闲时刻），说明有会议室已经空出来了，直接复用它：`pop` 堆顶；
   - 把当前会议的结束时刻 $t_i$ `push` 进堆（无论是复用旧会议室还是新开一间，都等价于「占用一间会议室直到 $t_i$」）。
4. 堆中元素个数即为同时占用的会议室数，其最终大小就是答案。

为何正确：每个会议都尽量复用最早空闲的会议室，因此使用的会议室数达到理论下界（最大重叠数）。复杂度：排序 $O(n\log n)$ + 堆操作 $O(n\log n)$，完全可过。

代码如下：

```c++
#include<bits/stdc++.h>
#define ll long long
using namespace std;
struct meet{
	int st;
	int ed;
}a[(int)2e5+5];
bool cmp(meet &a,meet &b){
	return a.st<b.st;
}
int n;
priority_queue<int,vector<int>,greater<int>>q;
int main(){
	freopen("meeting.in","r",stdin);
	freopen("meeting.out","w",stdout);
	cin>>n;
	for(int i=1;i<=n;i++){
		meet x;
		cin>>x.st>>x.ed;
		a[i]=x;
	}
	sort(a+1,a+n+1,cmp);
	for(int i=1;i<=n;i++){
		if(!q.empty()&&a[i].st>=q.top()){
			q.pop();
		}
		q.push(a[i].ed);
	}
	cout<<q.size()<<'\n';
	return 0;
}
```
