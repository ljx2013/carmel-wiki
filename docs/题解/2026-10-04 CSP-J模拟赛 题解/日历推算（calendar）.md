# 日历推算（calendar）题解

## 题目描述

小 T 在整理训练日志，需要对日期做推算。他使用格里高利历（公历），规则如下：

- 一年是闰年，当且仅当年份 $y$ 满足：$y$ 能被 $4$ 整除但不能被 $100$ 整除；或者 $y$ 能被 $400$ 整除。
- 闰年的 $2$ 月有 $29$ 天，平年的 $2$ 月有 $28$ 天。
- $1$、$3$、$5$、$7$、$8$、$10$、$12$ 月各有 $31$ 天；$4$、$6$、$9$、$11$ 月各有 $30$ 天。
- 已知 $1$ 年 $1$ 月 $1$ 日是星期一。

现在给定两个日期 $A$（$y_1$ 年 $m_1$ 月 $d_1$ 日）与 $B$（$y_2$ 年 $m_2$ 月 $d_2$ 日），保证 $A$ 不晚于 $B$。请计算：

1. 从日期 $A$ 到日期 $B$ 相差的天数：即恰好经过多少天后，日期 $A$ 会变成日期 $B$（例如 $10$ 月 $1$ 日到 $10$ 月 $3$ 日相差 $2$ 天）；
2. 日期 $B$ 是星期几：用 $1\sim7$ 依次表示星期一～星期日。

## 输入格式

从文件 `calendar.in` 中读入数据。

一行包含六个正整数 $y_1\ m_1\ d_1\ y_2\ m_2\ d_2$，相邻整数之间以一个空格分隔。

## 输出格式

输出到文件 `calendar.out` 中。

一行包含两个整数，用一个空格分隔，依次表示：相差的天数、日期 $B$ 是星期几。

### 样例 1 输入

    2026 10 1 2026 10 3

### 样例 1 输出

    2 6

### 样例 1 解释

$10$ 月 $1$ 日经过 $2$ 天是 $10$ 月 $3$ 日；$2026$ 年 $10$ 月 $3$ 日是星期六，用 $6$ 表示。

### 样例 2 输入

    2024 2 28 2024 3 1

### 样例 2 输出

    2 5

### 样例 2 解释

$2024$ 年是闰年，$2$ 月有 $29$ 天。$2$ 月 $28$ 日经过 $2$ 天是 $3$ 月 $1$ 日；$2024$ 年 $3$ 月 $1$ 日是星期五，用 $5$ 表示。

### 样例 3 输入

    1 1 1 1 1 2

### 样例 3 输出

    1 2

### 样例 3 解释

$1$ 年 $1$ 月 $1$ 日是星期一，因此 $1$ 年 $1$ 月 $2$ 日是星期二，用 $2$ 表示。

## 数据范围与测试点

对于所有测试数据，保证：$1 \le y_1 \le y_2 \le 9999$；所有日期均为合法日期；$A$ 不晚于 $B$。所有答案均在 $32$ 位有符号整数范围内。

| 测试点    | 分值 | 数据范围        | 特殊性质             |
| ------ | -:| ----------- | ---------------- |
| $1\sim2$  | $10$ | $y_2 \le 100$      | 无特殊性质             |
| $3\sim4$  | $10$ | $y_2 \le 1000$     | 无特殊性质             |
| $5\sim6$  | $10$ | $y_2 \le 9999$     | $A$ 与 $B$ 在同一年      |
| $7\sim8$  | $10$ | $y_2 \le 9999$     | $A$ 与 $B$ 相差不超过 $365$ 天 |
| $9\sim10$ | $10$ | $y_2 \le 9999$     | 无特殊性质             |

## 题解

本题核心是「日期 → 绝对天数」的换算：把任意一个日期映射到「距离 $1$ 年 $1$ 月 $1$ 日（记为第 $0$ 天）之前经过的天数」。

设 `days(y,m,d)` 返回日期 $(y,m,d)$ 对应的绝对天数：

- 先累加 $1 \sim y-1$ 每个整年的天数（闰年 $366$、平年 $365$）；
- 再累加 $1 \sim m-1$ 每个整月的天数（注意 $2$ 月是否闰年）；
- 最后加上 $d-1$（因为当月第 $1$ 天对应 $0$ 偏移）。

于是：

1. **相差天数** $= \text{days}(B) - \text{days}(A)$。
2. **星期几**：已知 $1$ 年 $1$ 月 $1$ 日（绝对天数 $0$）是星期一（用 $1$ 表示）。绝对天数每增加 $1$，星期顺移 $1$ 位，因此 $B$ 的星期 $= (\text{days}(B) \bmod 7) + 1$。
   - 校验：样例 $3$ 中 $1$ 年 $1$ 月 $2$ 日绝对天数 $1$，$(1\bmod 7)+1=2$（星期二），与输出一致。

由于 $y\le 9999$，单次换算约 $O(y)\approx 10^4$，加上只有一组询问，时间完全够用（如需更稳也可预处理年份/月份前缀和做到 $O(1)$）。

代码如下：

```c++
#include<bits/stdc++.h>
#define ll long long
using namespace std;
int month[]={0,31,28,31,30,31,30,31,31,30,31,30,31};
bool runyear(int year){
	return ((year%4==0&&year%100!=0)||(year%400==0));
}
int riqi(int y,int m){
	if(m==2&&runyear(y)) return 29;
	return month[m];
}
ll days(int y,int m,int d){
	ll days=0;
	for(int i=1;i<y;i++){
		days+=(runyear(i)?366:365);
	}
	for(int i=1;i<m;i++){
		days+=riqi(y,i);
	}
	days+=d-1;
	return days;
}
int main(){
	freopen("calendar.in","r",stdin);
	freopen("calendar.out","w",stdout);
	int y1,m1,d1,y2,m2,d2;
	cin>>y1>>m1>>d1>>y2>>m2>>d2;
	ll st=days(y1,m1,d1);
	ll ed=days(y2,m2,d2);
	cout<<ed-st<<' ';
	int z=(ed%7)+1;
	cout<<z<<'\n';
	return 0;
}
```
