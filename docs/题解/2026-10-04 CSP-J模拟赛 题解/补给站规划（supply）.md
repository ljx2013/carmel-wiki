# 补给站规划（supply）题解

## 题目描述

马拉松赛道全长 $L$ 米，起点位于 $0$ 米处，终点位于 $L$ 米处。赛道上设有 $n$ 个补给站，第 $i$ 个补给站距离起点 $d_i$ 米，满足 $0 < d_1 < d_2 < \dots < d_n < L$。

由于预算不足，需要撤掉至多 $m$ 个补给站（也可以一个都不撤）。撤站之后，运动员将依次经过起点、留下的补给站和终点，相邻两个经过点之间的距离有一个最小值。

请你设计撤站方案，使这个最小距离尽可能大，并输出这个最大值。

## 输入格式

从文件 `supply.in` 中读入数据。

第一行三个正整数 $L\ n\ m$，用一个空格分隔，分别表示赛道长度、补给站数量、最多可撤掉的补给站数量。

第二行 $n$ 个正整数 $d_1\ d_2\ \dots\ d_n$，表示各补给站距离起点的距离，严格递增，相邻整数之间以一个空格分隔。

## 输出格式

输出到文件 `supply.out` 中。

一行一个整数，表示「相邻经过点距离的最小值」的最大可能值。

### 样例 1 输入

    10 3 1
    2 5 9

### 样例 1 输出

    2

### 样例 1 解释

撤掉距离 $9$ 米的补给站后，经过点为 $0$、$2$、$5$、$10$，相邻距离依次为 $2$、$3$、$5$，最小值为 $2$。可以证明不存在最小值大于 $2$ 的方案（例如不撤站时相邻距离为 $2$、$3$、$4$、$1$，最小值为 $1$）。

### 样例 2 输入

    100 2 2
    30 60

### 样例 2 输出

    100

### 样例 2 解释

把两个补给站都撤掉，运动员只经过起点和终点，最小距离为 $100$。

### 样例 3 输入

    10 3 0
    3 6 9

### 样例 3 输出

    1

### 样例 3 解释

$m=0$，不能撤站，经过点为 $0$、$3$、$6$、$9$、$10$，相邻距离为 $3$、$3$、$3$、$1$，最小值为 $1$。

### 样例 4、5 输入

见选手目录下的 `supply/supply4.in` 与 `supply/supply4.ans`、`supply/supply5.in` 与 `supply/supply5.ans`。

## 数据范围与测试点

对于所有测试数据，保证：$1 \le n \le 5 \times 10^5$，$0 \le m \le n$，$1 \le L \le 10^9$，$1 \le d_i < L$ 且 $d_1 < d_2 < \dots < d_n$。答案不超过 $L$，在 $32$ 位有符号整数范围内。

| 测试点        | 分值  | 数据范围                  | 特殊性质         |
| ---------- | ---:| --------------------- | ------------ |
| $1\sim4$   | $5$ | $n \le 10$            | 无特殊性质        |
| $5\sim8$   | $5$ | $n \le 1000$          | 无特殊性质        |
| $9\sim12$  | $5$ | $n \le 5 \times 10^5$ | $m=1$        |
| $13\sim16$ | $5$ | $n \le 5 \times 10^5$ | 相邻补给站之间的距离相等 |
| $17\sim20$ | $5$ | $n \le 5 \times 10^5$ | 无特殊性质        |

## 题解

**问题转化**：要求「相邻距离的最小值」尽可能大，且最多撤 $m$ 个站。这是一个典型的「最大化最小值」问题，用**二分答案 + 贪心判定**。

设当前二分到的候选值为 $x$，判定函数 $f(x)$ 返回：在「相邻经过点距离都 $\ge x$」的约束下，**至少需要撤掉多少个补给站**（若无法做到则撤掉数会超过 $m$）。

**贪心判定 $f(x)$**（从左到右扫描，尽量保留站点以最小化撤站数）：

- 维护上一个**保留点**的位置 `sum`（初始为起点 $0$）。
- 把终点 $L$ 也作为必须保留的经过点（下标 $n+1$）。
- 对每个点 $d_i$（含终点）：
  - 若 $d_i - sum < x$：与上一个保留点距离不足 $x$，只能**撤掉** $d_i$（撤站数 $+1$），`sum` 保持不变；
  - 否则：可以保留 $d_i$，更新 `sum = d_i`。
- 返回撤站总数。若 $f(x) \le m$，说明 $x$ 可行；否则不可行。

> 直觉：始终保留最左边的点，之后只要某点离上一个保留点 $\ge x$ 就保留它，这样能保留最多的点、撤掉最少的点，是使约束满足的最优贪心策略。

**二分**：答案在 $[0, L]$ 之间。对 `mid` 判定，可行则尝试更大的（`l=mid+1`，记录 `ans=mid`），否则缩小（`r=mid-1`）。最终 `ans` 即为最大可行的最小距离。

复杂度：二分 $O(\log L)$ × 判定 $O(n)$ $= O(n\log L)$，可轻松通过 $n \le 5\times 10^5$。

代码如下：

```c++
#include<bits/stdc++.h>
#define ll long long
using namespace std;
ll L,n,m;
ll d[(int)5e5+5];
ll f(ll x){    ll cnt=0,sum=0;
    for(int i=1;i<=n+1;i++){
        if(d[i]-sum<x) cnt++;
        else{
            sum=d[i];
        }
    }
    return cnt;
}
int main(){
    freopen("supply.in","r",stdin);
    freopen("supply.out","w",stdout);
    ios::sync_with_stdio(0);
    cin.tie(0);
    cout.tie(0);
    cin>>L>>n>>m;
    for(int i=1;i<=n;i++){
        cin>>d[i];
    }
    d[n+1]=L;
    ll l=0,r=L,ans;
    while(l<=r){
        ll mid=(1LL*(l+r))/2;
        if(f(mid)<=m){
            l=mid+1;
            ans=mid;
        }
        else{
            r=mid-1;
        }
    }
    cout<<ans;
    return 0;
}
```
