# 文本编辑器（editor）题解

## 题目描述

小 T 正在开发一个简易文本编辑器。初始时文本为空，光标位于文本的最左端。设当前文本长度为 $len$，文本中的字符位置从左到右依次编号为 $1\sim len$。光标可以位于 $0\sim len$ 之间：光标位置为 $i$，表示光标在第 $i$ 个字符的右侧、第 $i+1$ 个字符的左侧（$i=0$ 表示在所有字符左侧，$i=len$ 表示在所有字符右侧）。

接下来依次执行 $n$ 个操作，操作有以下 $4$ 种：

- **I x**：在光标处插入字符 $x$（$x$ 是一个字符）。插入后 $x$ 的位置为原光标位置 $+1$，光标移动到 $x$ 的右侧；
- **D**：删除光标左侧的第一个字符（即位置恰好为当前光标位置的字符）；若光标位置为 $0$，该操作不做任何改变；
- **L**：光标向左移动一位；若光标位置为 $0$，该操作不做任何改变；
- **R**：光标向右移动一位；若光标位置为 $len$（文本末尾），该操作不做任何改变。

请输出所有操作执行完毕后的完整文本。若最终文本为空，输出一行 `Empty`。

## 输入格式

从文件 `editor.in` 中读入数据。

第一行一个正整数 $n$，表示操作的数量。

接下来 $n$ 行，每行描述一个操作：若为插入操作，格式为 `I x`（`I` 与 $x$ 之间恰好一个空格）；否则为单个大写字母 `D`、`L` 或 `R`。

## 输出格式

输出到文件 `editor.out` 中。

输出一行：所有操作执行完毕后的完整文本；若文本为空，输出 `Empty`。

### 样例 1 输入

    6
    I a
    I b
    L
    I c
    R
    D

### 样例 1 输出

    ac

### 样例 1 解释

依次得到 `a` → `ab` →（光标左移一位）→ `acb` →（光标右移一位）→ 删除 `b` 得到 `ac`。

### 样例 2 输入

    3
    D
    L
    R

### 样例 2 输出

    Empty

### 样例 2 解释

初始文本为空，三个操作均不改变任何内容。

### 样例 3 输入

    6
    I a
    R
    I b
    L
    L
    I c

### 样例 3 输出

    cab

### 样例 4、5 输入

见选手目录下的 `editor/editor4.in` 与 `editor/editor4.ans`、`editor/editor5.in` 与 `editor/editor5.ans`。

## 数据范围与测试点

对于所有测试数据，保证：$1 \le n \le 2 \times 10^5$；$x$ 为小写英文字母。

| 测试点       | 分值   | 数据范围                  | 特殊性质              |
| --------- | ----:| --------------------- | ----------------- |
| $1\sim3$  | $10$ | $n \le 100$           | 无特殊性质             |
| $4\sim6$  | $10$ | $n \le 5000$          | 无特殊性质             |
| $7\sim8$  | $10$ | $n \le 2 \times 10^5$ | 只有 `I` 与 `R` 两种操作 |
| $9\sim10$ | $10$ | $n \le 2 \times 10^5$ | 无特殊性质             |

## 题解

本题是经典的「光标 + 文本」模拟题，用一个字符串维护文本、用一个整数维护光标位置即可。

为方便下标处理，下面代码把字符串开头放一个占位字符（下标从 $1$ 开始），令 `gb` 表示光标**左侧字符的下标**（即光标在第 `gb` 个字符右边）。四种操作对应如下：

- **I x**：在 `gb` 右侧插入 $x$。若 `gb+1` 还在串内，用 `insert(gb+1, x)`；否则追加到末尾；然后 `gb++`（光标右移）。
- **L**：若 `gb>0`，`gb--`。
- **R**：若 `gb+1 < str.size()`（光标未到最后），`gb++`。
- **D**：若 `gb>0`，删除第 `gb` 个字符（`erase(gb,1)`），并 `gb--`。

最后去掉开头的占位字符；若串为空输出 `Empty`，否则输出串。

复杂度：单次操作主要花在 `string` 的 `insert`/`erase` 上，为 $O(len)$。整体最坏 $O(n^2)$，但本题数据下该实现可以通过；若想做到严格 $O(n)$，可改用 `std::list<char>`（链表插入删除 $O(1)$）或 `rope` 维护文本。

代码如下（即本题标准参考实现）：

```c++
#include<bits/stdc++.h>
#define ll long long
using namespace std;
int n,gb=0;
char op;
string x;
string str=" ";
int main(){
    freopen("editor.in","r",stdin);
    freopen("editor.out","w",stdout);
    ios::sync_with_stdio(0);
    cin.tie(0);
    cout.tie(0);
    cin>>n;
    for(int i=1;i<=n;i++){
        cin>>op;
        if(op=='I'){
            cin>>x;
            if(gb+1<str.length()){
                str.insert(gb+1,x);
            }
            else{
                str+=x;
            }
            gb++;
        }
        if(op=='L'){
            if(gb>0){
                gb--;
            }
        }
        if(op=='R'){
            if(gb+1<str.size()){
                gb++;
            }
        }
        if(op=='D'){
            if(gb>0){
                str.erase(gb,1);
                gb--;
            }
        }
    }
    str.erase(0,1);
    if(str.size()==0){
        cout<<"Empty\n";
        return 0;
    }
    cout<<str<<'\n';
    return 0;
}
```
