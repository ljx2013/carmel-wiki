# 幸运号码（lucky）题解

【题目描述】
------

小 L 喜欢收集“幸运号码”。他定义一个正整数 $x$ 是幸运号码，当且仅当同时满足：

1. $x$ 的十进制表示中不含有数字 $4$；
2. $x$ 的各位数字之和是 $3$ 的倍数。

例如 $12$ 是幸运号码（不含 $4$，且 $1+2=3$ 是 $3$ 的倍数），而 $24$ 不是幸运号码（含有数字 $4$），$5$ 也不是幸运号码（$5$ 不是 $3$ 的倍数）。

现在给定两个正整数 $L$ , $R$，请你帮小 L 计算：在 $L∼R$ 中（包含 $L$ 和 $R$）一共有多少个幸运号码。
【输入格式】
------

从文件 $lucky.in$ 中读入数据。

一行包含两个正整数 $L$ , $R$，用一个空格分隔。

## 【输出格式】

输出到文件 $lucky.out$ 中。

输出一行包含一个整数，表示 $L∼R$ 中幸运号码的数量。
【样例 1 输入】
---------

    1 30

【样例 1 输出】
---------

    9

【样例 1 解释】
---------

1∼30 中的幸运号码为 3, 6, 9, 12, 15, 18, 21, 27, 30，共 9 个。注意 24 的各位数字之和 2+4=6 是 3 的倍数，但 24 含有数字 4，因此不是幸运号码。

## 【样例 2 输入】

    4 5

【样例 2 输出】
---------

    0

【样例 2 解释】
---------

4 含有数字 4，5 的各位数字之和 5 不是 3 的倍数，因此区间内一个幸运号码也没有。

## 【样例 3 输入】

    98 102

【样例 3 输出】
---------

    2

【样例 3 解释】
---------

* 98：各位数字之和 9+8=17，不是 3 的倍数；

* 99：不含 4，且 9+9=18 是 3 的倍数，是幸运号码；

* 100：各位数字之和 1，不是 3 的倍数；

* 101：各位数字之和 2，不是 3 的倍数；

* 102：不含 4，且 1+0+2=3 是 3 的倍数，是幸运号码。
  共 2 个。

## 【数据范围】

对于所有测试数据，保证：$1≤L≤R≤10^6$。

| 测试点    | $R$         | 特殊性质  |
| ------ | ----------- | ----- |
| $1∼3$  | $\leq 10^3$ | 无特殊性质 |
| $4∼6$  | $\leq 10^5$ | 无特殊性质 |
| $7∼8$  | $\leq 10^6$ | $L=1$ |
| $9∼10$ | $\leq 10^6$ | 无特殊性质 |

## 【题解】

观察可得，$R_{max} \leq 10^6$ ，因此我们可以将时间复杂度维持在 $O(n)$ 左右即可。

根据题意，本题需要使用数位拆分，数位拆分的复杂度是 $O(\log_{10}n)$ 。

因此最优时间复杂度为 $O(n · \log_{10}n)$。

代码如下：

```c++
#include<bits/stdc++.h>
#define ll long long
using namespace std;
int main(){
    freopen("lucky.in","r",stdin);
    freopen("lucky.out","w",stdout);
    ios::sync_with_stdio(0);
    cin.tie(0);
    cout.tie(0);
    int L,R;
    cin>>L>>R;
    ll ans=0;
    for(int i=L;i<=R;i++){
        int temp=i;
        bool f=0;
        while(temp){
            if(temp%10==4){
                f=1;
                break;
            }
            temp/=10;
        }
        if(!f){
            ans++;
        }
    }
    cout<<ans<<endl;
    return 0;
} 
```
