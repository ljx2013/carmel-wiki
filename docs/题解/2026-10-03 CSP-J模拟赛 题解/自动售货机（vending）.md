# 自动售货机（vending）题解

## 题目描述

小 T 来到了学校新建的全自动无人便利店。便利店的支付系统支持两种代币：普通币（面值 $1$ 元）和高级币（面值 $K$ 元）。

便利店内有两台售货机：一台是零食售货机，出售 $n$ 种零食；另一台是饮料售货机，出售 $m$ 种饮料。零食的编号为 $1 \sim n$，饮料的编号为 $1 \sim m$。

第 $i$ 种零食的价格为 $A_i$ 元，第 $j$ 种饮料的价格为 $B_j$ 元。

在支付规则上，这两台机器有所不同：

- 零食售货机同时接受普通币和高级币的混合支付。
- 饮料售货机只接受高级币支付。

两台售货机的找零机制相同：所有的找零均使用普通币（面值 $1$ 元）退还给买家。

每种特定的零食或饮料，最多只能购买一件。

小 T 现在口袋里有 $X$ 枚普通币和 $Y$ 枚高级币。他希望用手头的这些代币购买尽可能多的商品。

请你帮小 T 计算一下，在最优的购买策略下，他最多能买到多少件商品？

## 输入格式

从文件 $vending.in$ 中读入数据。

第一行包含三个正整数 $n,m,K$，分别表示零食的种类数、饮料的种类数以及高级币的面值。

第二行包含两个非负整数 $X,Y$，分别表示小 T 拥有的普通币数量和高级币数量。

第三行包含 $n$ 个正整数 $A_1,A_2,\dots,A_n$，表示各零食的价格。

第四行包含 $m$ 个正整数 $B_1,B_2,\dots,B_m$，表示各饮料的价格。

## 输出格式

输出到文件 $vending.out$ 中。

输出一行包含一个整数，表示小 T 最多能购买的商品总数。

输入数据 1
------

    2 3 10
    50 6
    22 30
    20 12 24

输出数据 1
------

    4

### 样例 1 解释

初始时，小 T 有 50 枚普通币（面值 1）和 6 枚高级币（面值 10）。 通过以下购买策略，小 T 可以买到 4 件商品：

* 支付 2 枚高级币购买饮料 1（价格 20）。不找零。
* 支付 2 枚高级币购买饮料 2（价格 12）。找回 8 枚普通币。此时小 T 手中有 58 枚普通币和 2 枚高级币。
* 支付 2 枚高级币和 10 枚普通币购买零食 2（价格 30）。不找零。此时小 T 手中有 48 枚普通币和 0 枚高级币。
* 支付 22 枚普通币购买零食 1（价格 22）。不找零。
  
  他最多只能买到 4 件商品，因此答案为 4。

## 题解

## 题意转化

有两类商品：

- **零食**：可以用普通币和高级币混合支付，找零为普通币。
- **饮料**：只能用高级币支付，找零为普通币。

目标是买尽可能多的商品。

## 核心观察

### 1. 买饮料的代价

买第 $j$ 种饮料价格 $B_j$，必须用高级币支付。假设用了 $c = \lceil B_j / K \rceil$ 枚高级币，找零 $cK - B_j$ 元普通币。

所以**买一种饮料的净代价**：

- 消耗高级币 $\lceil B_j / K \rceil$ 枚
- 反而**增加**普通币 $cK - B_j$ 元

### 2. 买零食的代价

零食可以用普通币直接买，也可以用高级币支付后找零。因为普通币和高级币之间的"汇率"是 $1$ 高级币 $= K$ 普通币，所以只要总资产够就能买。因此零食只需要按价格从小到大排序，能用钱买就买。

### 3. 贪心策略

枚举**买多少种饮料**（一定是买最便宜的 $i$ 种，因为每种饮料的"高级币消耗"和"普通币返还"都是固定的，越便宜的组合越省高级币）。

对每种 $i$：

- 计算前 $i$ 种饮料消耗的高级币总数 $gj$ 和返还的普通币总数 $zl$。
- 如果 $gj > Y$，说明买不起了，直接退出。
- 剩余高级币 $sygj = Y - gj$，剩余普通币 $sypt = X + zl$。
- 把这些高级币全部换成普通币：总钱数 $= sypt + sygj \times K$。
- 用这些钱买尽量多的零食（前缀和 + 二分）。
- 更新答案。

代码如下：

```cpp
#include<bits/stdc++.h>
#define ll long long
using namespace std;
ll n,m,k;
ll pt,gj;
ll x,y;
ll a[(int)2e5+5],b[(int)2e5+5];
ll sum[(int)2e5+5];
int main(){
	freopen("vending.in","r",stdin);
	freopen("vending.out","w",stdout);
	ios::sync_with_stdio(0);
	cin.tie(0);
	cout.tie(0);
	cin>>n>>m>>k;
	cin>>x>>y;
	for(int i=1;i<=n;i++){
		cin>>a[i];
	}
	sort(a+1,a+n+1);
	for(int i=1;i<=m;i++){
		cin>>b[i];
	}
	sort(b+1,b+m+1);
	for(int i=1;i<=n;i++){
		sum[i]=sum[i-1]+a[i];
	}
	ll ans=0;
	ll gj=0;
	ll zl=0;
	for(int i=0;i<=m;i++){
		if(i>0){
			ll need=(b[i]+k-1)/k;
			ll zl_=need*k-b[i];
			gj+=need;
			zl+=zl_;
		}
		if(gj>y) break;
		ll sygj=y-gj;
		ll sypt=x+zl;
		ll pos1=sypt+sygj*k;
		ll pos=upper_bound(sum,sum+n+1,pos1)-sum;
		pos--;
		ans=max(ans,(ll)i+pos);
	}
	cout<<ans<<endl;
	return 0;
}
```
