# 序列（seq）题解

# 题目描述

小 L 正在进行一项关于序列的数学研究。

他想让你构造一个正整数序列 $a$，要求满足以下条件：

- 这个序列共有 $n$ 个数，下标从 $1$ 到 $n$。
- 序列所有元素的和恰好为 $m$，即 $\sum_{i=1}^{n} a_i = m$。
- 在满足上述条件的前提下，请你求出下面这个式子的最大值：

$$
\sum_{i=1}^{n} (a_i \bmod k)
$$

# 输入格式

从文件 $seq.in$ 中读入数据。

本题有多组数据。

第一行输入一个整数 $T$，表示测试数据组数，对于每一组数据：

输入包含 $3$ 个正整数 $n,m,k$，相邻整数之间以单个空格分隔。

# 输出格式

输出到文件 $seq.out$ 中。

对于每一组数据：

输出一行包含一个整数，表示题目要求的最大值。

## 输入数据 1

    3 5 3
    3 11 3

输出数据 1
------

    5

### 样例 1 解释

对于第一组数据，可构造出序列 a=[2,1,2]，对其分别取模后求和为 (2mod3)+(1mod3)+(2mod3)=5，可以证明这是能获得的最大值。

## 核心结论

答案分两种情况：

**情况 1：$m \le n(k-1)$**

可以让每个 $a_i$ 都小于 $k$，此时 $a_i \bmod k = a_i$，所以：

$$
\text{ans} = m
$$

**情况 2：$m > n(k-1)$**

让前 $n-1$ 个数都取 $k-1$（取模最大），最后一个数拿走剩下的。设剩余为 $S = m - (n-1)(k-1)$，则：

$$
\text{ans} = (n-1)(k-1) + (S \bmod k)
$$

代码如下：

```c++
#include<bits/stdc++.h>
#define ll long long
using namespace std;
int main(){
	freopen("seq.in","r",stdin);
	freopen("seq.out","w",stdout);
	ios::sync_with_stdio(0);
	cin.tie(0);
	cout.tie(0);
	ll T,n,m,k;
	cin>>T;
	for(int i=1;i<=T;i++){
		cin>>n>>m>>k;
		if(m<=n*(k-1)) cout<<m<<'\n';
		else cout<<(n-1)*(k-1)+((m-(n-1)*(k-1))%k)<<'\n';
	} 
	return 0;
}
```
