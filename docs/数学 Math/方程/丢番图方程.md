# 丢番图方程 Diophantine Equation

丢番图方程（Diophantine Equation）是要求**未知数取整数值**的方程或不等式组，以古希腊数学家丢番图（Diophantus）命名。它是数论的核心研究对象之一，与[裴蜀定理](../../模意义下的数和运算/裴蜀定理%20Bezout%20identity.md)、模运算、整数分解等主题密切相关。

!!! info "丢番图方程 vs 不定方程"
    「丢番图方程」与「不定方程」本质上是同一概念——都是求整数解的方程。在中文数学传统中多用「不定方程」，而西方文献中统称「Diophantine Equation」。本页侧重形式化的理论与算法，更多经典算题见 [不定方程](不定方程.md)。

## 定义

设 $f(x_1, x_2, \ldots, x_n)$ 是整系数多项式，形如

$$f(x_1, x_2, \ldots, x_n) = 0$$

的方程若要求 $x_1, x_2, \ldots, x_n \in \mathbb{Z}$，则称为**丢番图方程**。

常见的分类：

| 类型 | 一般形式 | 示例 |
|------|---------|------|
| 线性 | $a_1 x_1 + a_2 x_2 + \cdots + a_n x_n = c$ | $3x + 5y = 7$ |
| 二次 | $x^2 - Dy^2 = N$ | Pell 方程 $x^2 - 2y^2 = 1$ |
| 高次 | $x^n + y^n = z^n$ | 费马大定理 |
| 指数 | $a^x - b^y = c$ | Catalan 猜想 |

## 线性丢番图方程

### 二元情形

方程 $a x + b y = c$（$a, b, c \in \mathbb{Z}$）有整数解的**充要条件**是：

$$\gcd(a, b) \mid c$$

这正是[裴蜀定理](../../模意义下的数和运算/裴蜀定理%20Bezout%20identity.md)的推论。

#### 求解步骤

1. 令 $d = \gcd(a, b)$，若 $d \nmid c$ 则**无解**。
2. 用扩展欧几里得算法求 $a x_0 + b y_0 = d$ 的一组特解。
3. 令 $k = c / d$，则 $(k x_0,\ k y_0)$ 是原方程的一组特解。
4. **通解**为：

$$
\begin{cases}
x = k x_0 + \dfrac{b}{d} \cdot t \\[6pt]
y = k y_0 - \dfrac{a}{d} \cdot t
\end{cases}, \quad t \in \mathbb{Z}
$$

#### 代码实现

```cpp
long long exgcd(long long a, long long b, long long &x, long long &y) {
    if (b == 0) { x = 1; y = 0; return a; }
    long long d = exgcd(b, a % b, y, x);
    y -= a / b * x;
    return d;
}

// 求 ax + by = c 的通解，返回是否有解
bool solve_linear(long long a, long long b, long long c,
                  long long &x, long long &y, long long &dx, long long &dy) {
    long long x0, y0;
    long long d = exgcd(llabs(a), llabs(b), x0, y0);
    if (c % d != 0) return false;

    long long k = c / d;
    x = k * x0;
    y = k * y0;

    // 处理 a 或 b 为负的情况
    if (a < 0) x = -x;
    if (b < 0) y = -y;

    dx = b / d;  // x 的步长
    dy = a / d;  // y 的步长（注意符号：y 递减）
    return true;
}
```

!!! example "示例"
    求 $3x + 5y = 7$ 的所有整数解。

    $\gcd(3, 5) = 1$，$1 \mid 7$，有解。

    扩展欧几里得：$2 \times 3 + (-1) \times 5 = 1$，即 $x_0 = 2,\ y_0 = -1$。

    乘以 $k = 7$：特解 $x = 14,\ y = -7$。

    通解：

    $$
    \begin{cases}
    x = 14 + 5t \\
    y = -7 - 3t
    \end{cases}, \quad t \in \mathbb{Z}
    $$

### 多元情形

方程 $a_1 x_1 + a_2 x_2 + \cdots + a_n x_n = c$ 有解当且仅当：

$$\gcd(a_1, a_2, \ldots, a_n) \mid c$$

可通过逐对合并求解：先解 $a_1 x_1 + a_2 x_2 = d_2$（$d_2 = \gcd(a_1, a_2)$），再与 $a_3$ 合并，依此类推。

## 非负整数解

在实际问题中，常要求 $x, y \ge 0$。设 $d = \gcd(a, b)$，$a' = a/d$，$b' = b/d$，通解为：

$$
\begin{cases}
x = x_0 + b' t \\
y = y_0 - a' t
\end{cases}
$$

需要 $x \ge 0$ 且 $y \ge 0$，解得 $t$ 的范围：

$$
\left\lceil \frac{-x_0}{b'} \right\rceil \le t \le \left\lfloor \frac{y_0}{a'} \right\rfloor
$$

若区间非空，则非负整数解的个数为：

$$\left\lfloor \frac{y_0}{a'} \right\rfloor - \left\lceil \frac{-x_0}{b'} \right\rceil + 1$$

!!! tip "弗罗贝尼乌斯数"
    当 $\gcd(a, b) = 1$ 时，最大的不能用 $a, b$ 的非负线性组合表示的整数是：

    $$g(a, b) = ab - a - b$$

    例如 $\gcd(3, 5) = 1$，$g(3, 5) = 15 - 3 - 5 = 7$，即 $n \ge 8$ 时 $3x + 5y = n$ 必有非负整数解。

## 佩尔方程

形如 $x^2 - D y^2 = 1$（$D$ 为非完全平方正整数）的丢番图方程称为**佩尔方程**（Pell's Equation）。

### 性质

- 必有无穷多组正整数解。
- 最小正整数解 $(x_1, y_1)$ 称为**基本解**，所有解可由基本解生成。
- 通解满足递推：

$$
\begin{cases}
x_{n+1} = x_1 x_n + D y_1 y_n \\
y_{n+1} = x_1 y_n + y_1 x_n
\end{cases}
$$

等价地，$x_n + y_n \sqrt{D} = (x_1 + y_1 \sqrt{D})^n$。

### 示例

$D = 2$ 时，基本解 $(x_1, y_1) = (3, 2)$（因为 $3^2 - 2 \times 2^2 = 1$）。

前几组解：

| $n$ | $x_n$ | $y_n$ | 验证 |
|-----|-------|-------|------|
| 1 | 3 | 2 | $9 - 8 = 1$ ✓ |
| 2 | 17 | 12 | $289 - 288 = 1$ ✓ |
| 3 | 99 | 70 | $9801 - 9800 = 1$ ✓ |

### 求基本解

基本解可以通过**连分数展开**求得：计算 $\sqrt{D}$ 的连分数表示，其周期为 $k$，则基本解对应第 $k - 1$ 个渐近分数。

```cpp
// 求 x^2 - D*y^2 = 1 的最小正整数解
// 通过连分数法
pair<long long, long long> pell_basic(long long D) {
    long long m = 0, d = 1, a0 = (long long)sqrtl((long double)D);
    long long a = a0;
    // 渐近分数
    long long p_prev = 1, p_curr = a0;
    long long q_prev = 0, q_curr = 1;

    while (true) {
        // 检查 p^2 - D*q^2 == 1
        if (p_curr * p_curr - D * q_curr * q_curr == 1) {
            return {p_curr, q_curr};
        }
        // 下一轮
        m = d * a - m;
        d = (D - m * m) / d;
        a = (a0 + m) / d;
        long long p_next = a * p_curr + p_prev;
        long long q_next = a * q_curr + q_prev;
        p_prev = p_curr; p_curr = p_next;
        q_prev = q_curr; q_curr = q_next;
    }
}
```

!!! warning "注意"
    佩尔方程的基本解可能非常大。例如 $D = 61$ 时基本解为 $x = 1766319049$，$y = 226153980$，需使用大整数。

## 希尔伯特第十问题

1900 年，希尔伯特提出第 23 个问题中的第十问题：

> 给定一个整系数多项式方程，是否存在一个算法能判定它有无整数解？

1970 年，马季亚谢维奇（Matiyasevich）证明了**不存在这样的通用算法**——这即是著名的**不可判定性结果**（MRDP 定理）。

这意味着：丢番图方程的求解在一般情形下是**不可判定的**。但对于特定类型的方程（如线性、二次），仍存在有效的求解方法。

## 例题

!!! example "例题 1：二元线性方程"
    求 $6x + 9y = 21$ 的所有整数解。

    $\gcd(6, 9) = 3$，$3 \mid 21$ ✓。

    解 $6x + 9y = 3$：$2 \times 6 + (-1) \times 9 = 3$，即 $x_0 = 2,\ y_0 = -1$。

    乘以 $k = 7$：$x = 14,\ y = -7$。

    通解：$x = 14 + 3t$，$y = -7 - 2t$（$t \in \mathbb{Z}$）。

!!! example "例题 2：非负解计数"
    用 3 元和 5 元的硬币凑出 47 元，有多少种方案？

    即 $3x + 5y = 47$，$x, y \ge 0$。

    特解：$x_0 = 94,\ y_0 = -47$（由 $2 \times 3 + (-1) \times 5 = 1$ 乘以 47）。

    通解：$x = 94 + 5t$，$y = -47 - 3t$。

    由 $x \ge 0$ 得 $t \ge -18.8$，即 $t \ge -18$；
    由 $y \ge 0$ 得 $t \le -15.67$，即 $t \le -16$。

    $t \in \{-18, -17, -16\}$，共 **3** 种方案。

!!! example "例题 3：佩尔方程"
    求 $x^2 - 3y^2 = 1$ 的最小正整数解。

    $\sqrt{3} \approx 1.732$，连分数 $[1; \overline{1, 2}]$，周期为 2。

    渐近分数：$1/1$，$2/1$，$5/3$，……

    检查 $p_1^2 - 3 q_1^2 = 4 - 3 = 1$ ✓，基本解 $(x_1, y_1) = (2, 1)$。
