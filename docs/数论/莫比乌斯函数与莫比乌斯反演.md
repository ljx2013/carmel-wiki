# 莫比乌斯函数与莫比乌斯反演

莫比乌斯函数（Möbius Function）$\mu(n)$ 是数论中最重要的积性函数之一，与欧拉函数 $\varphi(n)$、约数个数函数 $d(n)$ 等通过**狄利克雷卷积**紧密联系。莫比乌斯反演（Möbius Inversion）是一种强大的求和转换工具——它将「由约数和定义的函数」与「原函数」相互转化，在 gcd 计数、容斥原理、筛法求和、组合计数等问题中有广泛应用。

## 莫比乌斯函数的定义

莫比乌斯函数 $\mu: \mathbb{Z}^+ \to \{-1, 0, 1\}$ 定义如下：

设 $n$ 的标准分解式为 $n = p_1^{\alpha_1} p_2^{\alpha_2} \cdots p_k^{\alpha_k}$，则

$$
\mu(n) =
\begin{cases}
1, & n = 1 \\
(-1)^k, & \alpha_1 = \alpha_2 = \cdots = \alpha_k = 1 \text{（即 $n$ 是 $k$ 个不同素数的乘积）} \\
0, & \text{存在某个 } \alpha_i \ge 2 \text{（即 $n$ 有平方因子）}
\end{cases}
$$

等价地：若 $n$ 含有平方因子则 $\mu(n) = 0$，否则 $\mu(n) = (-1)^{\omega(n)}$，其中 $\omega(n)$ 是 $n$ 的**不同**素因子个数。

!!! example "莫比乌斯函数值表"
    | $n$ | 分解 | $\mu(n)$ | 说明 |
    |-----|------|---------|------|
    | $1$ | $1$ | $1$ | 特殊定义 |
    | $2$ | $2$ | $-1$ | 1 个素因子，无平方 |
    | $3$ | $3$ | $-1$ | 1 个素因子 |
    | $4$ | $2^2$ | $0$ | 有平方因子 $2^2$ |
    | $5$ | $5$ | $-1$ | 1 个素因子 |
    | $6$ | $2 \times 3$ | $1$ | 2 个不同素因子，$(-1)^2 = 1$ |
    | $7$ | $7$ | $-1$ | 1 个素因子 |
    | $8$ | $2^3$ | $0$ | 平方因子 |
    | $9$ | $3^2$ | $0$ | 平方因子 |
    | $10$ | $2 \times 5$ | $1$ | 2 个不同素因子 |
    | $12$ | $2^2 \times 3$ | $0$ | 平方因子 $2^2$ |
    | $30$ | $2 \times 3 \times 5$ | $-1$ | 3 个不同素因子，$(-1)^3 = -1$ |

## 莫比乌斯函数的基本性质

### 性质 1：积性

莫比乌斯函数是**积性函数**：若 $\gcd(a, b) = 1$，则 $\mu(ab) = \mu(a)\mu(b)$。

**证明**：若 $a$ 或 $b$ 有平方因子，则 $ab$ 也有，两边均为 $0$。否则设 $a = \prod p_i$，$b = \prod q_j$（不同素数），则 $ab = \prod p_i \prod q_j$，$\mu(ab) = (-1)^{k+l} = (-1)^k (-1)^l = \mu(a)\mu(b)$。

### 性质 2：莫比乌斯函数的约数和

对任意正整数 $n$，有：

$$
\sum_{d \mid n} \mu(d) = [n = 1] =
\begin{cases}
1, & n = 1 \\
0, & n > 1
\end{cases}
$$

这是莫比乌斯函数最重要的恒等式，也是反演的理论基础。

**证明**：$n = 1$ 时显然。设 $n > 1$ 的标准分解为 $n = \prod_{i=1}^k p_i^{\alpha_i}$。含有平方因子的 $d \mid n$ 使 $\mu(d) = 0$，只需考虑无平方因子的约数，即从 $\{p_1, \ldots, p_k\}$ 中选若干个相乘：

$$
\sum_{d \mid n} \mu(d) = \sum_{S \subseteq \{p_1,\ldots,p_k\}} (-1)^{|S|} = \sum_{t=0}^k \binom{k}{t} (-1)^t = (1 - 1)^k = 0^k = 0
$$

其中使用了二项式定理。

!!! tip "容斥原理的体现"
    这个恒等式本质上是**容斥原理**的生成函数表达：选偶数个素数取正、奇数个取负，恰好相互抵消。

## 莫比乌斯反演

莫比乌斯反演是将函数 $f$ 和其「约数和」$g$ 相互转化的公式。有两种常见形式：约数型和倍数型。

### 约数型反演（除数和形式）

若对任意正整数 $n$，有

$$
g(n) = \sum_{d \mid n} f(d)
$$

则

$$
f(n) = \sum_{d \mid n} \mu(d) \, g\!\left(\frac{n}{d}\right)
$$

等价地（令 $d' = n/d$）：

$$
f(n) = \sum_{d \mid n} \mu\!\left(\frac{n}{d}\right) g(d)
$$

### 倍数型反演（倍数和形式）

若对任意正整数 $n$，有

$$
g(n) = \sum_{n \mid d} f(d)
$$

（即 $g(n)$ 是所有 $n$ 的倍数位置上 $f$ 值的和，通常隐含上限），则

$$
f(n) = \sum_{n \mid d} \mu\!\left(\frac{d}{n}\right) g(d)
$$

倍数型反演在算法竞赛中更常用，特别是结合「枚举倍数」的筛法思路。

### 反演的证明思路（约数型）

$$
\sum_{d \mid n} \mu(d) \, g\!\left(\frac{n}{d}\right)
= \sum_{d \mid n} \mu(d) \sum_{e \mid n/d} f(e)
= \sum_{e \mid n} f(e) \sum_{d \mid n/e} \mu(d)
$$

对固定的 $e$，内层和是 $\sum_{d \mid (n/e)} \mu(d) = [n/e = 1] = [e = n]$。因此只有 $e = n$ 一项非零，整个和等于 $f(n)$。

## 经典应用：求 gcd = k 的对数

### 问题

给定 $n, m$，求满足 $1 \le a \le n,\ 1 \le b \le m$，且 $\gcd(a, b) = k$ 的有序对 $(a, b)$ 的个数。

### 思路

令 $a' = a/k$，$b' = b/k$，则 $\gcd(a, b) = k$ 等价于 $\gcd(a', b') = 1$，且 $1 \le a' \le \lfloor n/k \rfloor$，$1 \le b' \le \lfloor m/k \rfloor$。因此只需解决 $k=1$ 的情况，然后替换 $n, m$ 即可。

设 $f(k)$ 为 $\gcd(a, b) = k$ 的对数，$g(k)$ 为 $k \mid \gcd(a, b)$ 的对数（即 $a, b$ 都是 $k$ 的倍数）。显然：

$$
g(k) = \left\lfloor \frac{n}{k} \right\rfloor \left\lfloor \frac{m}{k} \right\rfloor
$$

并且 $g(k) = \sum_{k \mid d} f(d)$（$\gcd$ 是 $k$ 的倍数等价于等于某个 $d = kt$）。

由**倍数型莫比乌斯反演**：

$$
f(k) = \sum_{k \mid d} \mu\!\left(\frac{d}{k}\right) g(d) = \sum_{t=1}^{\lfloor \min(n,m)/k \rfloor} \mu(t) \left\lfloor \frac{n}{kt} \right\rfloor \left\lfloor \frac{m}{kt} \right\rfloor
$$

特别地，$k = 1$ 时：

$$
f(1) = \sum_{t=1}^{\min(n,m)} \mu(t) \left\lfloor \frac{n}{t} \right\rfloor \left\lfloor \frac{m}{t} \right\rfloor
$$

!!! tip "优化：整除分块"
    注意到 $\lfloor n/t \rfloor$ 的取值只有 $O(\sqrt{n})$ 种不同的值。可以对相同的块用 $\mu$ 的前缀和一次求和，时间复杂度降至 $O(\sqrt{n} + \sqrt{m})$。这是莫比乌斯反演与「整除分块/数论分块」结合的标准套路。

### C++ 实现（线性筛求 μ）

```cpp
#include <vector>
using namespace std;

// 线性筛求莫比乌斯函数，返回 {primes, mu}
pair<vector<int>, vector<int>> sieve_mu(int n) {
    vector<int> mu(n + 1);
    vector<bool> is_prime(n + 1, true);
    vector<int> primes;
    is_prime[0] = is_prime[1] = false;
    mu[1] = 1;
    for (int i = 2; i <= n; i++) {
        if (is_prime[i]) {
            primes.push_back(i);
            mu[i] = -1;  // 素数：一个素因子
        }
        for (int p : primes) {
            if ((long long)p * i > n) break;
            is_prime[p * i] = false;
            if (i % p == 0) {
                // p * i 中 p 的指数 >= 2，有平方因子
                mu[p * i] = 0;
                break;
            } else {
                // p 与 i 互素，新增一个素因子
                mu[p * i] = -mu[i];
            }
        }
    }
    return {primes, mu};
}

// 求 1<=a<=n, 1<=b<=m, gcd(a,b)==1 的对数
long long count_coprime(int n, int m, const vector<int>& mu) {
    if (n > m) swap(n, m);
    vector<long long> premu(m + 1, 0);
    for (int i = 1; i <= m; i++) premu[i] = premu[i-1] + mu[i];
    long long ans = 0;
    for (int l = 1, r; l <= n; l = r + 1) {
        r = min(n / (n / l), m / (m / l));
        ans += (premu[r] - premu[l-1]) * (long long)(n / l) * (m / l);
    }
    return ans;
}
```

## 狄利克雷卷积与函数关系

### 狄利克雷卷积的定义

两个数论函数 $f, g$ 的**狄利克雷卷积**（Dirichlet convolution）定义为：

$$
(f * g)(n) = \sum_{d \mid n} f(d) \, g\!\left(\frac{n}{d}\right)
$$

狄利克雷卷积满足交换律、结合律，且单位元是 $\varepsilon(n) = [n = 1]$。

### 用卷积语言重述

- $\sum_{d \mid n} \mu(d) = [n=1]$ 等价于 $\mu * \mathbf{1} = \varepsilon$，其中 $\mathbf{1}(n) = 1$ 是常值函数。
- 约数型反演：$g = f * \mathbf{1} \iff f = g * \mu$。两边同时卷 $\mu$，由 $\mu * \mathbf{1} = \varepsilon$ 即得。

### 欧拉函数与莫比乌斯函数的关系

欧拉函数满足一个经典的约数和恒等式：

$$
\sum_{d \mid n} \varphi(d) = n
$$

用狄利克雷卷积写就是 $\varphi * \mathbf{1} = \operatorname{id}$，其中 $\operatorname{id}(n) = n$ 是恒等函数。两边卷 $\mu$：

$$
\varphi = \operatorname{id} * \mu
$$

即：

$$
\varphi(n) = \sum_{d \mid n} \mu(d) \cdot \frac{n}{d} = n \sum_{d \mid n} \frac{\mu(d)}{d}
$$

这给出了欧拉函数的另一种表达形式，与标准分解式公式等价。展开验证：

$$
\sum_{d \mid n} \frac{\mu(d)}{d} = \prod_{p \mid n} \left(1 - \frac{1}{p}\right)
$$

因为展开乘积后，每个项对应从每个素因子中选择「取 1 或取 $-1/p$」，恰好对应 $\mu(d)/d$ 对无平方因子约数 $d$ 的求和。

## 例题

!!! example "例题 1：验证 μ 的约数和恒等式"
    验证 $n = 12$ 时 $\sum_{d \mid 12} \mu(d) = 0$。

    **解**：12 的正约数为 $1, 2, 3, 4, 6, 12$。

    $\mu(1) = 1$，$\mu(2) = -1$，$\mu(3) = -1$，$\mu(4) = 0$，$\mu(6) = 1$，$\mu(12) = 0$。

    $\sum_{d \mid 12} \mu(d) = 1 + (-1) + (-1) + 0 + 1 + 0 = 0$ ✓

!!! example "例题 2：gcd = k 的计数"
    求 $1 \le a, b \le 10$ 中满足 $\gcd(a, b) = 2$ 的有序对个数。

    **解**：令 $a = 2a'$，$b = 2b'$，则 $1 \le a', b' \le 5$，需要 $\gcd(a', b') = 1$。

    $f(1) = \sum_{t=1}^5 \mu(t) \lfloor 5/t \rfloor \lfloor 5/t \rfloor$

    | $t$ | $\mu(t)$ | $\lfloor 5/t \rfloor$ | 项 |
    |-----|---------|----------------------|----|
    | $1$ | $1$ | $5$ | $1 \times 25 = 25$ |
    | $2$ | $-1$ | $2$ | $-1 \times 4 = -4$ |
    | $3$ | $-1$ | $1$ | $-1 \times 1 = -1$ |
    | $4$ | $0$ | $1$ | $0 \times 1 = 0$ |
    | $5$ | $-1$ | $1$ | $-1 \times 1 = -1$ |

    合计：$25 - 4 - 1 - 1 = 19$。

    验证：直接枚举 $1 \sim 5$ 中互素对，共有 $19$ 对（如 $(1,1), (1,2), \ldots, (5,4)$ 等）✓

    因此 $\gcd(a, b) = 2$ 的有序对共 **19** 个。

!!! example "例题 3：容斥原理与莫比乌斯反演的等价性"
    设 $S = \{1, 2, \ldots, n\}$，求 $S$ 中与 $m$ 互素的数的个数。

    **方法一（容斥原理）**：设 $m = p_1 p_2 \cdots p_k$（去重），则由容斥：

    $$
    \text{ans} = \sum_{S' \subseteq \{p_1,\ldots,p_k\}} (-1)^{|S'|} \left\lfloor \frac{n}{\prod S'} \right\rfloor
    $$

    **方法二（莫比乌斯函数）**：利用 $\sum_{d \mid \gcd(x, m)} \mu(d) = [\gcd(x, m) = 1]$，

    $$
    \text{ans} = \sum_{x=1}^n [\gcd(x, m) = 1] = \sum_{x=1}^n \sum_{d \mid \gcd(x, m)} \mu(d) = \sum_{d \mid m} \mu(d) \left\lfloor \frac{n}{d} \right\rfloor
    $$

    两者完全等价：因为当 $d$ 有平方因子时 $\mu(d) = 0$，实际求和仅遍历 $m$ 的无平方因子约数，对应容斥中的所有子集 $S'$，而 $\mu(d) = (-1)^{|S'|}$。
