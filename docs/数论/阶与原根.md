# 阶与原根

阶（Order）与原根（Primitive Root）是模乘法群结构理论中的核心概念。阶描述了一个整数在模 $m$ 下的幂次周期性，而原根则是模乘法群的生成元——它的幂次遍历整个既约剩余系。原根的存在性深刻刻画了模 $m$ 乘法群的循环性，是离散对数、Diffie-Hellman 密钥交换、数字签名等密码学协议的理论基础。

## 阶的定义

### 定义

设 $m$ 为正整数，$a$ 为整数且 $\gcd(a, m) = 1$。满足

$$
a^d \equiv 1 \pmod{m}
$$

的**最小正整数** $d$ 称为 $a$ 对模 $m$ 的**阶**（multiplicative order），记作 $\operatorname{ord}_m(a)$。

### 存在条件

阶存在的前提是 $\gcd(a, m) = 1$。这是因为：由 [欧拉定理](欧拉函数.md)，当 $\gcd(a, m) = 1$ 时，$a^{\varphi(m)} \equiv 1 \pmod{m}$，因此满足条件的 $d$ 存在。如果 $\gcd(a, m) = d > 1$，则 $a^k \equiv 1 \pmod{m}$ 两边模 $d$ 得 $0 \equiv 1 \pmod{d}$，矛盾，故阶不存在。

!!! example "阶的计算示例"
    求 $\operatorname{ord}_7(2)$ 和 $\operatorname{ord}_7(3)$。

    - 对 $a = 2, m = 7$，依次计算：
      $2^1 = 2 \not\equiv 1$，$2^2 = 4 \not\equiv 1$，$2^3 = 8 \equiv 1 \pmod{7}$。
      故 $\operatorname{ord}_7(2) = 3$。

    - 对 $a = 3, m = 7$：
      $3^1 = 3$，$3^2 = 2$，$3^3 = 6$，$3^4 = 4$，$3^5 = 5$，$3^6 = 1 \pmod{7}$。
      故 $\operatorname{ord}_7(3) = 6$。

| $a$ | $1$ | $2$ | $3$ | $4$ | $5$ | $6$ |
|-----|-----|-----|-----|-----|-----|-----|
| $\operatorname{ord}_7(a)$ | $1$ | $3$ | $6$ | $3$ | $6$ | $2$ |

## 阶的基本性质

### 性质 1：整除欧拉函数

若 $\gcd(a, m) = 1$，则 $\operatorname{ord}_m(a) \mid \varphi(m)$。

**证明**：设 $d = \operatorname{ord}_m(a)$，由欧拉定理 $a^{\varphi(m)} \equiv 1 \pmod{m}$。将 $\varphi(m)$ 写成 $q \cdot d + r$（$0 \le r < d$），则：

$$
1 \equiv a^{\varphi(m)} = a^{qd + r} = (a^d)^q \cdot a^r \equiv 1^q \cdot a^r = a^r \pmod{m}
$$

若 $r > 0$，则与 $d$ 的最小性矛盾。故 $r = 0$，即 $d \mid \varphi(m)$。

推论：$\operatorname{ord}_m(a)$ 一定是 $\varphi(m)$ 的约数。因此计算阶时，只需枚举 $\varphi(m)$ 的所有正约数，找到最小满足条件的即可。

### 性质 2：$a^k \equiv 1 \pmod{m}$ 当且仅当 $\operatorname{ord}_m(a) \mid k$

**证明**：充分性显然（$a^k = (a^d)^{k/d} \equiv 1$）。必要性与性质 1 类似，利用带余除法和 $d$ 的最小性。

### 性质 3：$a^i \equiv a^j \pmod{m}$ 当且仅当 $i \equiv j \pmod{\operatorname{ord}_m(a)}$

由性质 2，$a^{i-j} \equiv 1$ 当且仅当 $d \mid (i-j)$。这说明 $a$ 的幂序列模 $m$ 是**纯周期**的，周期为 $d$。

### 性质 4：阶的「缩放」

设 $d = \operatorname{ord}_m(a)$，则对任意整数 $k \ge 0$：

$$
\operatorname{ord}_m(a^k) = \frac{d}{\gcd(d, k)}
$$

**证明**：设 $g = \gcd(d, k)$，令 $d = g d'$，$k = g k'$，则 $\gcd(d', k') = 1$。

要找到最小的 $t$ 使得 $(a^k)^t \equiv 1$，即 $a^{kt} \equiv 1$，即 $d \mid kt$，即 $g d' \mid g k' t$，即 $d' \mid k' t$。由于 $\gcd(d', k') = 1$，故 $d' \mid t$。最小的 $t$ 为 $d' = d/g$，即 $\operatorname{ord}_m(a^k) = d / \gcd(d, k)$。

!!! example "性质 4 验证"
    已知 $\operatorname{ord}_7(3) = 6$。求 $\operatorname{ord}_7(3^4)$ 和 $\operatorname{ord}_7(3^2)$。

    - $\operatorname{ord}_7(3^4) = 6 / \gcd(6, 4) = 6 / 2 = 3$。
      验证：$3^4 \equiv 4 \pmod{7}$，$\operatorname{ord}_7(4) = 3$ ✓

    - $\operatorname{ord}_7(3^2) = 6 / \gcd(6, 2) = 6 / 2 = 3$。
      验证：$3^2 \equiv 2 \pmod{7}$，$\operatorname{ord}_7(2) = 3$ ✓

## 原根的定义

### 定义

若 $\operatorname{ord}_m(g) = \varphi(m)$，则称 $g$ 为模 $m$ 的一个**原根**（primitive root）。

等价地说，$g$ 是模 $m$ 的原根当且仅当集合 $\{g^0, g^1, g^2, \ldots, g^{\varphi(m)-1}\}$ 恰好构成模 $m$ 的一个既约剩余系（即每个与 $m$ 互素的数都能唯一表示为 $g$ 的幂）。

**几何直观**：原根 $g$ 生成了模 $m$ 的整个既约剩余乘法群 $(\mathbb{Z}/m\mathbb{Z})^\times$，即该群是**循环群**。

!!! example "模 7 的原根"
    $\varphi(7) = 6$。由上表，$\operatorname{ord}_7(3) = 6 = \varphi(7)$，$\operatorname{ord}_7(5) = 6 = \varphi(7)$。
    因此模 $7$ 的原根是 $3$ 和 $5$。

    验证 $g = 3$：$3^0 \equiv 1, 3^1 \equiv 3, 3^2 \equiv 2, 3^3 \equiv 6, 3^4 \equiv 4, 3^5 \equiv 5$，恰好遍历 $\{1, 2, 3, 4, 5, 6\}$ ✓

## 原根存在的条件

并非对所有 $m$ 都存在原根。模 $m$ 的既约剩余乘法群是循环群（即存在原根）当且仅当 $m$ 为以下情形之一：

$$
m = 2,\quad m = 4,\quad m = p^k,\quad m = 2p^k
$$

其中 $p$ 为奇素数，$k \ge 1$。

| $m$ | $\varphi(m)$ | 是否存在原根 | 原根示例 |
|-----|-------------|------------|---------|
| $2$ | $1$ | 是 | $1$ |
| $3$ | $2$ | 是 | $2$ |
| $4$ | $2$ | 是 | $3$ |
| $5$ | $4$ | 是 | $2, 3$ |
| $6$（$= 2 \times 3$） | $2$ | 是 | $5$ |
| $7$ | $6$ | 是 | $3, 5$ |
| $8$ | $4$ | **否** | — |
| $9$（$= 3^2$） | $6$ | 是 | $2, 5$ |
| $10$（$= 2 \times 5$） | $4$ | 是 | $3, 7$ |
| $12$ | $4$ | **否** | — |
| $16$ | $8$ | **否** | — |

!!! note "模 8 的验证"
    模 $8$ 的既约剩余系是 $\{1, 3, 5, 7\}$，共 $\varphi(8) = 4$ 个数。但：
    - $\operatorname{ord}_8(1) = 1$，$\operatorname{ord}_8(3) = 2$，$\operatorname{ord}_8(5) = 2$，$\operatorname{ord}_8(7) = 2$。
    没有阶为 $4$ 的元素，故模 $8$ 无原根。

## 原根的计数

若模 $m$ 存在原根，则原根的个数为 $\varphi(\varphi(m))$。

**证明**：设 $g$ 为模 $m$ 的一个原根，则所有与 $m$ 互素的数可唯一表示为 $g^k$（$0 \le k < \varphi(m)$）。由阶的缩放性质：

$$
\operatorname{ord}_m(g^k) = \frac{\varphi(m)}{\gcd(\varphi(m), k)}
$$

要求 $\operatorname{ord}_m(g^k) = \varphi(m)$，即需要 $\gcd(\varphi(m), k) = 1$。满足条件的 $k$ 有 $\varphi(\varphi(m))$ 个，对应 $\varphi(\varphi(m))$ 个原根。

!!! example "模 7 的原根个数"
    $\varphi(7) = 6$，故原根个数为 $\varphi(\varphi(7)) = \varphi(6) = 2$（即 $3$ 和 $5$）✓

## 求原根的算法

### 算法步骤

给定模数 $m$（保证存在原根），求最小原根：

1. 计算 $\varphi = \varphi(m)$。
2. 对 $\varphi$ 做质因数分解，得到所有**不同**的素因子：$\varphi = p_1^{\alpha_1} p_2^{\alpha_2} \cdots p_k^{\alpha_k}$。
3. 从小到大枚举 $g = 2, 3, 5, \ldots$：
   - 若 $\gcd(g, m) \neq 1$，跳过；
   - 对每个 $i = 1 \sim k$，检查 $g^{\varphi / p_i} \not\equiv 1 \pmod{m}$；
   - 若所有 $p_i$ 都满足上式，则 $g$ 是原根，返回。

**正确性**：若 $g$ 不是原根，则 $\operatorname{ord}_m(g) < \varphi$。但由性质 1，$\operatorname{ord}_m(g) \mid \varphi$，因此它至少是 $\varphi / p_i$ 中的一个约数，即存在某个 $p_i$ 使得 $g^{\varphi / p_i} \equiv 1 \pmod{m}$。反之，若对所有 $p_i$ 都有 $g^{\varphi / p_i} \not\equiv 1$，则阶不可能是 $\varphi$ 的真约数，只能是 $\varphi$ 本身。

### C++ 实现

```cpp
#include <vector>
#include <algorithm>
using namespace std;
using ll = long long;

ll pow_mod(ll a, ll b, ll mod) {
    ll res = 1; a %= mod;
    while (b) {
        if (b & 1) res = res * a % mod;
        a = a * a % mod;
        b >>= 1;
    }
    return res;
}

ll euler_phi(ll n) {
    ll res = n;
    for (ll p = 2; p * p <= n; p++) {
        if (n % p == 0) {
            while (n % p == 0) n /= p;
            res -= res / p;
        }
    }
    if (n > 1) res -= res / n;
    return res;
}

// 获取 n 的所有不同素因子
vector<ll> get_prime_factors(ll n) {
    vector<ll> res;
    for (ll p = 2; p * p <= n; p++) {
        if (n % p == 0) {
            res.push_back(p);
            while (n % p == 0) n /= p;
        }
    }
    if (n > 1) res.push_back(n);
    return res;
}

// 求模 m 的最小原根（假设存在原根）
ll primitive_root(ll m) {
    if (m == 2) return 1;
    ll phi = euler_phi(m);
    vector<ll> factors = get_prime_factors(phi);
    for (ll g = 2; ; g++) {
        if (__gcd(g, (ll)m) != 1) continue;
        bool ok = true;
        for (ll p : factors) {
            if (pow_mod(g, phi / p, m) == 1) {
                ok = false;
                break;
            }
        }
        if (ok) return g;
    }
}

// 获取模 m 的所有原根
vector<ll> all_primitive_roots(ll m) {
    vector<ll> res;
    ll g = primitive_root(m);
    ll phi = euler_phi(m);
    ll cur = 1;
    for (ll k = 0; k < phi; k++) {
        if (__gcd(k, phi) == 1) {
            res.push_back(cur);
        }
        cur = cur * g % m;
    }
    sort(res.begin(), res.end());
    return res;
}
```

!!! tip "原根的大小"
    实践中，最小原根通常很小。对素数 $p < 10^9$，最小原根几乎不超过 $100$；因此枚举法非常高效。

## 例题

!!! example "例题 1：求阶"
    求 $\operatorname{ord}_{11}(2)$ 和 $\operatorname{ord}_{11}(10)$。

    **解**：
    $\varphi(11) = 10$，其正约数为 $1, 2, 5, 10$。

    - 对 $a = 2$：
      $2^1 = 2 \not\equiv 1$，$2^2 = 4 \not\equiv 1$，$2^5 = 32 \equiv 10 \not\equiv 1$，$2^{10} \equiv 1$。
      故 $\operatorname{ord}_{11}(2) = 10$（因此 $2$ 是模 $11$ 的原根）。

    - 对 $a = 10$：
      $10 \equiv -1 \pmod{11}$，$10^1 \equiv 10$，$10^2 \equiv (-1)^2 = 1 \pmod{11}$。
      故 $\operatorname{ord}_{11}(10) = 2$。

!!! example "例题 2：求模 13 的所有原根"
    **解**：
    $\varphi(13) = 12$，其不同素因子为 $2, 3$。

    找最小原根 $g$：
    - $g = 2$：$2^{12/2} = 2^6 = 64 \equiv 12 \not\equiv 1$，$2^{12/3} = 2^4 = 16 \equiv 3 \not\equiv 1$。
      两个条件都满足！故最小原根为 $2$。

    所有原根对应 $2^k$，其中 $\gcd(k, 12) = 1$，即 $k \in \{1, 5, 7, 11\}$：
    - $2^1 = 2$，$2^5 = 32 \equiv 6$，$2^7 = 128 \equiv 11$，$2^{11} \equiv 7 \pmod{13}$。

    模 $13$ 的全部原根：$\{2, 6, 7, 11\}$（共 $\varphi(12) = 4$ 个）。

!!! example "例题 3：离散对数（BSGS 前置概念）"
    设 $p$ 是素数，$g$ 是模 $p$ 的原根。证明：对任意 $1 \le a \le p-1$，存在唯一的 $0 \le x \le p-2$ 使得 $g^x \equiv a \pmod{p}$。

    这就是离散对数问题（求 $x$），是密码学中许多公钥体系的单向函数基础。

    **证明**：
    **存在性**：因为 $g$ 是原根，$\operatorname{ord}_p(g) = p-1$，所以 $g^0, g^1, \ldots, g^{p-2}$ 是 $p-1$ 个互不同余的数（若 $g^i \equiv g^j$ 则 $g^{i-j} \equiv 1$，由阶的性质必有 $p-1 \mid i-j$，但 $|i-j| < p-1$，故 $i = j$）。它们恰好是模 $p$ 的既约剩余系，因此 $a$ 必等于其中之一。

    **唯一性**：若 $g^{x_1} \equiv a \equiv g^{x_2}$，则 $g^{x_1 - x_2} \equiv 1$。由阶的性质，$p-1 \mid x_1 - x_2$。但 $0 \le x_1, x_2 \le p-2$，故 $x_1 = x_2$。
