# 等比数列

## 一、基本概念

### 1.1 定义

如果一个数列从第二项起，每一项与它的前一项的比等于同一个常数，这个数列就叫做**等比数列**（Geometric Progression, GP）。这个常数叫做等比数列的**公比**，通常用字母 $q$ 表示（$q \neq 0$）。

用数学语言表述为：对于任意正整数 $n \ge 2$，都有
$$\frac{a_n}{a_{n-1}} = q$$
其中 $q$ 为非零常数。

> **注意**：等比数列的所有项都不能为0，因为如果有某一项为0，那么其后一项与该项的比值就无意义了。公比 $q$ 也不能为0。

### 1.2 通项公式

等比数列的通项公式为：
$$a_n = a_1 \cdot q^{n-1}$$

其中：
- $a_1$ 是首项（$a_1 \neq 0$）
- $q$ 是公比（$q \neq 0$）
- $n$ 是项数
- $a_n$ 是第 $n$ 项

> **推导过程**：根据定义，$a_2 = a_1q$，$a_3 = a_2q = a_1q^2$，$a_4 = a_3q = a_1q^3$，以此类推，归纳可得 $a_n = a_1q^{n-1}$。

更一般地，等比数列中任意两项之间的关系为：
$$a_n = a_m \cdot q^{n-m}$$

### 1.3 前 $n$ 项和公式

等比数列的前 $n$ 项和公式需要分情况讨论：

**当 $q \neq 1$ 时**：
$$S_n = \frac{a_1(q^n - 1)}{q - 1} = \frac{a_1(1 - q^n)}{1 - q}$$

**当 $q = 1$ 时**：
此时数列是常数列，$a_n = a_1$，因此：
$$S_n = na_1$$

> **推导过程**（错位相减法）：
> 当 $q \neq 1$ 时，设
> $$S_n = a_1 + a_1q + a_1q^2 + \cdots + a_1q^{n-1} \tag{1}$$
> 两边同乘以 $q$：
> $$qS_n = a_1q + a_1q^2 + a_1q^3 + \cdots + a_1q^n \tag{2}$$
> 用 (1) - (2) 得：
> $$S_n - qS_n = a_1 - a_1q^n$$
> $$S_n(1-q) = a_1(1-q^n)$$
> $$S_n = \frac{a_1(1-q^n)}{1-q} = \frac{a_1(q^n-1)}{q-1}$$

利用 $a_n = a_1q^{n-1}$，前 $n$ 项和也可以表示为：
$$S_n = \frac{a_1 - a_nq}{1-q} \quad (q \neq 1)$$

### 1.4 无穷递缩等比数列的和

当等比数列的公比 $|q| < 1$ 且 $q \neq 0$ 时，数列的项的绝对值会越来越小，趋近于0。此时，前 $n$ 项和 $S_n$ 在 $n \to \infty$ 时存在极限，这个极限叫做**无穷递缩等比数列的各项和**，记为 $S$：

$$S = \lim_{n \to \infty} S_n = \lim_{n \to \infty} \frac{a_1(1-q^n)}{1-q} = \frac{a_1}{1-q}$$

这是因为当 $|q| < 1$ 时，$\lim_{n \to \infty} q^n = 0$。

> **重要应用**：无穷递缩等比数列求和公式是将无限循环小数化为分数的理论基础。

## 二、重要性质

### 2.1 等比中项

如果三个数 $a, G, b$ 成等比数列，那么 $G$ 叫做 $a$ 和 $b$ 的**等比中项**。根据等比数列的定义：
$$\frac{G}{a} = \frac{b}{G} \implies G^2 = ab \implies G = \pm\sqrt{ab}$$

**注意**：
- 两个实数 $a, b$ 存在等比中项的充要条件是 $ab > 0$（即 $a$ 和 $b$ 同号且均不为0）。
- 当 $ab > 0$ 时，$a$ 和 $b$ 有两个互为相反数的等比中项 $\sqrt{ab}$ 和 $-\sqrt{ab}$。
- 两个正数的等比中项的正值称为它们的**几何平均数**，即 $G = \sqrt{ab}$。

### 2.2 下标乘积相等性质

在等比数列中，如果 $m \cdot n = p \cdot q$ 这个结论是错误的！正确的性质是：如果 $m + n = p + r$，那么：
$$a_m \cdot a_n = a_p \cdot a_r$$

**证明**：
$$a_m \cdot a_n = (a_1q^{m-1}) \cdot (a_1q^{n-1}) = a_1^2 q^{m+n-2}$$
$$a_p \cdot a_r = (a_1q^{p-1}) \cdot (a_1q^{r-1}) = a_1^2 q^{p+r-2}$$
因为 $m+n = p+r$，所以两式相等。

特别地，当 $m + n = 2k$ 时，有 $a_m \cdot a_n = a_k^2$，即 $a_k$ 是 $a_m$ 和 $a_n$ 的等比中项（之一）。

### 2.3 等比数列的片段性质

设 $\{a_n\}$ 是公比为 $q$ 的等比数列，则：

1. **等长片段积的关系**：不一定成等比，但有如下性质：
   $$\prod_{i=1}^k a_i, \prod_{i=k+1}^{2k} a_i, \prod_{i=2k+1}^{3k} a_i, \ldots$$
   构成公比为 $q^{k^2}$ 的等比数列。

2. **等长片段和仍成等比（条件）**：当 $q \neq -1$ 或 $k$ 为奇数时，$S_k, S_{2k}-S_k, S_{3k}-S_{2k}, \ldots$ 仍成等比数列，其公比为 $q^k$。

3. **下标成等差的项仍成等比**：$a_m, a_{m+k}, a_{m+2k}, \ldots$ 仍成等比数列，其公比为 $q^k$。

4. **乘积性质**：若 $\{a_n\}, \{b_n\}$ 都是等比数列，则 $\{a_n \cdot b_n\}$ 和 $\left\{\dfrac{a_n}{b_n}\right\}$ 也是等比数列。

### 2.4 循环小数化为分数

利用无穷递缩等比数列求和公式，可以将任何无限循环小数化为分数。

**方法**：将循环小数表示为无穷递缩等比数列的和，然后用公式 $S = \dfrac{a_1}{1-q}$ 计算。

#### 示例1：纯循环小数

将 $0.\dot{7} = 0.7777\cdots$ 化为分数。

$$0.\dot{7} = 0.7 + 0.07 + 0.007 + 0.0007 + \cdots$$

这是首项 $a_1 = 0.7 = \dfrac{7}{10}$，公比 $q = 0.1 = \dfrac{1}{10}$ 的无穷递缩等比数列的和：

$$0.\dot{7} = \frac{a_1}{1-q} = \frac{\frac{7}{10}}{1 - \frac{1}{10}} = \frac{\frac{7}{10}}{\frac{9}{10}} = \frac{7}{9}$$

#### 示例2：混循环小数

将 $0.2\dot{3}\dot{4} = 0.2343434\cdots$ 化为分数。

$$0.2\dot{3}\dot{4} = 0.2 + 0.034 + 0.00034 + 0.0000034 + \cdots$$

其中 $0.034 + 0.00034 + \cdots$ 是首项 $a_1 = 0.034 = \dfrac{34}{1000}$，公比 $q = 0.01 = \dfrac{1}{100}$ 的无穷递缩等比数列：

$$0.2\dot{3}\dot{4} = 0.2 + \frac{\frac{34}{1000}}{1 - \frac{1}{100}} = \frac{1}{5} + \frac{\frac{34}{1000}}{\frac{99}{100}} = \frac{1}{5} + \frac{34}{990} = \frac{198 + 34}{990} = \frac{232}{990} = \frac{116}{495}$$

**通用规则**：
- 纯循环小数：分母由循环位数个9组成，分子为循环节。如 $0.\dot{a_1}a_2\cdots\dot{a_n} = \dfrac{a_1a_2\cdots a_n}{99\cdots9}$（$n$ 个9）
- 混循环小数：分母为循环位数个9后面接非循环位数个0，分子为小数点后所有数字减去非循环部分。如 $0.b_1\cdots b_m\dot{a_1}\cdots\dot{a_n} = \dfrac{b_1\cdots b_ma_1\cdots a_n - b_1\cdots b_m}{99\cdots900\cdots0}$（$n$ 个9，$m$ 个0）

## 三、C++ 实现

### 3.1 等比数列基本运算

```cpp
#include <iostream>
#include <vector>
#include <cmath>
#include <iomanip>
using namespace std;

// 计算等比数列的第n项
long long nthTerm(long long a1, long long q, int n) {
    return a1 * (long long)pow(q, n - 1);
}

// 使用快速幂计算（更精确，处理大指数）
long long power(long long base, int exp) {
    long long result = 1;
    while (exp > 0) {
        if (exp % 2 == 1) result *= base;
        base *= base;
        exp /= 2;
    }
    return result;
}

long long nthTermFast(long long a1, long long q, int n) {
    return a1 * power(q, n - 1);
}

// 计算等比数列前n项和（q != 1）
long long sumGP(long long a1, long long q, int n) {
    if (q == 1) return a1 * n;
    return a1 * (power(q, n) - 1) / (q - 1);
}

// 无穷递缩等比数列和（|q| < 1）
double infiniteSum(double a1, double q) {
    if (fabs(q) >= 1.0) {
        cerr << "警告：|q| >= 1，无穷和发散" << endl;
        return -1;
    }
    return a1 / (1 - q);
}

// 生成等比数列的前n项
vector<long long> generateGP(long long a1, long long q, int n) {
    vector<long long> gp(n);
    gp[0] = a1;
    for (int i = 1; i < n; i++) {
        gp[i] = gp[i-1] * q;
    }
    return gp;
}

// 等比中项（返回正数解）
double geometricMean(double a, double b) {
    if (a * b <= 0) {
        cerr << "错误：ab <= 0，实数范围内不存在等比中项" << endl;
        return -1;
    }
    return sqrt(a * b);
}

// 将纯循环小数化为分数
// input: 循环节字符串，如 "7" 表示 0.777...
void pureRepeatingToFraction(const string& repeat) {
    long long numerator = stoll(repeat);
    long long denominator = 0;
    for (size_t i = 0; i < repeat.size(); i++) {
        denominator = denominator * 10 + 9;
    }
    cout << "0." << string(repeat.size(), repeat[0] == '0' ? '0' : '~');
    cout << " = " << numerator << "/" << denominator << endl;
}

int main() {
    long long a1 = 2, q = 3;
    int n = 6;
    
    cout << "等比数列前6项: ";
    vector<long long> gp = generateGP(a1, q, n);
    for (long long x : gp) cout << x << " ";
    cout << endl;
    
    cout << "第6项 = " << nthTermFast(a1, q, 6) << endl;
    cout << "前6项和 = " << sumGP(a1, q, 6) << endl;
    
    cout << fixed << setprecision(6);
    cout << "无穷递缩等比数列（a1=1, q=0.5）的和 = " << infiniteSum(1.0, 0.5) << endl;
    cout << "4和9的几何平均 = " << geometricMean(4, 9) << endl;
    
    pureRepeatingToFraction("7");
    
    return 0;
}
```

**输出**：
```
等比数列前6项: 2 6 18 54 162 486 
第6项 = 486
前6项和 = 728
无穷递缩等比数列（a1=1, q=0.5）的和 = 2.000000
4和9的几何平均 = 6.000000
0.~~~~~~~ = 7/9
```

## 四、典型例题

### 例题1

**题目**：已知等比数列 $\{a_n\}$ 中，$a_2 = 6$，$a_5 = 162$，求 $a_4$ 和前5项和 $S_5$。

**解答**：

方法一：利用通项公式

由 $a_n = a_1q^{n-1}$，代入已知条件：
$$\begin{cases} a_1q = 6 \quad (1) \\ a_1q^4 = 162 \quad (2) \end{cases}$$

用 (2) ÷ (1) 得：
$$q^3 = \frac{162}{6} = 27 \implies q = 3$$

代入 (1) 得：$a_1 \times 3 = 6 \implies a_1 = 2$

因此：
$$a_4 = a_1q^3 = 2 \times 27 = 54$$
$$S_5 = \frac{a_1(q^5 - 1)}{q - 1} = \frac{2(243 - 1)}{3 - 1} = \frac{2 \times 242}{2} = 242$$

方法二：利用任意两项关系

由 $a_n = a_m q^{n-m}$，得：
$$a_5 = a_2 q^{3} \implies 162 = 6q^3 \implies q^3 = 27 \implies q = 3$$

然后：
$$a_4 = a_5 \cdot q^{-1} = \frac{162}{3} = 54$$

再求 $a_1 = a_2 \cdot q^{-1} = \frac{6}{3} = 2$，进而求出 $S_5 = 242$。

> **答案**：$a_4 = \boxed{54}$，$S_5 = \boxed{242}$

### 例题2

**题目**：等比数列 $\{a_n\}$ 的前 $n$ 项和为 $S_n$，已知 $S_4 = 1$，$S_8 = 4$，求 $a_{17} + a_{18} + a_{19} + a_{20}$。

**解答**：

方法一：基本公式法

设首项为 $a_1$，公比为 $q$，显然 $q \neq 1$（否则 $S_8 = 2S_4$，与题设矛盾）。

$$\begin{cases} \dfrac{a_1(1-q^4)}{1-q} = 1 \quad (1) \\ \dfrac{a_1(1-q^8)}{1-q} = 4 \quad (2) \end{cases}$$

用 (2) ÷ (1) 得：
$$\frac{1-q^8}{1-q^4} = 4 \implies \frac{(1-q^4)(1+q^4)}{1-q^4} = 4 \implies 1+q^4 = 4 \implies q^4 = 3$$

代入 (1) 得：
$$\frac{a_1(1-3)}{1-q} = 1 \implies \frac{-2a_1}{1-q} = 1 \implies \frac{a_1}{1-q} = -\frac{1}{2}$$

要求的是 $a_{17} + a_{18} + a_{19} + a_{20}$，这等于 $S_{20} - S_{16}$：

$$S_{20} - S_{16} = \frac{a_1(1-q^{20})}{1-q} - \frac{a_1(1-q^{16})}{1-q} = \frac{a_1}{1-q}(q^{16} - q^{20})$$

注意 $q^4 = 3$，所以 $q^{16} = (q^4)^4 = 3^4 = 81$，$q^{20} = (q^4)^5 = 3^5 = 243$：

$$S_{20} - S_{16} = -\frac{1}{2} \times (81 - 243) = -\frac{1}{2} \times (-162) = 81$$

方法二：利用片段和性质

等比数列中，$S_k, S_{2k}-S_k, S_{3k}-S_{2k}, \ldots$ 仍成等比数列（$q \neq -1$ 时）。

取 $k = 4$，则：
$$S_4 = 1, \quad S_8 - S_4 = 4 - 1 = 3$$

这个新等比数列的公比为 $\dfrac{3}{1} = 3$。

而 $a_{17} + a_{18} + a_{19} + a_{20} = S_{20} - S_{16}$ 是这个新等比数列的第5项（因为：第1项 $S_4$，第2项 $S_8-S_4$，第3项 $S_{12}-S_8$，第4项 $S_{16}-S_{12}$，第5项 $S_{20}-S_{16}$）：

$$S_{20} - S_{16} = S_4 \times 3^{5-1} = 1 \times 3^4 = 81$$

> **答案**：$\boxed{81}$

### 例题3

**题目**：已知数列 $\{a_n\}$ 满足 $a_1 = 1$，$a_{n+1} = 2a_n + 1$（$n \ge 1$），求通项公式 $a_n$。

**解答**：

这是一个一阶线性递推数列，可以通过构造等比数列来求解。

$$a_{n+1} = 2a_n + 1$$

我们希望将其变形为 $a_{n+1} + c = 2(a_n + c)$ 的形式，展开得：
$$a_{n+1} + c = 2a_n + 2c \implies a_{n+1} = 2a_n + c$$

对比原式 $a_{n+1} = 2a_n + 1$，得 $c = 1$。

因此：
$$a_{n+1} + 1 = 2(a_n + 1)$$

令 $b_n = a_n + 1$，则 $b_{n+1} = 2b_n$，这是一个公比为2的等比数列，且首项为：
$$b_1 = a_1 + 1 = 1 + 1 = 2$$

所以：
$$b_n = b_1 \cdot q^{n-1} = 2 \times 2^{n-1} = 2^n$$

即：
$$a_n + 1 = 2^n \implies a_n = 2^n - 1$$

**验证**：
$n=1$：$a_1 = 2^1 - 1 = 1$ ✓
$n=2$：$a_2 = 2^2 - 1 = 3$，而由递推式 $a_2 = 2a_1 + 1 = 3$ ✓
$n=3$：$a_3 = 2^3 - 1 = 7$，而由递推式 $a_3 = 2a_2 + 1 = 7$ ✓

> **答案**：$a_n = \boxed{2^n - 1}$

## 五、总结

| 内容 | 公式 |
|------|------|
| 通项公式 | $a_n = a_1q^{n-1}$ |
| 通项推广 | $a_n = a_m q^{n-m}$ |
| 前 $n$ 项和（$q \neq 1$） | $S_n = \dfrac{a_1(q^n-1)}{q-1} = \dfrac{a_1(1-q^n)}{1-q}$ |
| 前 $n$ 项和（$q = 1$） | $S_n = na_1$ |
| 无穷递缩等比数列和（$\|q\|<1$） | $S = \dfrac{a_1}{1-q}$ |
| 等比中项 | $G = \pm\sqrt{ab}$（$ab>0$） |
| 下标和性质 | $m+n = p+r \implies a_m \cdot a_n = a_p \cdot a_r$ |
| 片段和性质（$q \neq -1$） | $S_k, S_{2k}-S_k, S_{3k}-S_{2k}$ 成等比，公比 $q^k$ |
| 纯循环小数化分数 | $0.\dot{a_1}\cdots\dot{a_n} = \dfrac{a_1\cdots a_n}{\underbrace{99\cdots9}_{n个}}$ |

等比数列与等差数列并称数列中的两大基础类型。等比数列的计算中经常涉及指数运算，因此掌握快速幂算法对于处理大指数情况非常重要。在解题中，片段和性质、构造法求递推数列通项等技巧都需要熟练运用。无穷递缩等比数列的求和公式更是连接数列与极限的重要桥梁。
