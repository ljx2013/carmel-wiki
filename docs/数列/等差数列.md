# 等差数列

## 一、基本概念

### 1.1 定义

如果一个数列从第二项起，每一项与它的前一项的差等于同一个常数，这个数列就叫做**等差数列**（Arithmetic Progression, AP）。这个常数叫做等差数列的**公差**，通常用字母 $d$ 表示。

用数学语言表述为：对于任意正整数 $n \ge 2$，都有
$$a_n - a_{n-1} = d$$
其中 $d$ 为常数。

### 1.2 通项公式

等差数列的通项公式为：
$$a_n = a_1 + (n-1)d$$

其中：
- $a_1$ 是首项（第1项）
- $d$ 是公差
- $n$ 是项数
- $a_n$ 是第 $n$ 项

> **推导过程**：根据定义，$a_2 = a_1 + d$，$a_3 = a_2 + d = a_1 + 2d$，$a_4 = a_3 + d = a_1 + 3d$，以此类推，归纳可得 $a_n = a_1 + (n-1)d$。

更一般地，等差数列中任意两项之间的关系为：
$$a_n = a_m + (n-m)d$$

这个公式告诉我们，只要知道等差数列中的任意一项和公差，就可以求出数列中的任何一项。

### 1.3 前 $n$ 项和公式

等差数列的前 $n$ 项和有两个等价的表达式：

**公式一**（用首项和末项表示）：
$$S_n = \frac{n(a_1 + a_n)}{2}$$

**公式二**（用首项和公差表示）：
$$S_n = na_1 + \frac{n(n-1)d}{2}$$

> **推导过程**（倒序相加法）：
> $$S_n = a_1 + a_2 + a_3 + \cdots + a_n$$
> $$S_n = a_n + a_{n-1} + a_{n-2} + \cdots + a_1$$
> 两式相加得：
> $$2S_n = (a_1+a_n) + (a_2+a_{n-1}) + \cdots + (a_n+a_1)$$
> 由等差数列性质，每一组括号内的和都等于 $a_1+a_n$，共 $n$ 组，因此：
> $$2S_n = n(a_1 + a_n) \implies S_n = \frac{n(a_1 + a_n)}{2}$$
> 将 $a_n = a_1 + (n-1)d$ 代入即得公式二。

## 二、重要性质

### 2.1 下标和相等则项和相等

在等差数列中，如果 $m + n = p + q$（其中 $m, n, p, q$ 均为正整数），那么：
$$a_m + a_n = a_p + a_q$$

**证明**：
$$a_m + a_n = [a_1 + (m-1)d] + [a_1 + (n-1)d] = 2a_1 + (m+n-2)d$$
$$a_p + a_q = [a_1 + (p-1)d] + [a_1 + (q-1)d] = 2a_1 + (p+q-2)d$$
因为 $m+n = p+q$，所以两式相等。

特别地，当 $m + n = 2k$ 时，有 $a_m + a_n = 2a_k$，即 $a_k$ 是 $a_m$ 和 $a_n$ 的等差中项。

### 2.2 等差中项

如果三个数 $a, A, b$ 成等差数列，那么 $A$ 叫做 $a$ 和 $b$ 的**等差中项**。根据等差数列的定义：
$$A - a = b - A \implies 2A = a + b \implies A = \frac{a+b}{2}$$

也就是说，两个数的等差中项等于它们的算术平均值。

### 2.3 等差数列的片段性质

设 $\{a_n\}$ 是公差为 $d$ 的等差数列，则：

1. **等长片段和仍成等差**：$S_k, S_{2k}-S_k, S_{3k}-S_{2k}, \ldots$ 仍成等差数列，其公差为 $k^2d$。

2. **下标成等差的项仍成等差**：$a_m, a_{m+k}, a_{m+2k}, \ldots$ 仍成等差数列，其公差为 $kd$。

3. **线性组合仍为等差**：若 $\{a_n\}, \{b_n\}$ 都是等差数列，则 $\{pa_n + qb_n\}$（$p, q$ 为常数）也是等差数列。

### 2.4 奇数项和与偶数项和的关系

设等差数列 $\{a_n\}$ 共有 $n$ 项，公差为 $d$：

**当 $n = 2k$（偶数）时**：
- 奇数项有 $k$ 项：$a_1, a_3, \ldots, a_{2k-1}$，构成首项为 $a_1$、公差为 $2d$ 的等差数列
- 偶数项有 $k$ 项：$a_2, a_4, \ldots, a_{2k}$，构成首项为 $a_2$、公差为 $2d$ 的等差数列
- 偶数项和与奇数项和之差：$S_{\text{偶}} - S_{\text{奇}} = kd$
- 偶数项和与奇数项和之比：$\dfrac{S_{\text{偶}}}{S_{\text{奇}}} = \dfrac{a_{k+1}}{a_k}$

**当 $n = 2k-1$（奇数）时**：
- 奇数项有 $k$ 项，偶数项有 $k-1$ 项
- 奇数项和减去偶数项和等于中间项：$S_{\text{奇}} - S_{\text{偶}} = a_k$
- $\dfrac{S_{\text{奇}}}{S_{\text{偶}}} = \dfrac{k}{k-1}$
- $S_n = (2k-1)a_k$（即前 $n$ 项和等于项数乘以中间项）

### 2.5 前 $n$ 项和的函数性质

将 $S_n = na_1 + \dfrac{n(n-1)d}{2}$ 整理得：
$$S_n = \frac{d}{2}n^2 + \left(a_1 - \frac{d}{2}\right)n$$

这是关于 $n$ 的二次函数（当 $d \neq 0$ 时），且常数项为0。因此：
- 当 $d > 0$ 时，$S_n$ 对应的抛物线开口向上，$S_n$ 有最小值
- 当 $d < 0$ 时，$S_n$ 对应的抛物线开口向下，$S_n$ 有最大值

求 $S_n$ 的最值时，可以利用二次函数的性质，找到最接近对称轴的正整数 $n$。

## 三、C++ 实现

### 3.1 等差数列基本运算

```cpp
#include <iostream>
#include <vector>
using namespace std;

// 计算等差数列的第n项
long long nthTerm(long long a1, long long d, int n) {
    return a1 + (long long)(n - 1) * d;
}

// 计算等差数列前n项和（公式一：首项+末项）
long long sumFormula1(long long a1, long long an, int n) {
    return (long long)n * (a1 + an) / 2;
}

// 计算等差数列前n项和（公式二：首项+公差）
long long sumFormula2(long long a1, long long d, int n) {
    return (long long)n * a1 + (long long)n * (n - 1) * d / 2;
}

// 生成等差数列的前n项
vector<long long> generateAP(long long a1, long long d, int n) {
    vector<long long> ap(n);
    for (int i = 0; i < n; i++) {
        ap[i] = a1 + (long long)i * d;
    }
    return ap;
}

// 判断三个数是否构成等差数列
bool isAP(long long a, long long b, long long c) {
    return (b - a) == (c - b);
}

// 等差中项
double arithmeticMean(double a, double b) {
    return (a + b) / 2.0;
}

int main() {
    long long a1 = 2, d = 3;
    int n = 10;
    
    cout << "等差数列前10项: ";
    vector<long long> ap = generateAP(a1, d, n);
    for (long long x : ap) cout << x << " ";
    cout << endl;
    
    cout << "第10项 = " << nthTerm(a1, d, 10) << endl;
    cout << "前10项和（公式一）= " << sumFormula1(a1, nthTerm(a1, d, n), n) << endl;
    cout << "前10项和（公式二）= " << sumFormula2(a1, d, n) << endl;
    cout << "4和10的等差中项 = " << arithmeticMean(4, 10) << endl;
    
    return 0;
}
```

**输出**：
```
等差数列前10项: 2 5 8 11 14 17 20 23 26 29 
第10项 = 29
前10项和（公式一）= 155
前10项和（公式二）= 155
4和10的等差中项 = 7
```

## 四、典型例题

### 例题1

**题目**：已知等差数列 $\{a_n\}$ 中，$a_3 = 7$，$a_7 = 15$，求 $a_{10}$ 和前10项和 $S_{10}$。

**解答**：

方法一：利用通项公式

由 $a_n = a_1 + (n-1)d$，代入已知条件：
$$\begin{cases} a_1 + 2d = 7 \\ a_1 + 6d = 15 \end{cases}$$

两式相减得 $4d = 8$，所以 $d = 2$。代入第一式得 $a_1 + 4 = 7$，所以 $a_1 = 3$。

因此：
$$a_{10} = a_1 + 9d = 3 + 9 \times 2 = 21$$
$$S_{10} = \frac{10(a_1 + a_{10})}{2} = 5 \times (3 + 21) = 120$$

方法二：利用任意两项关系

由 $a_n = a_m + (n-m)d$，得：
$$a_7 = a_3 + 4d \implies 15 = 7 + 4d \implies d = 2$$

然后：
$$a_{10} = a_7 + 3d = 15 + 3 \times 2 = 21$$

再由 $a_1 = a_3 - 2d = 7 - 4 = 3$，同样可求出 $S_{10} = 120$。

> **答案**：$a_{10} = \boxed{21}$，$S_{10} = \boxed{120}$

### 例题2

**题目**：等差数列 $\{a_n\}$ 的前 $n$ 项和为 $S_n$，已知 $S_{10} = 100$，$S_{20} = 400$，求 $S_{30}$。

**解答**：

方法一：基本公式法

设首项为 $a_1$，公差为 $d$，则：
$$\begin{cases} 10a_1 + \dfrac{10 \times 9}{2}d = 100 \\ 20a_1 + \dfrac{20 \times 19}{2}d = 400 \end{cases}$$

化简：
$$\begin{cases} 10a_1 + 45d = 100 \quad (1) \\ 20a_1 + 190d = 400 \quad (2) \end{cases}$$

由 $(2) - 2 \times (1)$ 得：
$$(20a_1 + 190d) - 2(10a_1 + 45d) = 400 - 200$$
$$100d = 200 \implies d = 2$$

代入 (1)：$10a_1 + 90 = 100 \implies a_1 = 1$

所以：
$$S_{30} = 30 \times 1 + \frac{30 \times 29}{2} \times 2 = 30 + 870 = 900$$

方法二：利用片段和性质

等差数列中，$S_k, S_{2k}-S_k, S_{3k}-S_{2k}$ 仍成等差数列。

取 $k = 10$，则 $S_{10} = 100$，$S_{20} - S_{10} = 300$，设 $S_{30} - S_{20} = x$，则 $100, 300, x$ 成等差数列，所以：
$$2 \times 300 = 100 + x \implies x = 500$$

因此 $S_{30} = S_{20} + 500 = 400 + 500 = 900$。

> **答案**：$S_{30} = \boxed{900}$

### 例题3

**题目**：设等差数列 $\{a_n\}$ 的前 $n$ 项和为 $S_n$，已知 $a_1 > 0$，$S_{12} > 0$，$S_{13} < 0$。求前多少项和最大，并说明理由。

**解答**：

由前 $n$ 项和公式：
$$S_{12} = \frac{12(a_1 + a_{12})}{2} = 6(a_1 + a_{12}) = 6(a_6 + a_7) > 0$$
$$S_{13} = \frac{13(a_1 + a_{13})}{2} = \frac{13 \times 2a_7}{2} = 13a_7 < 0$$

由 $S_{13} < 0$ 得 $13a_7 < 0$，即 $a_7 < 0$。

由 $S_{12} > 0$ 得 $6(a_6 + a_7) > 0$，即 $a_6 + a_7 > 0$。

因为 $a_7 < 0$ 且 $a_6 + a_7 > 0$，所以 $a_6 > -a_7 > 0$，即 $a_6 > 0$。

因此，这个等差数列的第6项为正，第7项为负。由于公差 $d = a_7 - a_6 < 0$，数列是递减的，所以：
$$a_1 > a_2 > \cdots > a_6 > 0 > a_7 > a_8 > \cdots$$

前6项都是正数，从第7项开始都是负数，因此前6项和 $S_6$ 最大。

也可以从二次函数角度分析：$S_n$ 是开口向下的抛物线（因为 $d < 0$），对称轴在 $n = 6$ 和 $n = 7$ 之间（因为 $a_6 > 0, a_7 < 0$），所以最接近对称轴的正整数是 $n = 6$，因此 $S_6$ 最大。

> **答案**：前 $\boxed{6}$ 项和最大

## 五、总结

| 内容 | 公式 |
|------|------|
| 通项公式 | $a_n = a_1 + (n-1)d$ |
| 通项推广 | $a_n = a_m + (n-m)d$ |
| 前 $n$ 项和（一） | $S_n = \dfrac{n(a_1 + a_n)}{2}$ |
| 前 $n$ 项和（二） | $S_n = na_1 + \dfrac{n(n-1)d}{2}$ |
| 等差中项 | $A = \dfrac{a+b}{2}$ |
| 下标和性质 | $m+n = p+q \implies a_m + a_n = a_p + a_q$ |
| 片段和性质 | $S_k, S_{2k}-S_k, S_{3k}-S_{2k}$ 成等差，公差 $k^2d$ |
| 奇偶数项差（偶数项 $2k$） | $S_{\text{偶}} - S_{\text{奇}} = kd$ |
| 奇偶数项差（奇数项 $2k-1$） | $S_{\text{奇}} - S_{\text{偶}} = a_k$ |

等差数列是最基本的数列类型之一，掌握其基本公式和性质对于解决更复杂的数列问题至关重要。在实际解题中，灵活运用下标和性质、片段和性质等往往能大大简化计算过程。
