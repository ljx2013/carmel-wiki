# 向量基础

向量是几何与代数之间的桥梁，是计算几何的基石。无论是简单的线段相交判断，还是复杂的碰撞检测，向量运算都扮演着核心角色。本文将系统介绍向量的定义、基本运算及其几何意义，并给出 C++ 实现与经典例题。

## 向量定义与表示

### 什么是向量

**向量**（Vector）是既有**大小**又有**方向**的量。与只有大小的标量（Scalar）不同，向量可以表示位移、速度、力等物理概念。

在几何中，向量通常用有向线段表示：
- 起点为 $A$，终点为 $B$ 的向量记作 $\overrightarrow{AB}$
- 向量的大小（模长）记作 $|\overrightarrow{AB}|$，表示线段的长度

### 坐标表示

在平面直角坐标系中，任意向量都可以用有序实数对表示：

$$\vec{a} = (x, y)$$

其中 $x$ 称为 $x$ 分量，$y$ 称为 $y$ 分量。向量也可以写成列向量形式：

$$\vec{a} = \begin{pmatrix} x \\ y \end{pmatrix}$$

在三维空间中，向量有三个分量：$\vec{a} = (x, y, z)$。

> **注意**：向量与位置无关。无论起点在哪里，只要两个向量的分量对应相等，它们就是**相等向量**。因此通常将向量的起点放在原点进行研究。

### 特殊向量

| 名称 | 定义 | 表示 |
|------|------|------|
| 零向量 | 所有分量都是 0 的向量 | $\vec{0} = (0, 0)$ |
| 单位向量 | 模长等于 1 的向量 | $\hat{a} = \dfrac{\vec{a}}{|\vec{a}|}$ |
| 负向量 | 与 $\vec{a}$ 大小相等、方向相反的向量 | $-\vec{a} = (-x, -y)$ |

## 向量的加减运算

### 加法运算

两个向量相加，对应分量相加：

$$\vec{a} + \vec{b} = (x_1 + x_2, y_1 + y_2)$$

**几何意义**：
- **三角形法则**：将 $\vec{b}$ 的起点平移到 $\vec{a}$ 的终点，则从 $\vec{a}$ 的起点到 $\vec{b}$ 的终点的向量即为 $\vec{a} + \vec{b}$
- **平行四边形法则**：将 $\vec{a}$ 和 $\vec{b}$ 的起点放在同一点，以它们为邻边作平行四边形，则从该公共起点出发的对角线即为 $\vec{a} + \vec{b}$

### 减法运算

两个向量相减，对应分量相减：

$$\vec{a} - \vec{b} = (x_1 - x_2, y_1 - y_2)$$

**几何意义**：$\vec{a} - \vec{b}$ 表示从 $\vec{b}$ 的终点指向 $\vec{a}$ 的终点的向量。即：

$$\overrightarrow{AB} = B - A$$

这是计算几何中最常用的公式之一：给定点 $A$ 和 $B$，向量 $\overrightarrow{AB}$ 等于终点坐标减去起点坐标。

### 运算性质

$$\vec{a} + \vec{b} = \vec{b} + \vec{a} \quad \text{（交换律）}$$
$$(\vec{a} + \vec{b}) + \vec{c} = \vec{a} + (\vec{b} + \vec{c}) \quad \text{（结合律）}$$
$$\vec{a} + \vec{0} = \vec{a}$$

## 数乘运算

实数 $k$ 与向量 $\vec{a}$ 的乘积记作 $k\vec{a}$，定义为：

$$k\vec{a} = (kx, ky)$$

### 几何意义

- 当 $k > 0$ 时，方向不变，长度变为原来的 $k$ 倍
- 当 $k < 0$ 时，方向相反，长度变为原来的 $|k|$ 倍
- 当 $k = 0$ 时，结果为零向量 $\vec{0}$

特别地，$-1 \cdot \vec{a} = -\vec{a}$，即数乘 $-1$ 得到负向量。

### 运算性质

$$k(m\vec{a}) = (km)\vec{a} \quad \text{（结合律）}$$
$$(k + m)\vec{a} = k\vec{a} + m\vec{a} \quad \text{（分配律1）}$$
$$k(\vec{a} + \vec{b}) = k\vec{a} + k\vec{b} \quad \text{（分配律2）}$$

## 内积（点乘）

### 定义

两个向量的**内积**（Dot Product，也称点积）是一个标量，定义为对应分量乘积之和：

$$\vec{a} \cdot \vec{b} = x_1x_2 + y_1y_2$$

内积的另一个等价定义（几何定义）为：

$$\vec{a} \cdot \vec{b} = |\vec{a}| |\vec{b}| \cos\theta$$

其中 $\theta$ 为两个向量之间的夹角（$0 \leq \theta \leq \pi$）。

### 几何意义：投影

内积的几何意义是**投影**。将向量 $\vec{b}$ 投影到向量 $\vec{a}$ 所在的直线上，得到投影向量 $\vec{b'}$，其长度为 $|\vec{b}| \cos\theta$。因此：

$$\vec{a} \cdot \vec{b} = |\vec{a}| \times (\text{投影长度})$$

> **重要性质**：向量 $\vec{a}$ 自身的内积等于模长的平方：
> $$\vec{a} \cdot \vec{a} = |\vec{a}|^2 = x^2 + y^2$$
> 因此向量模长可以用内积计算：$|\vec{a}| = \sqrt{\vec{a} \cdot \vec{a}}$

### 判断夹角类型

根据内积的几何定义 $\vec{a} \cdot \vec{b} = |\vec{a}| |\vec{b}| \cos\theta$，由于 $|\vec{a}|$ 和 $|\vec{b}|$ 恒为非负数，内积的符号直接由 $\cos\theta$ 决定：

| 条件 | 夹角类型 |
|------|----------|
| $\vec{a} \cdot \vec{b} > 0$ | $\theta < 90^\circ$，锐角 |
| $\vec{a} \cdot \vec{b} = 0$ | $\theta = 90^\circ$，直角（正交） |
| $\vec{a} \cdot \vec{b} < 0$ | $\theta > 90^\circ$，钝角 |

!!! tip "正交判定"
    两个非零向量**正交**（垂直）的充要条件是它们的内积为零：
    $$\vec{a} \perp \vec{b} \iff \vec{a} \cdot \vec{b} = 0$$

### 正交投影公式

向量 $\vec{b}$ 在向量 $\vec{a}$ 方向上的**正交投影**（Orthogonal Projection）是一个向量，记作 $\text{proj}_{\vec{a}} \vec{b}$。

推导过程：
1. 投影的长度为 $|\vec{b}| \cos\theta = \dfrac{\vec{a} \cdot \vec{b}}{|\vec{a}|}$
2. 投影的方向与 $\vec{a}$ 相同，单位向量为 $\dfrac{\vec{a}}{|\vec{a}|}$

因此：

$$\text{proj}_{\vec{a}} \vec{b} = \left( \frac{\vec{a} \cdot \vec{b}}{|\vec{a}|^2} \right) \vec{a} = \left( \frac{\vec{a} \cdot \vec{b}}{\vec{a} \cdot \vec{a}} \right) \vec{a}$$

## 外积（叉乘）

### 二维叉乘

在二维平面中，两个向量的**外积**（Cross Product，也称叉乘）定义为一个**标量**：

$$\vec{a} \times \vec{b} = x_1y_2 - x_2y_1$$

### 三维叉乘

在三维空间中，两个向量的叉乘是一个**向量**：

$$\vec{a} \times \vec{b} = \begin{vmatrix} \hat{i} & \hat{j} & \hat{k} \\ x_1 & y_1 & z_1 \\ x_2 & y_2 & z_2 \end{vmatrix} = (y_1z_2 - y_2z_1, z_1x_2 - z_2x_1, x_1y_2 - x_2y_1)$$

其中 $\hat{i}, \hat{j}, \hat{k}$ 分别是 $x, y, z$ 轴方向的单位向量。

### 几何意义：面积与方向

二维叉乘的绝对值等于以两个向量为邻边的**平行四边形的面积**：

$$S = |\vec{a} \times \vec{b}| = |x_1y_2 - x_2y_1|$$

对应的三角形面积为平行四边形面积的一半：

$$S_{\triangle} = \frac{1}{2} |\vec{a} \times \vec{b}|$$

### 叉乘的符号：判断左右

二维叉乘的符号具有重要的几何意义，它可以判断一个点在一条有向直线的哪一侧，或者三个点构成的转向。

设向量 $\overrightarrow{AB}$ 为基准方向，考察点 $C$：

计算叉乘 $\overrightarrow{AB} \times \overrightarrow{AC}$：

| 叉乘符号 | 几何含义 |
|----------|----------|
| $> 0$ | $C$ 在 $\overrightarrow{AB}$ 的**左侧**，$A \to B \to C$ 为**逆时针**转向 |
| $= 0$ | $A, B, C$ **三点共线** |
| $< 0$ | $C$ 在 $\overrightarrow{AB}$ 的**右侧**，$A \to B \to C$ 为**顺时针**转向 |

!!! warning "叉乘不满足交换律"
    叉乘满足反交换律：
    $$\vec{a} \times \vec{b} = -\vec{b} \times \vec{a}$$
    这意味着交换顺序会改变符号。

## 向量共线与共面判定

### 二维共线判定

两个向量 $\vec{a} = (x_1, y_1)$ 和 $\vec{b} = (x_2, y_2)$ **共线**（平行）的充要条件：

$$\vec{a} \times \vec{b} = 0 \quad \text{即} \quad x_1y_2 = x_2y_1$$

几何解释：两个向量构成的平行四边形面积为 $0$，说明它们在同一条直线上。

### 三点共线判定

三个点 $A, B, C$ 共线的充要条件：

$$\overrightarrow{AB} \times \overrightarrow{AC} = 0$$

### 三维共面判定

三个三维向量 $\vec{a}, \vec{b}, \vec{c}$ **共面**的充要条件是它们的**混合积**为零：

$$(\vec{a} \times \vec{b}) \cdot \vec{c} = 0$$

混合积的绝对值等于以三个向量为棱的平行六面体的体积，体积为零说明三个向量共面。

四个点 $A, B, C, D$ 共面的充要条件：

$$(\overrightarrow{AB} \times \overrightarrow{AC}) \cdot \overrightarrow{AD} = 0$$

## C++ 实现向量

下面给出二维向量的完整 C++ 实现，包含点积、叉积、线段相交判断等核心功能。

### 向量结构体与基本运算

```cpp
#include <iostream>
#include <cmath>
#include <algorithm>

using namespace std;

const double eps = 1e-8;
const double PI = acos(-1.0);

int sgn(double x) {
    if (fabs(x) < eps) return 0;
    if (x < 0) return -1;
    return 1;
}

struct Point {
    double x, y;
    Point() {}
    Point(double x, double y) : x(x), y(y) {}
    
    Point operator+(const Point &p) const { return Point(x + p.x, y + p.y); }
    Point operator-(const Point &p) const { return Point(x - p.x, y - p.y); }
    Point operator*(const double k) const { return Point(x * k, y * k); }
    Point operator/(const double k) const { return Point(x / k, y / k); }
    
    bool operator==(const Point &p) const {
        return sgn(x - p.x) == 0 && sgn(y - p.y) == 0;
    }
};

typedef Point Vector;
```

### 点积、叉积与模长

```cpp
double dot(Vector a, Vector b) {
    return a.x * b.x + a.y * b.y;
}

double cross(Vector a, Vector b) {
    return a.x * b.y - a.y * b.x;
}

double cross(Point A, Point B, Point C) {
    return cross(B - A, C - A);
}

double length(Vector a) {
    return sqrt(dot(a, a));
}

double distance(Point A, Point B) {
    return length(B - A);
}
```

### 线段相交判定（参数法）

线段相交判断使用**参数法**（也称 Straddle 跨立实验），分两步：

1. **快速排斥实验**：两个线段的外接矩形不相交，则线段不可能相交
2. **跨立实验**：利用叉乘判断每条线段的两个端点是否分别在另一条线段的两侧

```cpp
bool onSegment(Point P, Point A, Point B) {
    return sgn(cross(A, B, P)) == 0 && sgn(dot(A - P, B - P)) <= 0;
}

bool segmentIntersection(Point A1, Point A2, Point B1, Point B2) {
    // 快速排斥实验
    if (max(A1.x, A2.x) < min(B1.x, B2.x) - eps) return false;
    if (max(B1.x, B2.x) < min(A1.x, A2.x) - eps) return false;
    if (max(A1.y, A2.y) < min(B1.y, B2.y) - eps) return false;
    if (max(B1.y, B2.y) < min(A1.y, A2.y) - eps) return false;
    
    // 跨立实验
    double c1 = cross(A2 - A1, B1 - A1);
    double c2 = cross(A2 - A1, B2 - A1);
    double c3 = cross(B2 - B1, A1 - B1);
    double c4 = cross(B2 - B1, A2 - B1);
    
    // 严格相交
    if (sgn(c1) * sgn(c2) < 0 && sgn(c3) * sgn(c4) < 0) return true;
    
    // 端点在线段上（共线重叠情况）
    if (onSegment(B1, A1, A2)) return true;
    if (onSegment(B2, A1, A2)) return true;
    if (onSegment(A1, B1, B2)) return true;
    if (onSegment(A2, B1, B2)) return true;
    
    return false;
}
```

> **说明**：浮点运算需要注意精度问题，引入 `eps = 1e-8` 作为误差阈值，`sgn` 函数用于判断符号。

## 例题

### 例题 1：判断点是否在三角形内部

**题目**：给定三角形 $ABC$ 和点 $P$，判断 $P$ 是否在三角形内部（不包含边界）。

**思路**：利用叉乘判断点是否在三角形三条边的同一侧（同侧法）。对于逆时针排列的三角形，点 $P$ 应该在三条边的左侧（叉乘均为正）。

**解答**：

设三个叉乘：
- $c_1 = \overrightarrow{AB} \times \overrightarrow{AP}$
- $c_2 = \overrightarrow{BC} \times \overrightarrow{BP}$
- $c_3 = \overrightarrow{CA} \times \overrightarrow{CP}$

若 $c_1, c_2, c_3$ 全部为正（三角形逆时针）或全部为负（三角形顺时针），则 $P$ 在三角形内部。

```cpp
bool pointInTriangle(Point A, Point B, Point C, Point P) {
    double c1 = cross(B - A, P - A);
    double c2 = cross(C - B, P - B);
    double c3 = cross(A - C, P - C);
    return (sgn(c1) > 0 && sgn(c2) > 0 && sgn(c3) > 0) ||
           (sgn(c1) < 0 && sgn(c2) < 0 && sgn(c3) < 0);
}
```

### 例题 2：点到直线的距离

**题目**：求点 $P$ 到直线 $AB$ 的距离。

**思路**：利用叉乘求平行四边形面积，再除以底边长度。

**解答**：

以 $\overrightarrow{AB}$ 和 $\overrightarrow{AP}$ 为邻边的平行四边形面积为 $|\overrightarrow{AB} \times \overrightarrow{AP}|$，底边长度为 $|\overrightarrow{AB}|$，因此：

$$d = \frac{|\overrightarrow{AB} \times \overrightarrow{AP}|}{|\overrightarrow{AB}|}$$

```cpp
double distanceToLine(Point P, Point A, Point B) {
    return fabs(cross(B - A, P - A)) / length(B - A);
}
```

### 例题 3：求两个向量的夹角

**题目**：给定两个向量 $\vec{a}$ 和 $\vec{b}$，求它们的夹角（弧度制）。

**思路**：利用点积公式 $\vec{a} \cdot \vec{b} = |\vec{a}| |\vec{b}| \cos\theta$。

**解答**：

$$\cos\theta = \frac{\vec{a} \cdot \vec{b}}{|\vec{a}| |\vec{b}|}$$
$$\theta = \arccos\left( \frac{\vec{a} \cdot \vec{b}}{|\vec{a}| |\vec{b}|} \right)$$

```cpp
double angleBetween(Vector a, Vector b) {
    double cos_theta = dot(a, b) / (length(a) * length(b));
    cos_theta = max(-1.0, min(1.0, cos_theta));
    return acos(cos_theta);
}
```

> **注意**：由于浮点误差，$\cos\theta$ 可能超出 $[-1, 1]$ 范围，需要钳位处理。

### 例题 4：判断凸多边形

**题目**：给定多边形顶点序列 $P_0, P_1, \dots, P_{n-1}$，判断该多边形是否为凸多边形。

**思路**：凸多边形的所有相邻边向量的叉乘符号相同（全部非负或全部非正）。即沿着多边形边界走，每一次转向的方向一致。

**解答**：

遍历每三个连续顶点 $(P_i, P_{i+1}, P_{i+2})$，计算叉乘 $\overrightarrow{P_iP_{i+1}} \times \overrightarrow{P_{i+1}P_{i+2}}$ 的符号。如果所有叉乘的符号相同，则为凸多边形。

```cpp
bool isConvexPolygon(Point p[], int n) {
    bool hasPos = false, hasNeg = false;
    for (int i = 0; i < n; i++) {
        int j = (i + 1) % n;
        int k = (i + 2) % n;
        double c = cross(p[j] - p[i], p[k] - p[j]);
        if (sgn(c) > 0) hasPos = true;
        if (sgn(c) < 0) hasNeg = true;
        if (hasPos && hasNeg) return false;
    }
    return true;
}
```

**时间复杂度**：$O(n)$，需遍历所有顶点。
