# 三角形面积与海伦公式

三角形是最简单的多边形，却是计算几何中最重要的基本图形之一。求三角形面积的方法多种多样，从最直观的"底乘高"到优雅的海伦公式，每一种公式都蕴含着深刻的几何意义。本文将系统总结四种常用的三角形面积公式，推导海伦公式，介绍三角形的内心、外心等特殊点，并给出 Pick 定理及其应用。

## 四种面积公式

设 $\triangle ABC$ 的三个顶点为 $A, B, C$，对应边长为 $a = |BC|, b = |AC|, c = |AB|$，高为 $h_a$（$BC$ 边上的高），内角为 $\angle A, \angle B, \angle C$。

### 公式一：底乘高公式

最经典、最直观的面积公式：

$$S = \frac{1}{2} \times \text{底} \times \text{高} = \frac{1}{2} \cdot a \cdot h_a$$

同理也可写成 $S = \dfrac{1}{2} b \cdot h_b = \dfrac{1}{2} c \cdot h_c$。

**几何意义**：将三角形补成同底等高的平行四边形，三角形面积为平行四边形面积的一半。

**适用场景**：已知一条边的长度及对应高时直接使用。在解析几何中，若已知直线方程，可通过点到直线的距离求高。

### 公式二：两边及夹角公式

已知两边长度及其夹角：

$$S = \frac{1}{2}ab \sin C = \frac{1}{2}bc \sin A = \frac{1}{2}ac \sin B$$

**推导**：由高的定义，$h_a = b \sin C$，代入底乘高公式即得。

**适用场景**：已知两边及其夹角时使用。特别地，当夹角为 $90^\circ$ 时，$\sin 90^\circ = 1$，公式退化为直角三角形面积 $S = \dfrac{1}{2}ab$。

### 公式三：坐标叉乘公式（行列式形式）

已知三角形三个顶点的坐标：$A(x_1, y_1), B(x_2, y_2), C(x_3, y_3)$，则：

$$S = \frac{1}{2} \left| (B - A) \times (C - A) \right|$$

展开写成分量形式：

$$S = \frac{1}{2} \left| (x_2 - x_1)(y_3 - y_1) - (y_2 - y_1)(x_3 - x_1) \right|$$

用行列式表示更加简洁：

$$S = \frac{1}{2} \left| \begin{vmatrix} x_1 & y_1 & 1 \\ x_2 & y_2 & 1 \\ x_3 & y_3 & 1 \end{vmatrix} \right| = \frac{1}{2} \left| x_1(y_2 - y_3) + x_2(y_3 - y_1) + x_3(y_1 - y_2) \right|$$

**几何意义**：向量 $\overrightarrow{AB}$ 和 $\overrightarrow{AC}$ 的叉乘绝对值等于以它们为邻边的平行四边形面积，取一半即得三角形面积。

**适用场景**：坐标法计算的首选公式，是计算几何中使用最频繁的面积公式。

### 公式四：海伦公式（Heron's Formula）

已知三角形的三边长 $a, b, c$，令**半周长**（Semiperimeter）：

$$p = \frac{a + b + c}{2}$$

则面积：

$$S = \sqrt{p(p - a)(p - b)(p - c)}$$

**适用场景**：仅已知三边长时使用。海伦公式形式优美对称，在仅知道边长而不知道角度或坐标时非常方便。

!!! tip "四种公式对比"

    | 公式 | 已知条件 | 优点 | 适用场景 |
    |------|----------|------|----------|
    | $\dfrac{1}{2}ah_a$ | 一边及对应高 | 最直观 | 初等几何 |
    | $\dfrac{1}{2}ab\sin C$ | 两边及夹角 | 三角函数结合 | 解三角形 |
    | $\dfrac{1}{2}\|\overrightarrow{AB} \times \overrightarrow{AC}\|$ | 三点坐标 | 计算高效 | 计算几何 |
    | $\sqrt{p(p-a)(p-b)(p-c)}$ | 三边长 | 形式对称优美 | 仅知边长 |

## 海伦公式的推导

海伦公式并非凭空而来，它可以通过余弦定理和代数变形严谨推导。

### 推导步骤

**第一步**：由余弦定理求 $\cos C$

$$c^2 = a^2 + b^2 - 2ab \cos C$$

解得：

$$\cos C = \frac{a^2 + b^2 - c^2}{2ab}$$

**第二步**：利用三角恒等式求 $\sin C$

由 $\sin^2 C + \cos^2 C = 1$：

$$\sin^2 C = 1 - \cos^2 C = (1 - \cos C)(1 + \cos C)$$

代入 $\cos C$ 的表达式：

$$1 - \cos C = 1 - \frac{a^2 + b^2 - c^2}{2ab} = \frac{2ab - a^2 - b^2 + c^2}{2ab} = \frac{c^2 - (a - b)^2}{2ab} = \frac{(c + a - b)(c - a + b)}{2ab}$$

$$1 + \cos C = 1 + \frac{a^2 + b^2 - c^2}{2ab} = \frac{2ab + a^2 + b^2 - c^2}{2ab} = \frac{(a + b)^2 - c^2}{2ab} = \frac{(a + b + c)(a + b - c)}{2ab}$$

**第三步**：代入半周长 $p = \dfrac{a + b + c}{2}$

注意到：

$$a + b + c = 2p$$
$$a + b - c = 2(p - c)$$
$$b + c - a = 2(p - a)$$
$$c + a - b = 2(p - b)$$

因此：

$$\sin^2 C = \frac{2(p - b) \cdot 2(p - a)}{2ab} \cdot \frac{2p \cdot 2(p - c)}{2ab} = \frac{4p(p - a)(p - b)(p - c)}{a^2b^2}$$

开方（取正值，因为 $0 < C < \pi$，所以 $\sin C > 0$）：

$$\sin C = \frac{2\sqrt{p(p - a)(p - b)(p - c)}}{ab}$$

**第四步**：代入面积公式 $S = \dfrac{1}{2}ab \sin C$

$$S = \frac{1}{2}ab \cdot \frac{2\sqrt{p(p - a)(p - b)(p - c)}}{ab} = \sqrt{p(p - a)(p - b)(p - c)}$$

证毕。

## 秦九韶三斜求积公式

中国南宋数学家秦九韶在《数书九章》（1247年）中独立提出了与海伦公式等价的"三斜求积术"：

$$S = \sqrt{\frac{1}{4} \left[ a^2c^2 - \left( \frac{a^2 + c^2 - b^2}{2} \right)^2 \right]}$$

其中 $a$ 为"大斜"（最长边），$b$ 为"中斜"，$c$ 为"小斜"（最短边）。

### 等价性证明

我们可以将秦九韶公式展开，化简后即可得到海伦公式。

令大斜 $a$、中斜 $b$、小斜 $c$，秦九韶公式：

$$16S^2 = 4a^2c^2 - (a^2 + c^2 - b^2)^2$$

右边用平方差公式因式分解：

$$4a^2c^2 - (a^2 + c^2 - b^2)^2 = [2ac - (a^2 + c^2 - b^2)] \cdot [2ac + (a^2 + c^2 - b^2)]$$
$$= [b^2 - (a - c)^2] \cdot [(a + c)^2 - b^2]$$
$$= (b + a - c)(b - a + c)(a + c + b)(a + c - b)$$
$$= 2(p - c) \cdot 2(p - a) \cdot 2p \cdot 2(p - b)$$
$$= 16p(p - a)(p - b)(p - c)$$

因此 $16S^2 = 16p(p - a)(p - b)(p - c)$，两边开方即得海伦公式。

> **历史注记**：秦九韶公式与海伦公式虽然形式不同，但本质等价。前者用边长平方表示，后者用半周长表示。秦九韶的工作比海伦晚了一千多年，但完全是独立发现。

## 内心、外心与特殊圆

### 内心与内切圆

三角形的**内心**（Incenter）是三条角平分线的交点，也是三角形**内切圆**的圆心。

- 内心到三边的距离相等，这个距离就是内切圆半径 $r$
- 内切圆与三角形三边都相切

**内切圆半径公式**：

$$r = \frac{S}{p}$$

**推导**：连接内心 $I$ 与三个顶点，将 $\triangle ABC$ 分成三个小三角形 $\triangle IBC, \triangle ICA, \triangle IAB$，它们的高都是内切圆半径 $r$，因此：

$$S = S_{\triangle IBC} + S_{\triangle ICA} + S_{\triangle IAB} = \frac{1}{2}a \cdot r + \frac{1}{2}b \cdot r + \frac{1}{2}c \cdot r = \frac{1}{2}(a + b + c)r = p \cdot r$$

整理即得 $r = \dfrac{S}{p}$。

### 外心与外接圆

三角形的**外心**（Circumcenter）是三条垂直平分线的交点，也是三角形**外接圆**的圆心。

- 外心到三个顶点的距离相等，这个距离就是外接圆半径 $R$
- 外接圆经过三角形的三个顶点

**外接圆半径公式**：

$$R = \frac{abc}{4S}$$

**推导**：由正弦定理 $\dfrac{a}{\sin A} = 2R$，得 $\sin A = \dfrac{a}{2R}$。代入面积公式 $S = \dfrac{1}{2}bc \sin A$：

$$S = \frac{1}{2}bc \cdot \frac{a}{2R} = \frac{abc}{4R}$$

整理即得 $R = \dfrac{abc}{4S}$。

> **特殊三角形的半径**
> - 等边三角形：$r = \dfrac{a\sqrt{3}}{6}$，$R = \dfrac{a\sqrt{3}}{3}$，注意 $R = 2r$
> - 直角三角形：$R = \dfrac{c}{2}$（$c$ 为斜边），$r = \dfrac{a + b - c}{2}$

### 旁心、重心简介

| 特殊点 | 定义 | 坐标公式 |
|--------|------|----------|
| **重心** $G$ | 三条中线交点 | $\left( \dfrac{x_A + x_B + x_C}{3}, \dfrac{y_A + y_B + y_C}{3} \right)$ |
| **垂心** $H$ | 三条高线交点 | 无简单公式 |
| **旁心** $I_a$ | 一个内角平分线与另外两个外角平分线交点 | 权重 $(-a : b : c)$ |
| **内心** $I$ | 三条角平分线交点 | 权重 $(a : b : c)$ |
| **外心** $O$ | 三条垂直平分线交点 | 无简单公式 |

**重心的性质**：重心将每条中线分为 $2:1$ 的两段（靠近顶点的一段长为 $2$ 份）。

**旁心**：三角形有三个旁心，每个旁心对应一个旁切圆，旁切圆与三角形一边及另外两边的延长线相切。旁切圆半径 $r_a = \dfrac{S}{p - a}$。

!!! note "欧拉线"
    在任意非等边三角形中，重心 $G$、垂心 $H$、外心 $O$ 三点共线，这条直线称为**欧拉线**（Euler Line），且满足 $HG : GO = 2 : 1$。

## Pick 定理

### 定理陈述

**Pick 定理**（皮克定理）是一个非常巧妙的结论，用于计算**格点多边形**（顶点都在格点上的简单多边形）的面积。

设格点多边形的：
- 内部格点数为 $I$（Interior）
- 边界格点数为 $B$（Boundary）

则多边形面积：

$$S = I + \frac{B}{2} - 1$$

### 示例验证

以 $2 \times 2$ 的格点正方形为例：

```
(0,2)──(1,2)──(2,2)
  │       │       │
(0,1)──(1,1)──(2,1)
  │       │       │
(0,0)──(1,0)──(2,0)
```

取顶点为 $(0,0), (2,0), (2,2), (0,2)$ 的正方形：
- 面积 $S = 4$
- 内部格点 $I = 1$（点 $(1,1)$）
- 边界格点 $B = 8$（每条边 3 个点，共 $4 \times 3 - 4 = 8$，减去重复的 4 个顶点）

代入 Pick 定理：

$$S = 1 + \frac{8}{2} - 1 = 1 + 4 - 1 = 4 \quad \checkmark$$

再看一个直角三角形，顶点 $(0,0), (3,0), (0,4)$：
- 面积 $S = \dfrac{1}{2} \times 3 \times 4 = 6$
- 内部格点：通过枚举或计算 $I = 3$
- 边界格点：三条边的格点数分别为 4（水平边）、5（竖直边）、gcd(3,4)+1=5（斜边），共 $4+5+5-3=11$，$B=11$

代入验证：

$$S = 3 + \frac{11}{2} - 1 = 3 + 5.5 - 1 = 7.5 \quad?$$

等等，这不对！让我们重新仔细计算边界格点和内部格点。

正确的边界格点计算：一条线段从 $(x_1, y_1)$ 到 $(x_2, y_2)$ 上的格点数为 $\gcd(|x_2-x_1|, |y_2-y_1|) + 1$。

- 边 $(0,0) \to (3,0)$：$\gcd(3,0)+1 = 3+1 = 4$
- 边 $(3,0) \to (0,4)$：$\gcd(3,4)+1 = 1+1 = 2$
- 边 $(0,4) \to (0,0)$：$\gcd(0,4)+1 = 4+1 = 5$

边界格点总数（减去重复的 3 个顶点）：$B = (4-1) + (2-1) + (5-1) = 3 + 1 + 4 = 8$

内部格点 $I$：枚举 $(1,1), (1,2), (2,1)$，共 3 个。

$$S = 3 + \frac{8}{2} - 1 = 3 + 4 - 1 = 6 \quad \checkmark$$

> **边界格点公式**：线段两端点 $(x_1,y_1)$ 和 $(x_2,y_2)$ 之间的格点数为 $\gcd(|x_2-x_1|, |y_2-y_1|) + 1$。计算多边形边界格点时，每条边贡献 $\gcd(\Delta x, \Delta y)$ 个不重复格点（不计算末端顶点），总和即为 $B$。

## 例题

### 例题 1：已知三边求面积

**题目**：三角形三边长分别为 $a = 13, b = 14, c = 15$，求面积。

**解答**：

这是著名的"13-14-15 三角形"，用海伦公式求解：

半周长：

$$p = \frac{13 + 14 + 15}{2} = 21$$

面积：

$$S = \sqrt{p(p-a)(p-b)(p-c)} = \sqrt{21 \times (21-13) \times (21-14) \times (21-15)}$$
$$= \sqrt{21 \times 8 \times 7 \times 6} = \sqrt{7056} = 84$$

答案：$S = 84$。

### 例题 2：求内切圆和外接圆半径

**题目**：三角形三边长为 $a = 5, b = 12, c = 13$，求内切圆半径 $r$ 和外接圆半径 $R$。

**解答**：

首先注意到 $5^2 + 12^2 = 25 + 144 = 169 = 13^2$，这是一个直角三角形！

半周长：

$$p = \frac{5 + 12 + 13}{2} = 15$$

面积（用直角三角形面积公式）：

$$S = \frac{1}{2} \times 5 \times 12 = 30$$

内切圆半径：

$$r = \frac{S}{p} = \frac{30}{15} = 2$$

验证直角三角形内切圆公式：$r = \dfrac{a + b - c}{2} = \dfrac{5 + 12 - 13}{2} = \dfrac{4}{2} = 2 \quad \checkmark$

外接圆半径：

$$R = \frac{abc}{4S} = \frac{5 \times 12 \times 13}{4 \times 30} = \frac{780}{120} = 6.5$$

验证直角三角形外接圆公式：$R = \dfrac{c}{2} = \dfrac{13}{2} = 6.5 \quad \checkmark$

答案：$r = 2$，$R = \dfrac{13}{2} = 6.5$。

---

### 例题 3：坐标法求三角形面积

**题目**：已知三角形三个顶点 $A(1, 2), B(4, 6), C(7, 3)$，求三角形面积。

**解答**：

使用叉乘公式：

$$\overrightarrow{AB} = B - A = (4 - 1, 6 - 2) = (3, 4)$$
$$\overrightarrow{AC} = C - A = (7 - 1, 3 - 2) = (6, 1)$$

叉乘：

$$\overrightarrow{AB} \times \overrightarrow{AC} = 3 \times 1 - 4 \times 6 = 3 - 24 = -21$$

面积：

$$S = \frac{1}{2} |-21| = \frac{21}{2} = 10.5$$

**验证（用海伦公式）**：

三边长：
- $a = |BC| = \sqrt{(7-4)^2 + (3-6)^2} = \sqrt{9 + 9} = \sqrt{18} = 3\sqrt{2}$
- $b = |AC| = \sqrt{(7-1)^2 + (3-2)^2} = \sqrt{36 + 1} = \sqrt{37}$
- $c = |AB| = \sqrt{(4-1)^2 + (6-2)^2} = \sqrt{9 + 16} = 5$

半周长 $p = \dfrac{3\sqrt{2} + \sqrt{37} + 5}{2}$，直接代入海伦公式计算繁琐，但结果一致（$S^2 = 110.25$）。可见坐标叉乘法的优势。

答案：$S = \dfrac{21}{2} = 10.5$。

### 例题 4：Pick 定理的应用

**题目**：格点三角形的三个顶点为 $A(0, 0), B(6, 0), C(2, 4)$，请用两种方法求面积并验证 Pick 定理。

**解答**：

**方法一：坐标叉乘法**

$$\overrightarrow{AB} = (6, 0), \quad \overrightarrow{AC} = (2, 4)$$

$$S = \frac{1}{2} |6 \times 4 - 0 \times 2| = \frac{1}{2} \times 24 = 12$$

**方法二：Pick 定理**

首先计算边界格点数 $B$：

- 边 $AB$：$\gcd(6, 0) = 6$，贡献 6 个格点
- 边 $BC$：$\gcd(|2-6|, |4-0|) = \gcd(4, 4) = 4$，贡献 4 个格点
- 边 $CA$：$\gcd(|0-2|, |0-4|) = \gcd(2, 4) = 2$，贡献 2 个格点

$$B = 6 + 4 + 2 = 12$$

现在用 Pick 定理求内部格点数 $I$：

$$S = I + \frac{B}{2} - 1 \implies 12 = I + \frac{12}{2} - 1 \implies 12 = I + 6 - 1 \implies I = 7$$

**验证内部格点**：列出所有满足条件的格点：
$(1,1), (2,1), (3,1), (2,2), (3,2), (4,2), (3,3)$，共 7 个。$\checkmark$

因此 Pick 定理验证成立：

$$12 = 7 + \frac{12}{2} - 1 = 7 + 6 - 1 = 12 \quad \checkmark$$

答案：面积 $S = 12$，Pick 定理验证成立。
