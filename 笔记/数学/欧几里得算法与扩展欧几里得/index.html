    欧几里得算法与扩展欧几里得¶

    最大公约数（gcd）是数论最基础的运算之一，也是「加法」之后第一个真正需要带余除法支撑的概念。本文先给出 gcd 的定义与性质，再推导经典算法（辗转相除法）及其复杂度，最后把它推广成能直接构造解的「扩展欧几里得算法」，并给出求逆元、解线性同余等应用。

    最大公约数的定义¶

    对整数 $a,b$（不同时为 $0$），记 $\gcd(a,b)$ 为能同时整除 $a,b$ 的最大正整数，即

    \[\gcd(a,b)=\max\{\,d\in\mathbb{Z}^+\mid d\mid a\ \text{且}\ d\mid b\,\}\]

    并约定 $\gcd(a,0)=|a|$（即 $0$ 与任意数的最大公约数是该数的绝对值）。

    几个最常用的基本性质：

    1. 交换律：$\gcd(a,b)=\gcd(b,a)$；
    2. 加减不变性：对任意整数 $k$，有 $\gcd(a,b)=\gcd(a,b+ka)=\gcd(a,b-ka)$；
    3. 约去公因数后互质：若 $g=\gcd(a,b)$，则 $\gcd!\left(\dfrac{a}{g},\dfrac{b}{g}\right)=1$；
    4. 与 lcm 的关系：$\gcd(a,b)\cdot\operatorname{lcm}(a,b)=|ab|$。

    其中第 2 条是后面所有算法的核心——它告诉我们「给其中一个数加/减另一个数的若干倍，最大公约数不变」。

    欧几里得算法（辗转相除法）¶

    原理¶

    基于如下定理（当 $b\neq 0$ 时成立）：

    \[\gcd(a,b)=\gcd(b,\ a\bmod b)\]

    证明：设 $a=bq+r$，其中 $q=\lfloor a/b\rfloor$，$r=a\bmod b$，且 $0\le r<b$。 - 若 $d\mid a$ 且 $d\mid b$，则 $d\mid r=a-bq$，所以 $d$ 也是 $(b,r)$ 的公约数； - 反之若 $d\mid b$ 且 $d\mid r$，则 $d\mid a=bq+r$，所以 $d$ 也是 $(a,b)$ 的公约数。

    两边公约数集合完全相同，故最大公约数相等。当 $b=0$ 时直接落到约定 $\gcd(a,0)=|a|$。

    复杂度¶

    每执行一次 a, b = b, a % b，余数严格变小。更精细地：

    • 若 $b\le a/2$，则 $a\bmod b<b\le a/2$，一轮后新的 $a$（即原 $b$）和新的 $b$（即余数）都 $\le a/2$；
    • 若 $b>a/2$，则 $a\bmod b=a-b<a/2$，下一轮 $b$ 会减半。

    因此每两轮数值至少减半，总步数为 $O(\log\min(a,b))$。

    更紧的结论是 Lamé 定理：算法步数不超过 $5\log_{10}(\min(a,b)+1)$。最坏情况恰好发生在 $a,b$ 为相邻的斐波那契数 $F_{n+1},F_n$ 时，需要 $n$ 次递归。

    C++ 实现¶

    递归与迭代两种写法等价，迭代更省栈：

    long long gcd(long long a, long long b) {
    return b ? gcd(b, a % b) : a;
}

// 迭代版（推荐，避免深递归）
long long gcd_iter(long long a, long long b) {
    while (b) {
        a %= b;
        std::swap(a, b);
    }
    return a;
}

    扩展欧几里得算法¶

    贝祖等式（Bézout's identity）¶

    对整数 $a,b$，必然存在整数 $x,y$ 使得

    \[ax+by=\gcd(a,b)\]

    这样的 $(x,y)$ 称为一组贝祖系数。扩展欧几里得算法的目标，就是在求 gcd 的同时把 $(x,y)$ 也构造出来。

    递归推导¶

    假设已经递归求出了 $\gcd(b,\ a\bmod b)$ 的一组解 $(x',y')$，满足

    \[bx'+(a\bmod b)\,y'=\gcd(a,b)\]

    把 $a\bmod b=a-b\lfloor a/b\rfloor$ 代入：

    \[bx'+\bigl(a-b\lfloor a/b\rfloor\bigr)y'=\gcd(a,b)\]

    展开并重新按 $a,b$ 整理：

    \[a\,y'+b\bigl(x'-\lfloor a/b\rfloor\,y'\bigr)=\gcd(a,b)\]

    于是直接读出：取

    \[x=y',\qquad y=x'-\lfloor a/b\rfloor\,y'\]

    就得到原方程 $ax+by=\gcd(a,b)$ 的一组解。

    递归边界：当 $b=0$ 时 $\gcd(a,0)=a$，显然 $a\cdot 1+0\cdot 0=a$，故取 $(x,y)=(1,0)$。

    C++ 实现¶

    // 返回 g = gcd(a,b)，并通过引用返回一组贝祖系数 (x, y) 使 a*x + b*y = g
long long exgcd(long long a, long long b, long long &x, long long &y) {
    if (b == 0) {
        x = 1;
        y = 0;
        return a;
    }
    long long x1, y1;
    long long g = exgcd(b, a % b, x1, y1);
    x = y1;
    y = x1 - (a / b) * y1;
    return g;
}

    通解公式¶

    若 $(x_0,y_0)$ 是一组特解，$g=\gcd(a,b)$，则方程 $ax+by=g$ 的全部整数解为

    \[x=x_0+\frac{b}{g}\,t,\qquad y=y_0-\frac{a}{g}\,t,\qquad t\in\mathbb{Z}\]

    直觉上：$(b/g)\,t$ 与 $(a/g)\,t$ 恰好把「加 $b$ 倍、减 $a$ 倍」相互抵消，保持 $ax+by$ 不变。

    应用¶

    求乘法逆元¶

    若 $\gcd(a,m)=1$，则同余方程 $ax\equiv 1\pmod m$ 有唯一解 $x$，称为 $a$ 模 $m$ 的逆元，记作 $a^{-1}\bmod m$。 用 exgcd 解 $ax+my=1$，取 $x$ 的正余数即可：

    long long inv(long long a, long long m) {
    long long x, y;
    long long g = exgcd(a, m, x, y);
    // 调用前需保证 gcd(a, m) == 1，否则无逆元
    return (x % m + m) % m;   // 保证落在 [0, m) 内
}

    解线性同余方程¶

    方程 $ax\equiv c\pmod m$ 有解 当且仅当 $g=\gcd(a,m)\mid c$。 先用 exgcd 求出 $ax_0+my_0=g$，两边乘 $c/g$ 得到特解 $x^* = x_0\cdot(c/g)$，通解为

    \[x\equiv x^\*\pmod{m/g},\qquad\text{即}\quad x=x^\*+\frac{m}{g}\,t\ (t\in\mathbb{Z})\]

    最小非负解同样用 (x* % (m/g) + m/g) % (m/g) 归一化。

    小结¶

    要点 内容
    核心定义 $\gcd(a,b)$ 为最大公共正因数；约定 $\gcd(a,0)=|a|$
    加减不变性 $\gcd(a,b)=\gcd(a,b+ka)$，是算法的理论根基
    辗转相除 $\gcd(a,b)=\gcd(b,a\bmod b)$；递归 / 迭代均可
    复杂度 $O(\log\min(a,b))$；最坏为相邻斐波那契数（Lamé 定理）
    贝祖等式 存在 $x,y$ 使 $ax+by=\gcd(a,b)$
    扩展欧几里得 递归构造 $(x,y)$，代码约 5 行，返回 gcd
    通解 $x=x_0+(b/g)t,\ y=y_0-(a/g)t\ (t\in\mathbb{Z})$
    典型应用 求乘法逆元、解线性同余方程 $ax\equiv c\pmod m$
